## 目标、顺序和停止点

总体目标仍是给已有 LF/N4 研究层提供独立、任务明确、可审计的 HF 标签。当前仅处理 C2 已发现的启动合同遗漏和强压缩 F 浮点求值问题。本轮顺序为：P1 实现与替身回归 → 独立复核 → 新运动学实现 → 制造场、原保存态完整内力及一致切线验证 → 报告与可恢复交接。

本轮不求解新的平衡路径，不改变原材料、边界、目标、容差或冻结 v3；不把原细网格失败改成通过，也不进入 HF5。路径补测必须另行冻结新协议、实现身份、预算与停止条件。新的固定态计算属于候选实现验证，不是原 run 的重新准入。

## P1 的实现与验收

新增仅依赖标准库的共同校验模块和两个入口；旧 runner、wrapper、协议与审计保留原字节。新入口固定受信协议原字节 SHA，不接受调用者自报 expected SHA 作为授权。完整合同涵盖物理、solver、audit、目标、case、顺序、预算、观测定义、来源及修订身份。

两种公开入口在建目录、日志、回执、导入重型后端或派发子进程之前，完成相同的协议、完整来源、成功前序、预算和次序检查。直接入口不能绕过包装器的共同计划检查。子进程启动后、加载原后端前再次核验输入；内部工作模式与公共直接入口的边界须在实现报告中写明。这个边界用于防误编辑和无效计算，不宣称对能够改写代码与全部证据的恶意调用者提供安全隔离。

反例至少包括逐字段修改、缺项/多项、空来源表、自报新哈希、重复 JSON 键、非有限数、bool 冒充计数、负 elapsed、错误次序、超额预算、失败/超时前序、来源/详情/日志被改，以及 audit 无成功 solve 回执。负例须观察到零派发和零输出；正例只抵达被替身截断的派发边界。完整历史来源缺失仍拒绝，不能把公开 readback 的两项来源边界用于新执行。

## 运动学候选及其范围

候选只在新模块中实现。准确目标是输入 binary64 数所表示的仿射表达式 `F = I + sum(L*grad) + sum(w*grad)`；单位项与乘积高/低部分一起累加，最后舍入。G 单独不加单位项求值，用于原近单位材料分支；不能用 `F-I` 恢复微小 G。HuHu 保持原弱式及其非对称导数。

优先评估 TwoProduct/Dekker Split + TwoSum 的补偿内积（Dot2）。它不是任意输入正确舍入保证；若预先确定的制造场显示二阶残差问题，再保留首候选失败记录并评估更强固定展开。生产端不得读取 HP 答案、用 Decimal 回调替代内核，或只修正输出 F 而不修正残差和切线。

适用范围首先限定为现有轴对齐矩形 Q1、已输入的浮点算子、CPU float64；非 dyadic 算子用 `.1 × .3` 等尺寸覆盖。支持的指数区间必须由实现明确检查，过大/过小输入拒绝而非回退旧算法。编译选项限定在新内核顶层，检查实际补偿计算与编译后中间表示；不以 Python 括号或 barrier 数量单独证明正确性。

数学参考：[Ogita–Rump–Oishi 补偿求和/内积](https://www.tuhh.de/ti3/paper/rump/OgRuOi05.pdf)。编译边界依据 [JAX compiler_options](https://docs.jax.dev/en/latest/201/controlling-xla.html) 与 [optimization_barrier](https://docs.jax.dev/en/latest/_autosummary/jax.lax.optimization_barrier.html)，自定义线性化依据 [custom_jvp](https://docs.jax.dev/en/latest/301/custom-jvp-vjp.html)。本地安装行为还需实际验证，文档不能代替数值证据。

## 无求解验证矩阵

在首次候选数值验证前，另以机器可读清单绑定实际新源码、输入及以下门槛，不因观察结果调松门槛。

- 算术：`1-(1+2^-27)*(1-2^-27)=2^-54` 的乘积残差反例、强消减、dyadic/非 dyadic、NumPy 与编译 JAX 对照，记录支持域和拒绝行为。
- 制造场：零/平移、近刚体、小应变、剪切、非零混合二阶梯度 Hu、近单位分支两侧、强压缩；至少 dyadic 与非 dyadic 两组算子。
- 完整弱式：独立 Decimal 80/120 位给出材料、正则、总内力及解析 Jv；保留原 SF 和分量尺度，使用原 C2 门：总力 `1e-11`、总 Jv `1e-10`、分量 `1e-9`、80/120 一致 `1e-40`。制造场的 SF 在计算前按明确规则定义。
- 一致切线：比较候选组装 `K@v`、残差函数直接 JVP、独立解析 HP Jv；以独立 Decimal 方向差分趋势作为附加证据。不能仅比较两个共享 AD 的结果，不能把 HuHu 弱式当作能量 Hessian 或强制对称。
- 保存态：原细网格末态 `uniform_tmc:20` 与前一个有效态、两条已通过 C2 路径末态及四个原 C1 TMC 末态。优先复用原已存 80/120 位力和切线证据，并逐项重验输入绑定；新独立 HP 计算只用于需要的新制造场/方向核验。候选生产仅接收普通模型/双数组/方向输入，审计层单独读取 HP。

历史身份与新实现身份分开记录；原审计依赖的文件不能改写后再放宽校验。来源输入在原冻结或恢复树验证，候选结果写入新目录，保存原/新源码和输入哈希映射。

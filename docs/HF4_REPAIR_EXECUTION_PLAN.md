# HF-4 状态精度修正执行计划

2026-09-14，用户已授权按[再审阅决定](HF4_REPAIR_READINESS_REVIEW.md)执行并要求完整记录与可视化。旧版0.4.0及其3/4部分通过结论保留；本轮新证据写入 `hf4_repair_results/`，不修改旧数值账本或失败文件。

## 目标与判定

目标是保存当前绝对位移中被舍入丢失的小变形，在原模型和门槛下完成第四组，并复验新版本全部四组与独立安装。第一步只检验已存校正量的保留是否能跨过原1e-9生产目标；通过后才实施生产表示。完成本轮并不自动验证非均匀二维接触、圆柱或真实机构夹持性能。

本轮原理及误差标准沿用原HF4规范，SHA-256为 `002cd49edae3066d7283f5f98d1281e9c57a22c7bb33cd8be353674906d69067`。不改变网格、gamma、E、nu、alpha、Lr、原六目标、SF、Armijo或二分规则。原1e-9生产、1e-8外部HP、1e-9 SF内力求值、1e-10约束、1e-30精度交叉以及物理参考门槛均保持。

## 执行顺序

0. 核对存档候选、delta、模型和原SHA；alpha固定为1及1/2，对比舍入更新与高精度保留更新。所有状态以50/80位重算，按原HF4 SF和同一基态SF的Armijo判断。至少一个保留更新状态达到1e-9且域、约束、交叉检查全部通过方可继续。旧舍入状态的预期不收敛不计作实验错误。探针不能被当作正式路径接受态。
1. 第0级通过后，在独立实施规范中冻结新模块/API/schema、状态权威性、lift生成及推进规则、固定用例与误差判据。实施最小两分量内核和独立HP；验证小应变、闭合、强压缩、总J非法、两分量非零HuHu、方向导数及必要旧回归。
2. 小检查通过后，连接最小规定运动求解入口，在原第四组从零求到0.125 mm。保存两个实际数组及失败/回滚证据，不以独立解析答案初始化。
3. 首目标通过生产与HP后，冻结生产源码，运行一次第四组完整六目标路径。全接受态HP、末原目标50/80及独立标量/硬接触参考均须通过。
4. 第四组完整通过后，用同一版本重放另三组；完成新状态读回、无共享状态、断开LF的新环境重放。只在全部满足后把新版B标为完成。

第1/2级的失败须保存原因并先定位，不能继续依赖路径。完整路径的每个组合本轮限一个版本尝试；若失败，记录部分结论与后续方案，不通过隐性重试或变参数获得PASS。修复测试本身/导出工具问题须先记录与力学输入的关系；不得擦除失败账目。

## 预算、存档与图

新轮数值累计上限1800秒，进程树RSS软限4GiB，顺序执行。分配为：小探针120秒、测试360秒、第四完整路径120秒、第四HP150秒、其它三路径各120秒、其它HP300秒、独立重放180秒、图60秒。合计1650秒，剩余150秒未分配，不隐含允许重试。每个小进程最长300秒、每条路径最长120秒，实际限额取剩余预算最小值。安装耗时单列记录。

配置与输入身份在 [execution_spec.json](../hf4_repair_results/execution_spec.json) 冻结；每次启动记录调用、执行脚本哈希、进程树采样峰值、耗时、退出码和原日志。失败同样计入预算。

图至少包括固定更新对照的残差/门槛、旧新版同工况力与间隙、同模型参考误差、最终变形及未达目标标识。图来自存档数据，显示用单数组不作为新状态验收输入。失败时仍生成已达到阶段的诊断图，不外推未算状态。

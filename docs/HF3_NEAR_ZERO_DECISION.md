# HF-3 近零求值问题及等价算术修正决定

2026-09-14。先于非线性桥接，在两份真实几何的同任务K0预测位移上检查了0.2.1。输入d=1e-3/1e-4/1e-5mm及1e-9求值预算来自已冻结规范；这些状态只诊断表达式误差，不要求其满足非线性平衡。

原[预检查](../hf3_results/near_zero_v021_001/summary.json)显示：最大输入处两例误差约5–6e-10；1e-4处约5–6e-9，1e-5处约5–6e-8。小外载使几乎固定的绝对舍入误差占比增大。该证据说明当前表达式不适合本阶段最小幅值的精度要求；不意味着HF2强压缩认证被改判。

令G=grad(u)、F=I+G，delta=tr(G)+det(G)。当每积分点max|Gij|<=0.01时，改用J=1+delta及log1p(delta)，并用

`P=[mu*(G+G^T+G*G^T)+lambda*log1p(delta)*I]*F^-T`

计算材料力。它与原Piola严格数学等价，避免先加单位阵再提取微小应变以及mu*F与约mu*F^-T大项抵消。辅助S由F^-1*P恢复；实际Jacobian仍对实际残差求导，完整HuHu保持。阈值外保留0.2.1的直接F/J/P表达，以保留强压缩算术特性。

近零材料能量同样使用等价稳定式：`||G||²−2detG=(G00−G11)²+(G01+G10)²`，以及`delta−log1p(delta)`的k=2..14交错幂级数。near条件保证|delta|<=0.0202，剩余项界为|delta|^15/(15*(1−|delta|))；该项远低于binary64舍入。分支外使用原能量。分支未选中时log1p输入置零以防非法中间量污染AD，非法J仍拒绝，不截断实际J。

修正属于0.3.0，kernel标识`p26_q1_incremental_piola_huhu_v3`。几何、材料、网格、厚度、积分及正则不变。后续须在同一组已保存K0位移上复验、通过近零HP/导数及原强压缩和正常参考回归，然后才执行桥接。原0.2.1内核副本及预检查失败完整保留。

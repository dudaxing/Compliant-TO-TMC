# HF-4 第四组合停止：固定状态排查记录

2026-09-14。原始运行 `hf4_results/g1_m1_001` 在 h=0.0625 mm、gamma=1e-7 的首个非零目标停止，目标指标为 null；前三个组合已通过生产及独立 HP 验收。原规范、源码快照和失败目录保持不变。

## 观察与待验证假设

在 d=0.125 mm，生产自由残差依次从0.864降至2.166e-8、1.852e-9、1.841e-9；最后绝对自由残差约1.042e-16 N，SF约5.657e-8 N，仍高于冻结的1e-9停止要求。按既定8层二分降至d=0.00048828125 mm也未通过，残差约8.381e-9。J合法、约束误差为零、稀疏线性求解误差小；多个回溯因子的merit完全相同。

这些标量证据说明出现算术平台，还不能区分位移梯度/内力求值消去与绝对位移存储的量化误差。原日志只归档已接受零态，不能据其直接判定失败候选的 HP 平衡。

## 本次有界诊断决定（执行前记录）

在原1800秒总预算内使用尚余的preflight类别：只重现第四组合首个0→0.125目标，诊断性关闭二分（其余停止设置不改），通过外部观测包装器保存每次实际装配输入及失败候选。它是定位失败的追加短诊断，不是第五条正式接触验证路径，不覆盖或替代原失败。

在同一实际输入上做独立Decimal内力、自由平衡及生产求值误差比较；另构造独立半解析解逐节点最近binary64舍入的固定状态，观察其HP平衡。对每个单元去除常量位移后再次求值作为诊断，检查理想梯度是否保持、是否只是求值改善。该诊断不把平移后的自由度回写为原模型解，也不作为新的生产通过证据。

在结果确认前不修改本构、求解器、材料、网格、残差尺度或容差。若证据显示是状态表示精度限制，需单独设计可审计的表示改进；不能用强行增加迭代、缩步或放宽阈值宣布成功。后续记录必须区分原始失败候选、近似参考状态与任何诊断表达式。

## 固定状态取证结果

[第一诊断](../hf4_results/fixed_state_probe_001/summary.json)成功重现原首目标的失败，保存了每个实际基态位移。对最后失败候选独立核验：

| 量 | 结果（以共同SF归一化） |
|---|---:|
| 实际失败候选的 HP 自由残差 | 1.8410298639e-9 |
| 生产内力对同输入 HP 的全向量求值误差 | 7.0836150e-16 |
| 局部去平移后求值的自由残差 | 1.8410300190e-9 |
| 独立半解析位移逐节点一次舍入后的 HP 自由残差 | 1.8410298926e-9 |
| 50/80 位全内力差 | 约1.2–1.5e-42 |

因此这次平台的主因不是已实现材料力求值的精度；生产内力已经非常贴近同一保存位移的精确离散力。局部去平移的减法还产生约2.12e-17的最大理想梯度变化，因此该表达式试验不能冒充完全相同权威状态，更不能据其宣称新解。实际失败位移与一次舍入参考位移的HP结果都支持进一步调查绝对位移量化。

随后执行[第二诊断](../hf4_results/fixed_update_probe_001/summary.json)：只在保存候选上组装一次K并计算Newton校正，不运行新路径；原规范和源码不变。以alpha=1、1/2、1/16、1/65536观察更新：

- 完整校正仅改变下实体272个自由uy中的17个；该区域校正中位数约0.211 ULP，最大约0.505 ULP。
- alpha=1/2时，下实体272个自由uy全部不变；alpha=1/16时，全体595个自由DOF均逐位不变。
- 四个试探的HP残差都仍约1.84103e-9，与原来的回溯平台一致。

这些是当前Newton状态和当前单一binary64绝对位移表示上的可观察更新损失，不是“数学上不存在任何可通过的binary64位移场”的证明。尤其不能把一次舍入参考态当成最优离散舍入状态。

## 当前处理与后续界限

HF-4-A已具备接口与参考；HF-4-B记为3/4路径完成，第四组合未通过内部停止门。虽然失败候选的HP残差小于外部1e-8验收线，它仍未满足冻结的内部1e-9要求，因此不追认接受态。所有规定阈值、物理参数、内核和原失败记录保持不变。

按原停止条件不进入非均匀二维或圆柱。接下来应先设计并验证可保存微小变形分量的权威状态表示；方案见 [HF4_STATE_REPRESENTATION_PLAN.md](HF4_STATE_REPRESENTATION_PLAN.md)。本轮已完成现有结果的独立安装重放与部分结果图，以便审查三条成功路径和第四条真实失败。[独立安装记录](../hf4_results/detached/summary.json)已复现该失败及null目标语义；这不增加物理通过结论。

# HF4-C2：三项均匀对照的预先解释规则

日期：2026-09-21。本文科学解释规则在新对照结果产生前写定，不使用新路径的结果选择解释或阈值。依据 [公式审查](HF4_C2_FORMULATION_REVIEW.md)、[诊断计划](HF4_C2_DIAGNOSTIC_PLAN.md) 和 C2 v1 的科学协议；执行前的 v2、v3 修订保留相同科学内容。最终执行来源 v3 已完成只读复核；本文不授权额外算例。执行源码、准入链和隔离停止门的复核另见 [执行门审查](HF4_C2_EXECUTION_GUARD_REVIEW.md)。

本轮问题是：既定 TMC 弱式负节点反力对背景宽度、外底边驱动和网格的敏感性各有多大。允许的结论是受限任务中的可复现离散响应与敏感性；不能据此宣布一般接触物理正确、连续解收敛或进入 HF5/设计排名。

## 1. 比较对象必须先固定

全部路径使用同一实体 \([0,2]\times[0,1]\) mm、初始间隙 .25 mm、刚性矩形障碍 \([-4,6]\times[1.25,2.25]\) mm、面外厚度 1 mm；同一 P26 材料、\(E=100\) N/mm²、\(\nu=.3\)、\(\gamma=\alpha=10^{-6}\)、\(L_{ref}=2\) mm 和全域 broken-Q1 HuHu。扩大背景域不改变正则参考长度或系数。数值顶边 uy 固定，实体底边 uy=d，x=1 的底节点 ux 锚定；其他约束变化仅限下表明确一项。

|新算例，串行次序|独立改变项|主要对照|必须保持或明确承认的范围|
|---|---|---|---|
|`padding_2p5`：h=.125、padding=2.5|背景 x 域从 [−2,4] 改为 [−2.5,4.5]|已有 C1 h=.125、padding=2、整底边驱动均匀路径|h、实体、间隙、障碍、材料、Lref 和均匀位移幅度不变；背景材料总量、数值外边界位置和被驱动底边总长度随域改变。|
|`outer_free`：h=.125、padding=2|严格实体跨度外的底边 uy 从 prescribed 改为 free|同一已有 C1 h=.125 均匀路径|实体底边含 x=0、2 的节点仍规定 uy=d；严格外侧节点解除竖向约束。网格、材料、正则和 split lift 配方不变。|
|`mesh_h00625`：h=.0625、padding=2|参考网格尺寸|已有 C1 h=.125，并列已有 h=.25 均匀路径|物理域、材料、障碍、边界运动和 Lref 不变；DOF、单元数、薄层分辨率和离散应力场随 h 变化。|

不把三个新算例互相直接相减后称为单因素效应：padding 和 outer-free 的主比较分别对同一 h=.125 基线；细网格对 padding=2、整底边驱动基线。本文没有添加新 alpha/gamma、加载模式或障碍尺寸试验。

### 同一七目标，不能用相同步序替代

共同原始目标是

\[
d\in\{0, .125, .21875, .25, .28125, .375, .5\}\ \mathrm{mm}.
\]

本轮仅 `uniform_tmc`，参数 s 就是实体底面的规定平均位移 d。比较必须选取**同一已保存原始目标 d**，核对阶段、实际参数、`is_original_target` 与 `original_target_displacement`。不同路径的 accepted index 和二分步数无需相同；不能按索引配对、插值出不存在的状态，或把一个模型末态与另一个未达目标状态比较。所有中间 accepted 二分状态仍必须归档并通过审计。

本轮 uniform 的 d=0 是几何零初态。这个语义不得倒推到旧 C1 perturbation 的 s=0：后者已有 .375 mm 预载压缩。近零基线不能用微小残差作相对误差分母；已定义为零的参考量使用绝对差及明确的 `relative=null` 原因。

## 2. 先明确观察量，后看正负与大小

同一 d 下至少并列：顶节点总弱式反力及材料/正则分量、负节点数/负值和/正值和/净值、参考和当前坐标、实体及整底边平均位移、实际规定运动的共轭广义力，以及固定参考帽函数的作用量。节点最小值和负节点数必须保留，但不得成为跨网格比较的唯一指标。

符号沿用冻结审查：internal 为约束对模型的作用；on-plane 顶面力为 \(-r_y\)。材料直接边投影也整体取相同的 on-plane 符号。弱式节点力、直接材料边牵引和接触压力三个名称不可交换。

### 固定参考 PWL 帽函数

左帽函数在参考 x=−.5、−.25、0 处取值 0、1、0；右帽函数在 x=2、2.25、2.5 处取值 0、1、0，支撑外为零。每个网格都采样**同一连续参考坐标函数**，不是选取相同的节点编号，也不是围绕新的负峰重新移动或缩放帽函数。

\[
Q_\phi^{\rm weak}=\sum_{a\in\Gamma_t}\phi(X_a)(-r_{a,y})\quad[\mathrm N].
\]

它是每 1 mm 虚位移幅值的虚功；若虚幅值为 1 mm，虚功为 \(Q_\phi\times1\) mm，单位 N·mm。三个网格都与帽函数折点对齐；没有任何 h 倍率需额外乘到已装配节点力上。直接边投影对应同一 \(\phi\) 的积分，材料/正则分别记录。

帽函数固定在参考坐标，不能在结果出现后改用当前坐标帽函数再把两者称为同一试验；当前坐标必须另列，以显示实际位置。帽函数权重是比较离散泛函的测试函数，不是接触面积标签。

### 固定测试与“负节点集合”不是同一个比较

总负节点集合 \(S_-\) 由总 on-plane 节点力 <0 定义；该集合上的材料和正则贡献可相加核账。材料项自身为负的集合、正则项自身为负的集合一般不同，三者的 `negative_sum` 不能直接相加。跨网格时节点力尺度和节点数量会变，负峰减小而负节点数增多不构成逻辑矛盾，也不单独证明改善或恶化。

完整顶面所有节点单位权重的 HuHu 合力及 Jv 合力为零，是当前矩形 Q1 恒等。局部帽函数、单节点和负节点子集的正则量可非零。净力接近不等于局部场接近；全顶面正则净力为零也不等于正则对位移和材料反力没有影响。

## 3. 哪些结果支持什么判断

|若观察到的结果|可以支持的受限推断|不能支持的推断|
|---|---|---|
|扩大 padding 后，共同目标/固定帽函数量的差异可数值区分|当前有限背景域宽度及随之移动的外边界影响这些离散响应。|原 padding=2 实现错误、padding=2.5 已代表无限域，或负项“只来自边界”；一次域扩展不足以排除其他原因。|
|扩大 padding 后固定局部观察量几乎不变|在比较精度和这一次范围内，未检出该观察量对域宽的明显变化。|背景域完全无影响；整体净力、远处背景场和其他加载不必同样不敏感。|
|outer-free 后负节点/帽函数量明显改变或消失|外底边规定运动这一边界条件对结果有影响；这是改变做功边界后的新边值问题。|原驱动边界有代码错误，或释放后的模型就更符合实际装置；那需要另有物理边界依据。|
|outer-free 的整底面平均位移不等于 d|与协议允许的自由外底边响应一致，需作为观察量报告；实体底面平均位移仍应等于 d。|自动判定约束失效，或为“修复平均值”给外底边重新加位移。|
|细网格下同一帽函数/净力差值缩小、负节点量减弱|所测离散泛函在三个指定网格上的变化趋势；可描述为有限网格细化观察。|连续解已收敛、获得可信阶次或 Richardson 真值、任意接触区域均准确；三个网格不是连续收敛证明。|
|细网格下负节点数增多但总负和/帽函数量减小|离散支撑和每节点力尺度变化；需综合固定泛函判断。|仅凭负节点数量说明更糟，或仅凭峰值下降说明压力已经非负。|
|同一网格下弱节点负值与直接材料压缩共存|再次确认两种读数不同；用下面的已定义分解定位材料弱力与边投影差额。|负弱力就是负接触压力，或正材料牵引足以证明完整接触互补条件。|
|直接材料边投影/点态法向材料应力出现真实符号变化|保存材料场的边界应力状态发生变化；应核对积分/整边符号证明的适用条件。|直接判定接触失效、也不能删去负值使之成为“压力”；TMC 固定数值顶边没有一般主动集。|
|不同边界/网格下所有门通过但指标非单调|这些限定离散问题的有效观察；需要报告非单调及相同 d 的原值。|为了得到单调曲线调整门、删掉一个算例，或自动增加第四条路径。|

“边界敏感”与“实现错误”是两类命题。实现错误应有违反明确公式、协议或独立代数核账的证据；改变一个有效边值问题后解发生变化，不构成这种证据。

## 4. 负节点差额的统一分解与局部区域语义

每个通过来源/数值/几何门的保存场可按冻结 SBP helper，把材料弱式节点力分解为顶边、其他外边界、内界面跳跃和 \(-\operatorname{Div}P^I\) 的体积分；物理厚度 Simpson 边值还须带已声明的体/边权重修正。所有项采用同一符号、同一节点或同一帽函数求和，记录恒等误差。

\(P^I\) 是九个 Lobatto 材料应力样值的逐单元双二次插值，\(\operatorname{Div}P^I\) 是该插值的导数。某项主导差额，只说明这个离散分解中的量级归因；不能直接改称连续体力、真实连续应力散度或求解器残差。直接真实 \(P(F)\) 的解析边积分与 Simpson 值有区别；若扩展诊断使用解析边值，要显式加入 Simpson−解析边值差，不能使旧 SBP 公式悄悄换定义。

对平直 Q1 顶边，若 \(F_{yx}=0\)、恒定 \(F_{xx}>0\)、\(\mu>0,\lambda\ge0\)，且两端 \(F_{yy}>0,P_{yy}<0\)，可使用冻结审查的单调性证明整边材料压缩。新状态必须重新验证这些条件；不能沿用旧四末态的 144 条证明代替新状态证据。正则节点量继续作为 weak term，不人为转成唯一的边界压力。

**原实体跨度 [0,2] 是参考几何标签，不是实际接触域。** 实体会侧向变形；数值顶面的节点属于顶部第三介质边界；位于参考跨度外既不证明无物理接触，也不证明发生接触。实际几何判断仍使用当前实体几何、间隙/障碍交面积与覆盖门；这些几何门通过也不额外证明力学互补。图中同时保留参考 x 和当前 x，不用参考跨度裁掉负节点。

## 5. outer-free 的做功与反力语义

outer-free 只规定实体底面 uy=d。严格外底边 uy 是自由未知量，虽然 split `lift_shape` 在这些 DOF 仍有数值值 1，fluctuation 可以补偿；**lift 的自由分量不是位移边界条件**。真正 prescribed `direction` 仅在 fixed DOF 上非零，反力组也仅包括实际 fixed DOF。

实际驱动的共轭广义力按 \(G_d=\mathrm{direction}_{fixed}^Tr_{fixed}\) 计算。整底边驱动时，它包括整底面的规定竖向运动；outer-free 时只包括实体底面的规定运动。自由外底边不应被当作反力驱动端，也不能把 body/whole mean 的测量向量替换成同一个力共轭方向。

完整顶边净力可在同一整体平衡意义下并列，但其输入做功边界已改变。不能把 outer-free 与 driven 的净力差全归给“接触算法误差”。整底边平均位移必须报告为 observation；不得通过强制它等于 d 抹掉这一因素。相同 h 下释放前后的刚体约束仍保留，不能把正常自由边位移误判为遗漏约束。

## 6. 数值可区分性、失败和停止

模型间差异是预定观察量，没有事后新增“必须相差不足某百分比”的物理一致门。若使用误差幅度判断差异是否可由读数误差解释，必须写明所用向量误差及传播规则。例如，对已知生产−HP 力向量差 \(e_A,e_B\)，同一物理帽函数在各网格的权重向量为 \(\phi_A,\phi_B\)，有

\[
|\phi_A^Te_A-\phi_B^Te_B|
\le\|\phi_A\|_2\|e_A\|_2+\|\phi_B\|_2\|e_B\|_2.
\]

该界只控制这两个**已测向量读数差**向标量的传播。80/120 一致性和生产/HP 差额都不是连续物理误差条，不能覆盖离散偏差、迭代残差引起的解误差、边界模型不确定性或接触模型误差。零或接近零的量不输出不稳定的百分比；绝对量保留。

每条路径必须依次完成：冻结来源/实现检查、求解完整七目标、全部 accepted 状态的独立 80/120 数值和几何审计、外部进程成功回执与有效输出绑定。只有这些均满足，才可开始下一条候选。C1 的严格 residual、constraint、force/Jv、分量、cross-precision、所有单元 J>0、实体与障碍交面积、顶边当前 x 覆盖等门保持不变。

- 某条路径正常返回失败、超时、来源不匹配、缺少目标、独立审计失败或输出绑定无效：保留日志、回执、数组、已接受状态和失败原因，停止后续候选。
- 已审计有效前缀可标识为前缀观察，不能把缺失 d 补齐、把未认证数据计入正式比较，或把最后 accepted 态冒充目标态。若中断导致完整 controller/completion 缺失，当前审计器不认证此前 NPZ 的正式前缀；原数据仍保留可读，不能补写成功 completion。
- 不自动重试、不搜索参数、不放宽门、不扩大障碍、不跳过失败算例继续下一候选；本轮上限仍是三条新路径和冻结总预算。
- 失败首先说明这次冻结实现/预算/数值门下未得到可准入的完整结果。单凭失败不能断言物理模型不存在解或该因素理论错误。

这些规则同样适用于“结果看起来合理但审计失败”和“指标看起来不理想但全部门通过”：前者不能准入，后者应如实报告，不修改解释以追求预期方向。

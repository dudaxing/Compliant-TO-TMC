## 3. 第一个动作：固定更新的因果对照

从[存档校正量](../hf4_results/fixed_update_probe_001/fixed_correction.npz)读取实际 `u`、`delta`，沿用第四组合实际模型原语。首先核对输入哈希、数组形状、固定 DOF 的校正严格为零、与原失败候选的身份一致。保持 d=0.125 mm、材料、网格和边界不变，不重新计算或筛选 Newton 方向。

预先限定 alpha=1 和 1/2，分别比较：

1. 旧方式：`D(round64(u + alpha*delta))`。
2. 保留更新：`D(u) + D(alpha)*D(delta)`，在独立高精度计算中形成物理状态，不先压回一个浮点数组。

`D` 表示精确提升实际 binary64 输入。两者只有更新的舍入处理不同；共同基态、校正量、模型和载荷均来自存档。保留后的状态是新的诊断状态，不能冒充原失败状态或正式接受态。

现有 [DecimalQ1Reference.evaluate](../hf_repo/scripts/hf2_precision_reference.py) 已支持 `direction=delta, offset=alpha, derivative=False`，可完成第二种求值，无须先改生产求解器。必须取其原始 Decimal 内力重新按 HF-4 定义计算 SF：该通用参考类在零外载时自带的单位尺度不适用于这里，不能直接使用它的 `relative_residual` 字段。

每个对照保存实际输入及哈希、50/80 位结果、自由残差分子、固定反力范数、原 HF-4 SF、正 J、约束误差以及采用同一基态 SF 的 Armijo 指标。alpha 的实际乘积也须核对，不能把未存档的小量藏进解释中。

预期判别如下，执行前记录，执行后不能改线：

- 若保留更新的状态满足 `HP自由残差/SF <= 1e-9`、原约束门、正 J、固定尺度 Armijo 下降和 `50/80位差 <= 1e-30`，则支持继续开发可保存该精度的生产表示。这里采用 1e-9 是检验能否达到既有生产目标，不是把正式外部 HP 门从 1e-8 改成新标准。
- 若残差有改善但仍大于 1e-9，因果验证尚未闭合；记录改善幅度，再用独立方向作用检查 `R + K*delta` 与非线性余项，不立即扩展完整接口或反复换方向。
- 若几乎没有改善，或 J/约束/高精度交叉不通过，则暂停后续实现，重新检查方向、切线、数据身份及尺度。该结果本身也应保留。

本试验只有 HP 的更新干预，不是生产双分量求解验收，也不增加一条正式路径。新记录使用单独目录和新资源账本；不继续写入已发布的旧账本。

## 4. 对原两分量方案必须补清的实现条件

**预测器只能采用一个明确的状态转换。** 取旧状态 `(L_n,w_n)`，新 lift 为 `L_n + delta_L`。固定 fluctuation 边界为零时，直接解 `K_ff*delta_w = -(K*delta_L)_f`，令预测状态为 `(L_n+delta_L, w_n+delta_w)`。不能先做 `w <- w-delta_L` 又套用这个增量式，否则重复补偿。现有 [prescribed.py](../hf_repo/src/hf_eval/prescribed.py) 只用固定 DOF 增量构造右端，不能原样移植。小检查须把预测器的总位移方向与独立逐单元方向作用对照，包含可能出现大项抵消的 `K*delta_L`。首版不做隐式重分解；注入失败时，两数组、目标身份和切线缓存必须整体回滚。

**分开保存不等于整个求值过程都保留了精度。** 在 [tmc_kernel.py](../hf_repo/src/hf_eval/tmc_kernel.py) 中，G、F、J、材料力与 HuHu 均需要处理新表示。分别求梯度后合并、再形成 `I+G`，依然可能产生舍入；特别是介质强压缩时 F 的小分量来自较大项相消。当前细网格 gamma=1e-7 的完整路径尚未成功，不能用其它组合或首目标改善替代这一验证。

**全部求值与检查必须对应同一总状态。** NumPy 的正 J 预检查、JAX 带切线和仅残差分支、`grad(L)+grad(w)`、`H(L)+H(w)`、材料力、正则力、反力与间隙都必须对照两部分精确和。lift 在 d>g0 时自身可以具有非正 J，只检查总物理状态；总 J 为零或负的小输入仍应被正确拒绝。近零应力分支仍须使用保留小量的 G，不能从已舍入 F 反算 G。

HuHu 小检查需让两个分量的 H 均非零且部分抵消，检查总 J 的 `exp(-5J)` 与总 H 联合作用及其非对称方向导数。两部分各算正则力再相加不等于总状态的正则力。另构造精确保持物理位移的两种分解，对照材料、正则和总力，避免常量 lift 或均匀层内 HuHu 恰为零掩盖错误。

这些条件须在下一版编码前明确到接口、schema、lift 生成与目标推进规则、文件字段及测试输入。HP 重建的权威输入必须是两个实际保存数组；显示单数组不参与验收。

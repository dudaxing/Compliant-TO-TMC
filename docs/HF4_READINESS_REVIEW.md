## 1. 整体目标与本次判断

整体目标仍是建立独立正向 HF 力学评估器：只依赖 HF 仓库、独立环境和普通几何数据，在明确版本的物理任务下，输出带单位、符号、有效性状态和可复核证据的响应。最终需要分别判断数据可读性、几何资格、数值求解、模型精度与功能表现。

本次判断是：HF-3 的指定数值验收足以支持继续推进。下一步优先解决**接触合力的定义与独立验证**，从有解析参考的平面法向小基准开始，之后再引入非均匀二维接触与固定圆柱。当前证据没有给出必须重跑全部 HF-3 的理由。

选择这一顺序，是因为直接进入真实夹持器与圆柱，会同时引入工件约束、力提取、接触模型偏差、曲面离散和机构变形等因素；一旦响应异常，很难辨别原因。小基准能先建立明确的力与间隙参照，并保留对新接口的直接检查。

初步约束形式可以使用 `u = T z + u_D(d)`；自由平衡为 `Tᵀ r = 0`，规定运动的共轭力由离散残差与该运动方向的虚功确定。实现时继续使用实际 Jacobian。这里只提出最小仿射约束需求，不要求通用多体运动框架。

固定平面可以通过明确的边界身份与规定运动表达，无需用任意放大的弹性模量伪装刚体。现有材料内核先保持不变；是否需要进一步修改，必须由新基准证据决定。

## 4. 首个基准：两块平行实体与均匀初始间隙

建议采用两块同材料的平行弹性块，参考高度为 `H1`、`H2`，宽度 `W`，厚度 `t`，初始间隙 `g0`。材料界面与网格对齐。各点横向位移受限，顶端固定，底端以均匀规定法向位移 `d` 向顶端运动。几何、厚度和边界条件作为独立的合成验证任务，不从真实机构参数偷偷继承。

这个问题需要两个用途不同的独立参考。

### 4.1 同一 TMC 模型的半解析参考：检查实现与测力

下面是基于当前材料能量、在上述受限均匀变形假设下的自行推导，不是将论文算例输出当作真值。

取三维平面应变变形梯度 `F = diag(1, s, 1)`，`s > 0`。第一 Lamé 参数记为 `lambda`，剪切模量为 `mu`。材料能量和正压缩名义应力为：

```text
Psi(s) = lambda/2 * log(s)^2 + mu/2 * (s^2 - 1 - 2*log(s))
p(s) = -dPsi/ds = mu*(1/s - s) - lambda*log(s)/s
```

若间隙材料的两个 Lamé 参数均为实体的 `gamma` 倍，令 `H = H1 + H2`，实体和间隙法向伸长比分别为 `s_s`、`s_v`，则：

```text
H*s_s + g0*s_v = H + g0 - d
p(s_s) = gamma*p(s_v)
s_s > 0, s_v > 0
F_TMC = W*t*p(s_s)
gap_TMC = g0*s_v
```

参考程序应独立求解该标量关系，不调用生产有限元、JAX 材料例程或装配器。它比较的是**同一个有限 gamma 模型**的力、剩余间隙和伸长比，用于检验边界、实现、测力符号与单位。

### 4.2 理想单边硬接触参考：度量模型偏差

同样的实体和外边界，在无黏附、理想法向硬接触条件下：

```text
0 <= d <= g0:
    F_hard = 0
    gap_hard = g0 - d
g0 < d < g0 + H:
    s = 1 - (d - g0)/H
    F_hard = W*t*p(s)
    gap_hard = 0
```

这里的差异用于度量 TMC 对理想接触的近似偏差，不是生产程序自身残差，也不是实验材料验证。有限刚度第三介质会在几何闭合前传递非零力，因此不能把“首次非零力”当作严格接触起点。这一模型性质见 [Frederiksen 等 2026 年论文](https://link.springer.com/article/10.1007/s00158-026-04341-7)。

### 4.3 这个基准的明确局限

均匀分层解在各单元内是仿射位移，`Hu = 0`，相应 HuHu 正则残差为零。因此，该基准能够直接检查法向材料响应、约束、映射与力提取，却不能验证非均匀二维接触中的正则影响、滑移表现或圆柱曲面离散。此处整数细化主要检查映射与装配一致性，不足以宣称一般接触网格收敛。

## 5. 合力验收必须先明确的内容

1. **对象与方向。** 每个测力组记录所属物体、边界侧、自由度集合、参考法向和单位。区分驱动器作用于模型的力、模型作用于压板/工件的力、单侧力和有符号净力。
2. **虚功定义。** 在 `r = fint - f_applied` 的约定下，规定自由度上的残差是维持该运动所需的约束力；模型对该约束装置的共轭力取相反号。运动选择向量必须对应已定义的单位规定运动，不能用任意节点截面替代。
3. **三路核对。** 比较指定边界反力、同一运动定义下的虚功合力、独立参考 `W*t*p`。另检查整体平衡及规定值误差。前两者的一致性检查算子实现，第三者提供独立力学参照。
4. **完整残差与分量。** 非均匀问题的总力须与实际材料及 HuHu 残差一致，并单独保留分量。不能从材料能量导数冒充完整非保守模型的合力。
5. **倍率与含义。** 半模型不自动乘 2；对称夹持时工件净力接近零也不能解释为没有夹持作用。正式单爪力与两爪向内合力在后续任务中分别定义。

A 阶段可以独立于正式圆柱参数推进。C 阶段参考方法的具体选择需要单独核查与冻结；本文不声称该参考已经建立。二维参考自身也必须有验证及精度说明，不能把另一个软件的收敛状态直接当作真值。

首轮计算规模可考虑 **1 个合成几何、2 个整数细化层次、2 个事先指定的 gamma、约 6 个输入目标**，最多 4 条短路径。这只是有界试验的建议，不是已冻结任务；具体尺寸、目标、gamma、误差阈值及资源预算需在计算前写入计划。此均匀基准不以扫描 alpha 为验证内容。

后续细化须保持物理尺寸、原点、边界与材料界面一致；真实几何子单元继承原始材料，几何身份与网格身份分别记录。端口权重从同一物理区域重新计算。模型中的物理特征长度 `Lr` 不随网格单元尺寸自动变化。相关约定见[数据契约草案](DATA_CONTRACT_DRAFT.md)，实际执行以对应冻结版本为准。

## 7. 计算前必须冻结的规范与停止条件

- 分开规定：自由平衡和约束误差、独立算术求值预算、FE 对同模型半解析参考误差、TMC 对理想接触的力/间隙偏差。HF-3 的残差阈值或初始模型偏差标志不能直接充当接触精度容差。
- 零力或近闭合区域使用有物理量纲的绝对误差与明确的尺度下限；不能除以零参考力。保存原始误差分子、尺度和有量纲结果。非零规定运动引入的反力尺度须同步纳入生产与 HP 检查。
- 任务参数、输入路径、状态输出、最大二分/试探次数、墙钟与内存预算在运行前固定；保留所有失败。正式候选共享同一任务，不逐候选调 gamma、alpha 或工件位置。
- 若公式/单位/符号不一致，或规定运动、独立同模型参考、HP、正 J、资源检查失败，先定位该问题，再决定是否修改代码或计划；不进入更复杂算例。
- 若实现检查通过但 TMC 对理想接触偏差超出预设范围，记录为模型适用性问题，开展有界分析。不得通过事后放宽阈值宣布通过，也不将其误记为既有 HF-3 数值验收失效。

## 复审依据与冻结边界

本轮用户授权是在深入检查现有代码、证据与修正计划后执行问题排查，条件式
完成 HF-2 修正，先于 HF-3。原 0.2.0 已知的三个失败状态为 Python λ=0.73、
MATLAB λ=0.76 与0.99；原浮点停止值通过，但其50位独立自由残差超过1e-8。
两种数学等价力表达的取证将问题定位到病态 C=FᵀF 的 det(C) 消去。

[独立数学复审](HF2_REPAIR_REVIEW_INDEPENDENT.md)提出了稳定第一Piola表达、
实际HuHu切线、高精度参考起点、精度预算及新旧版本判定的区分。最终采用的
计算前定义以[机读精度规范](../hf_repo/validation/hf2_repair/precision_spec.json)
为准，SHA-256 为 `ba4909b19d369890b79af8db8dfa58b01672e904fe68e8dc3175c408e23ad663`。
原 HF-2 规范及外部容差保持原样；其哈希为
`5e09dc712a1d1f1eec2adcf9ce230eeeae023c065791815527f8e46c03ca4971`。

冻结的关键要求是：新 C-shape 内部停止1e-9、独立外部自由残差1e-8；生产
内力与高精度内力的**向量差**，按相同外载范数归一化，全/自由DOF均≤1e-9。
高精度从实际binary64位移、算子、权重、材料系数、连接与外载开始精确提升，
重新计算F、J、log/exp、积分、装配和残差，不能只提升已舍入的F/J或单元力。

这组内部裕量和评估预算在新路径前冻结；不是看到修正结果后放宽停止条件。
若两个1e-9预算均成立，三角不等式提供外部1e-8以内的余量，但仍须逐目标
直接计算并验收高精度残差，不能仅据理论余量推断通过。

## 实际改动及版本

新版本为0.2.1，内核标识 `p26_q1_direct_piola_huhu_v2`，C-shape求解配置为
`hf2_precision_v2`。完整新路径绑定的运行源码哈希是
`3eeee09c781fc1509d54156bf696f0dd6ed5e2e52df1a19bbbacc59338dfe3b1`。

材料内力改为直接计算
`P=μF+(λlog(J)−μ)F⁻ᵀ`；二维F⁻ᵀ由F的余子式除以J形成，避免先构造
det(C)再求P。辅助第二Piola应力也改为由F的逆构造C⁻¹，不再采用原det(C)
相减的分母。材料能量仍按原表达及全部积分权重计算。

HuHu残差及exp(−5J)完全保留，kr仍按固定物理域宽和实体参数计算且不再乘
材料倍率。JAX继续对**新的实际总残差**求非对称一致Jacobian，包括正则项
随J变化的导数；没有沿用旧切线、对称化或使用替代总能量Hessian。

内部1e-9仅写入C-shape新配置，通用Newton默认容差未被暗改。增量、回溯、
二分上限和原物理/离散配置保持原样。每个接受目标新增生产内力存档；model
文件新增实际grad/Hessian/weights/λe/μe/kr，便于独立高精度复算。稀疏解
另存线性残差与范数后向误差作诊断。源码明确将“原实现停止判据接受”与
“独立精度认证”分开。

# 最小承载验证前置规格：导向刚体牵引探针

2026-10-22，L-CTIPLOADSPEC1。规格与接口核查，**尚未实现或执行新物理任务**。参照 main `8d589b65ab2e4efe8ca01b95034ed329fca81171`。本规格区分近期可验证的接口功能与最终要回答的承载问题。

## 目标与本次选择

整体目标仍是：HF 独立读取 LF 几何，可靠计算大变形／TMC 响应，最终判断夹持器对工件的作用、承载与释放。已有代码完成固定工件的加载／卸载及选定态独立参考，但固定工件反力不能证明可动工件承载。

最近先增加一个功能：**夹持器输入保持 1.06 mm，圆形工件由外部导向夹具沿 +x 刚体移动，读取驱动反力—位移响应。** 选择位移控制，是为了先验证工件运动、反力和两套控制量，不把脱开后的无静力平衡误判成释放。随后才选择指定外载的力控制任务。

|项目|近期探针规格|
|---|---|
|机构输入|原 input 端口平均位移恒为 `d_hold=1.06 mm`，不是固定各输入节点|
|工件运动|全部原工件节点共同 `u_x=q`、`u_y=0`；转角为零；导向夹具可提供竖向反力／约束矩|
|控制|独立指定工件 `q`；机构反力 `R_input` 与工件驱动反力 `Q_drive` 分别求出|

|独立工件外力|近期探针不同时施加已知工件外力；`Q_drive` 是输出，不是给定载荷|
|物理参照|α=2.5e−7、γ=1e−6、r=9 mm、圆心(80,40) mm、right=92 mm、Lr=80 mm；E=1 MPa、ν=0.3、平面应变、厚度20 mm、h=0.5 mm，其余原条件保持|
|性质|有导向夹具的运动探针；不是自由工件试验，不认证承载极限、摩擦、释放或稳定性|

## 刚体、域与状态的合同

工件仍使用原510单元／565节点的成员集合。它是原 passive_void 上的运动学覆盖；只解除节点固定会得到可变形介质，不能当刚体。随 q 移动时不得重新按新圆心选择单元、改变材料标签或删去原 interior／cut 节点。

原解析圆最右89 mm距参考域右界92 mm名义为3 mm。普通描述文件未绑定实际阶梯边界 xmax。由已核源码的“单元中心入圆”和 Q1 h_x=0.5 mm，可保守推出参考工件节点 `x≤89.25 mm`；候选 q=0.025 后 `x≤89.275 mm`，距参考 x=92 至少2.725 mm。**这是源码规则的几何上界，既不是保存态实测 xmax，也不是变形后介质间距、允许行程或域独立性证明。** 后续真实运行须从获准几何读取绑定实际 bbox、节点／单元身份和边界 DOF，若与此合同不符，停止该任务而非扩大域或改工件。

x=92 没有独立右侧夹紧条件，右上端点的 uy 来自 y=40 背景对称，不能把右域界画成固定墙。有限右侧介质会随工件／机构变化；其最小 J、Hu、实际边界距离须与反力一起观察。原非零 γ 介质能传递作用，Hu 也保留；这些不能改名为 Coulomb 摩擦或纯接触压力。

允许从原 α=2.5e−7、loading 1.06 mm、accepted12／global12 峰值提取初猜的**未来显式迁移**，不允许用现有 `extend_path` 改物理任务。迁移须核同一几何、节点、材料、边界、split lift／fluctuation、来源 SHA，并在新合同 q=0 做新的力／切线和平衡检查。q=0 约束与旧固定峰相同，初猜应直接满足原门；若不满足则报初始态不平衡，不能暗中修正、重放旧加载或继承旧 HP 资格。原矩阵不迁移。初猜迁移功能尚未实现。

## 半模型、单位和符号

沿 +x 平移与 y=40 镜像相容，上下半具有同一 q。所有力以已计入20 mm厚度的 **N** 报告，不再乘20。以下公式是任务定义，不是本轮新增数值结果。令 B 为全部原下半工件节点，`f_int` 为原总内力残差，`F_on` 为介质／机构作用于工件的弱式合力。

|量|下半模型|完整对称装配|
|---|---|---|
|工件位移|q|q，不倍增|
|作用于工件的轴向力|`F_on,x^half = −Σ_B f_int,x`|`F_on,x^full = 2 F_on,x^half`|
|位移探针驱动力（无另加外载）|`Q_drive^half = Σ_B f_int,x = −F_on,x^half`|`Q_drive^full = 2 Q_drive^half`|
|以后给定的完整装配外载 P|半模型施加 `P_half=P_full/2`|外载输入明确标为 P_full，换算只做一次|
|以后力控平衡|`Σ_B f_int,x − P_half = 0`|`2 F_on,x^half + P_full = 0`|

q 为 +x 时，Q>0 表示驱动需克服总作用，Q<0 表示需制动；保留符号，不取绝对值或截零。保存 q=0 的有符号原始预载，同时可报告 `Q(q)−Q(0)` 的有符号增量，不强制起点归零。材料／Hu 的 ON-body 分量分别保存，总量使用原 total；不能将整个 support 反力再次加上 body 驱动而重复计数。

反力账本采用互斥 DOF 分区：工件 ux 为探针驱动，工件 uy 为导向反力，其余原固定 DOF 为其余支撑。工件 uy 与 y=40 对称 DOF 的交集只计一次。完整账本包括机构输入、探针、导向、其余支撑和已有显式外作用。新任务若报告矩，原点明确为实际刚体中心 `(80+q,40) mm`，使用新实际位置并保留有符号 `r_x F_y−r_y F_x`；不平移或覆盖旧报告的原矩。导向可提供约束矩，不能称为自由工件的力矩平衡证明；原下半矩不直接乘2套成完整矩。

当前 `2|Fy|` 不是轴向承载力。一般竖移、转动、偏心载荷和重力不自动满足本半模型合同，须另立完整模型或明确相容的对称任务。

## 数学与最小实现边界

近期采用给定 q 的消元，**不引入第二平均约束或通用 MPC 框架**：

`u=L(q)+w`；B 的 ux 分量 `L=q,w=0`，B 的 uy 分量 `L=w=0`，其余零支撑保持零。未知量仍是非 body 自由波动与一个 `R_input`。

`r_F=[f_int(L(q),w)−b_in R_input]_F=0`；`b_inᵀu−d_hold=0`。

Newton 使用原非对称残差 Jacobian 与一般稀疏 LU：`[[K_FF,−b_F],[b_Fᵀ,0]]`。q 预测步的右端为 `[-(K ΔL)_F,−b_inᵀΔL]`；不能沿用原输入随 s 增加的平均位移右端。本任务 body 与 input 不相交，第二项为零。残差归一化保持 d_hold 与原 force floor，不能因 q 很小或 q=0 改用 q 缩放而改变验收强度。

保留现有力核、切线和 split 两数组状态；`u_display` 仅显示。新增 opt-in 控制应明确区分“零支撑”和“移动 prescribed body”，不能普遍删除原 fixed lift 非零保护。body 与机构端口／支撑冲突须拒绝，只有已声明的 body-uy／背景对称重叠可去重。工件逐节点残差是约束力输出，不应错误要求其为零。

以后若改力控制，q 才成为未知刚体坐标，需 `u=u_c+Pz`、`Pᵀr` 与 `PᵀKP`，body-x 列为每节点1，不能用节点平均系数代替广义力求和。不得同时给 q 和外载又把它们都称独立控制。本次不实现该分支。

|后续小模型功能通过|下述有界验证全部满足；默认路径保持，刚体 q 与 d_hold 解耦，驱动／导向／支撑不重复，迁移显式|具备受限探针功能|

|探针物理观察|描述有符号 Q、原始预载／增量、material/Hu、尖端关系、右介质 J／Hu／距离；可出现阻抗、助推或混合分段|观察到指定导向运动的总响应；不以 Q>0 直接授夹持资格|
|指定外载承载通过|未来必须先指定 P_full、允许 q／转角、保持路径、约束／介质贡献与保留几何判据，再解真正力控平衡并检查相应状态|当前未定义、未实现，暂不能作此判定|
|释放／稳定性通过|须另定义脱开几何、剩余介质作用、自由度与静／动态处理；切线非对称，不能用能量极小或对称特征值替代|当前不授予|

真实任务继续使用原参照设置：relative residual≤1e−9；平均位移误差≤`1e−10×max(|d_hold|,1e−6 mm)`；有限且 J>0；原 Armijo／回溯、max_checks、max_backtracks、max_bisections 与真实 minimum_increment=0.00625 mm 保持。数值设置最终从原归档绑定，不把通用类默认 minimum_increment 误当原真实任务设置。

原研究包装的 global force balance≤1e−6 和 fixed split≤8e−11 mm 不是 `evaluate_native` 自动强制的所有门，后续包装须显式核验并保留出处。运动后分别核零支撑位移与 `max_B|u_x−q|, max_B|u_y|≤8e−11 mm`，不再要求 body ux≈0。导向刚体由节点精确消元构造并核各节点；其形状不以一个平均 q 门代替。全局力门使用上述互斥账本。HP 的原15门属于另行独立参考，不声称每次探针都已完成15门。

首个终端错误、资源上限或几何／来源冲突都停止并保留真实 partial；非收敛、零模、低 J 或负 Q 均不能标为“已释放”。原内部回溯／二分与外部重试分开。不得为通过而改 α／γ／域、补更小 minimum_increment 或延长窗口。

## 输出与后续顺序

真实探针应输出每接受态的 q、d_hold 实测、两种反力、ON-body 三力、互斥支撑账本、刚体约束误差、最小 J／Hu 定位、右侧实际边界距离及收敛／时间／失败记录。图像至少包含实际×1机构与移动工件、局部尖端／右介质、Q—q（有符号原值和有符号增量分开）、R_input及收敛图／实际帧动画。禁止用固定旧坐标或重新栅格化后的图代替工件真实运动。

1. **L-CTIPMOVE1 最小实现与小模型验证（下一阶段）**：新增显式 opt-in 的 prescribed-body 探针入口、独立路径／反力记录、显式初猜 admission；尽量复用原 controller 与核，不复制整套求解器。仅验证小模型，不运行真实圆形路径，不安装为默认固定工件入口。
2. **L-CTIPPROBE1 首个真实探针（能力通过后再准备）**：绑定真实 bbox／DOF／来源，在新 q=0 合同下复核峰值，再仅推进到 q=0.025，观察变形、反力、右介质与收敛。参数、资源和实际包装另作有界执行卡；不在本轮启动。
3. **根据结果决定物理对照**：若探针可用，再做匹配的未夹持／低输入对照来识别背景介质作用；对照差仍不自动是纯接触力。再依据曲线与应用要求选 P_full、允许位移等，提出真正力控制承载；必要时单独研究域效应、自由释放或稳定性。不机械重复降低 α 或补 HP。

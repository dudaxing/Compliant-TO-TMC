## 3. 稳定 F：候选与无求解验证

### 3.1 候选内核（上一位开发者实现，本次未改）

`hf_eval/compensated_kinematics.py` 与 `hf_eval/split_kernel_compensated.py`（`p26_q1_split_compensated_dot2_v1`）：

- F 与 G 由补偿内积求出（Dekker TwoProduct + Knuth TwoSum 的 Dot2；单位项与乘积高低位进同一累加器）。F 与 G 分开求值，G 不含单位项。
- 自定义 JVP 给出精确仿射表达式的导数，不对舍入补偿量求导。
- 每次编译显式使用严格 CPU 选项（`xla_cpu_enable_fast_math=False`、`xla_cpu_ftz=False`），并插入优化屏障。
- 非零操作数范围为 [2⁻⁴⁰⁰, 2⁴⁰⁰]，超出直接拒绝，不回退旧算法。
- 弱式、材料分支、HuHu 与非对称切线与旧内核相同；旧内核保持原样。

**制造场。**
- 30／33 通过全部检查。
- 能区分新旧实现的是非二进制网格上的两个强压缩场：
  - `nondyadic_rect / compression`（J ≈ 7.6e-6）：候选 `2.5e-16`，旧内核 `1.33e-11`（不过）。
  - `nondyadic_rect / compression_hu`：候选 `1.6e-16`，旧内核 `1.37e-11`（不过）。
  - 两者的 J 绝对误差分别为候选 `3.4e-22`／`7.8e-22`、旧内核 `6.7e-17`／`1.2e-16`。
  - 这正是 C2 细网格失败的机制：强压缩背景单元里 F 的小分量由 O(1) 项相减得到。
  - 二进制尺寸网格上的同类场新旧内核都精确，因为那里的算子与输入乘积都是可精确表示的。
- 候选在全部非零精确分量上的运动学误差：F ≤ 0.49 ulp，G ≤ 0.5 ulp，J ≤ 0.92 ulp。
- 近刚体转动场 `near_rotation` 在三组网格上都只有力检查不过：
  - 总力误差与 SF 下限之比为 `1.3e-8` 至 `7.6e-8`；由于参考范数本身只有约 1e-14，分量相对误差约为 1。
  - 新旧内核的误差逐位相同，Jv 与运动学检查全部通过。
  - 这与修订 001 事先写下的分析一致：刚体转动的精确内力只有约 1e-14 N，而任何 binary64 实现求 μF − μF⁻ᵀ 的误差也在这个量级，远高于 1.25e-7 × 1e-11。按规则如实记为制造场阶段未全部通过；是否为今后的制造场改用与材料刚度相关的 SF 下限，另行决定，不回改本次结果。
- 一个小观察：在极端压缩场（J ≈ 7.6e-6）上，候选的"残差直接 JVP"与独立 Jv 相差 `6.5e-13`，组装切线乘向量 K·v 则为 `1.6e-16`。两者都在 `1e-10` 门内；保存态上两者都约为 1e-16。

**切线的独立佐证。** 有限差分曲线保留全部 5 个预定步长。以非二进制压缩场为例，独立 Decimal 中心差分对解析 HP Jv 的相对差依次为 `5.8e-5 → 3.6e-6 → 2.3e-7 → 1.4e-8 → 8.9e-10`，步长每缩为 1/4，差约缩为 1/16，是二阶收敛。binary64 差分在最小步长处受舍入限制（`1.4e-7`）。这些曲线只作诊断，不按步长挑选通过。

**编译证据。** 严格编译选项被接受。StableHLO 中每个分支有 1608 处优化屏障，优化后 HLO 中有 8 处；文本计数本身不构成精度证明，证明来自数值：编译后的候选 F 在 0.5 ulp 内，且与 NumPy 实现逐位相同（算术测试）。

**成本。** 细网格末态（1920 个单元、4074 个自由度）上一次组装的中位耗时：
- 旧内核：仅力 9.1 ms，含切线 19.7 ms。
- 候选：仅力 72.5 ms，含切线 102 ms；首次调用含编译约 0.8–1.1 s。

相对于每个 Newton 步的稀疏分解，这一增量预计很小；实际路径成本要在补测中测量。

### 3.4 这不等于什么

- 没有求解新路径，也不构成路径准入；细网格路径仍按原判定为 `NOT_PASS`。
- 固定态精度不能直接推到完整路径（Newton 历程、插入态、步长控制都可能不同），也不能推到其他平台。
- 运动学修复不涉及网格收敛、接触物理、材料或边界；C2 已观察到的边界敏感性与远端材料拉应力照旧保留。

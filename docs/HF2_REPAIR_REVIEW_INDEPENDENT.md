# HF-2 修正的独立数学与验收复审

2026-09-13。本文件基于现有源码、修正提案、100 目标对账和三个存档态的
50 位 Decimal 证据进行只读审阅。此次未运行数值求解、未修改生产源码。
以下是**计算前建议冻结的要求**；不是新算例已经通过的结果。当前用户授权
覆盖排查并条件式闭合 HF-2 修正，不覆盖 HF-3。

## 1. 已定位问题和修正边界

原 0.2.0 材料内力先构造 C=FᵀF，再以
`det(C)=C11*C22-C12²` 形成 C⁻¹，随后计算 S 和 P=F*S。三个已存状态的
最大 cond(C) 达 1.18e8、1.45e8、4.28e8；50 位算术确认其相对自由残差仍为
1.06444512e-8、1.07513900e-8、1.04443527e-8。现有证据支持修正浮点求值
方式，不能把旧状态改成通过，也不能把它解释为改变材料模型的依据。

建议新的材料残差直接采用

`P = μF + a F⁻ᵀ,  a = λ log(J) − μ,  J=det(F)>0`。

二维 F⁻ᵀ直接由 F 的余子式除以 J 构造，避免为了求 P 再形成病态 C 的
行列式。J 本身仍可能存在消去，因此“直接 Piola”不是自动通过的证明；
必须把从 u/算子到 J 再到全局力的整个链条纳入独立精度核验。

输出辅助 S 也应避免旧 det(C) 分母，例如先由 F 得 F⁻¹，再用
`C⁻¹=F⁻¹F⁻ᵀ` 与原 S 公式。即使 S 不参与新内力，旧不稳定输出仍可能误导
诊断或触发全输出 finite 守卫。材料能量继续为正确积分的原 Neo-Hookean
能量；没有 HuHu 保守总能量的声明。

网格、全部单元/自由度、厚度因子、λ/μ 材料倍率、kr 的域宽定义、九点积分、
HuHu 的全域作用和 exp(−5J) 均不改变。特别是 kr 不补乘 γ。

## 2. 实际一致切线的独立核对式

令方向位移 v 导致 D=Grad(v)，A=F⁻ᵀ，s=tr(F⁻¹D)。材料方向导数为

`δP = μD + λs A − (λlog(J)−μ) A Dᵀ A`。

这是新直接 Piola 的解析导数，可作为高精度 JVP 参考；JAX 应对新的实际
残差求导。不能通过沿用旧切线、对称化或使用替代总能量 Hessian 来完成修正。

对 Q1 单元令 B=HᵀH、I(u)=Σq wq exp(−5Jq)，原正则残差为
`rreg=kr I(u) B u`，其方向导数必须包含两项：

`δrreg = kr [ I(u) Bv − 5(Σq wq exp(−5Jq) δJq) Bu ]`，

其中 `δJq=cof(Fq):Dq`。H 中 xy 和 yx 都计入，不能丢掉其因子 2。
第二项一般不对称。建议对材料、正则化、总力的 JVP 分别检查，避免实体材料
的大切线掩盖漏掉的正则导数。

## 3. 高精度参考要从哪里开始

高精度验证应明确认证“固定离散输入的算术评估”，不混同解析连续体精度。

1. 保存并散列实际使用的 binary64 u、grad、H、weights、λe、μe、kr、连接表、
   λload 和 F0；另用独立预设构造核对这些算子的定义、单位和索引。不能仅因
   精确提升了错误算子，就宣称物理/离散定义正确。
2. 从这些原始 binary64 值精确提升至 Decimal，再高精度计算 F、J、log/exp、
   积分、单元力、全局散加、外载和残差范数。不能先在 float64 中计算 F/J/P
   或单元力，再只高精度相加；后者漏掉了当前最重要的误差来源。
3. 高精度参考使用明确的双层循环和独立连接映射，不调用 JAX 残差/雅可比，
   也不调用生产 sparse/bincount 装配器。保留全力向量，不能只比较两个残差
   范数：它们接近并不意味着残差向量接近。
4. 保存逐积分点 J 误差、最差位置、F/C 条件量，以及单元力和装配误差分解。
   可把“float64 单元力提升后高精度散加”作为装配诊断，和从原始 u 全程高
   精度得到的内力分开。前者不能替代后者。
5. 建议所有新接受原目标和额外子步都进行 50 位复核；至少所有 100 个原目标
   必须覆盖。预算内可预先固定 50/80 位双精度层重算，要求两层全力/自由力
   向量差除以外载尺度≤1e-12。若选择只对预定子集做精度层收敛，须提前列出
   子集与理由，不能在看到全部结果后挑选通过的点。

第 5 项的不同精度重复是参考算术可靠性检查；仍不能替代第 1–4 项的独立
公式、输入与索引核对。当前诊断脚本只覆盖三个旧态，不是新路径的全目标验收器。

## 4. 建议冻结的误差预算

对非零原 C-shape 目标保持 `S_F=||λload F0||₂`，不得换成大的内部单元力
范数稀释残差。λload=0 的接口测试另用既有显式非零尺度，不能除零。

| 量 | 建议要求 | 含义 |
|---|---|---|
| 新求解器内部停止 | `||r64,free||/S_F <= 1e-9` | 修正版本的内部裕量，写入 solver 标识 |
| 独立外部平衡 | `||rHP,free||/S_F <= 1e-8` | 原外部判据不变，全部新目标验收 |
| 全过程评估误差 | `||Fint64−FintHP||_free/S_F <= 1e-9`，全向量也同报同限 | 外部允许残差的 10%，检查向量差 |
| 两个执行分支的一致性 | `||R(tangent=True)−R(tangent=False)||_free/S_F <= 1e-10` | 避免基点/回溯使用不同浮点力而制造下降 |
| 高精度参考层收敛 | `||Fint50−Fint80||_free/all / S_F <= 1e-12` | 比总评估预算严格 1000 倍 |
| 局部 J 精度 | 所有 q 的 HP J>0；`max |J64−JHP|/JHP <=1e-8` | 避免全场范数掩盖最小 J 的误差 |

以上新预算须在任何新修正结果出现前确认并机读冻结。若内部残差≤1e-9且
全过程向量误差≤1e-9，则三角不等式给出外部残差≤约2e-9，加上已记录的
外载浮点误差，距离1e-8仍有裕量；这解释内部1e-9的理由。**即使理论预算
成立，也逐目标计算外部残差并实际验收，不能只用这个上界推断全路径通过。**

若预算失败，应定位输入/J、材料/正则评估、积分或装配中的贡献；不能直接
调大外部容差。不同装配顺序、补偿求和或稳定 J 表达只能作为明确版本的后续
修正，不在见到结果后悄悄更改参考口径。

## 5. 强压缩导数样本应怎样预定

保留原 16 小状态、正常范围 FD 曲线及既有容差。另固定三个旧存档态
Python 0.73、MATLAB 0.76/0.99，不能借替换旧位移让其“更好验证”。建议：

- 每个旧态取已存 J 最小的单元作为局部强压缩样本，索引及位移在修正前即
  归档；对其全部八个局部方向做高精度解析材料/正则/总 JVP 与 JAX 比较。
- 全局仍用 sin/cos(一基 DOF 序号)，固定 DOF 分量置零后归一化，物理方向
  长度取 sqrt(hx*hy)。对三个完整旧态各检查两条方向，避免构造3906²的高精度
  稠密矩阵；用逐元素 JVP 后独立散加。
- 新强压缩 JVP 可拟定相对容差1e-8，分母为参考 JVP 范数与原同量纲尺度
  下限的较大值；材料和正则分量分别按各自原尺度，不用实体尺度压小正则误差。
- FD 步长通过**只依赖输入 kinematics 的预定规则**确定，不能要求这些 J≈1e-4
  的旧态满足普通样本 J≥0.4。由 `J(h)=J0+h a+h² b` 构造对称安全步长，使
  所有 q 满足 `|h a|+h²|b|<=J0/4`；取不大于该界且不大于1e-2的最大十进制
  幂作为 h0，再固定 h0×[1,1e-1,1e-2,1e-3,1e-4]。保存所有±扰动的实际 J。
- 强压缩 FD 作为曲线证据，主要导数门槛由独立高精度解析 JVP 提供。若要求
  FD 也作门控，须先固定误差阈值和平台规则，不能看见舍入平台后才豁免；可
  在高精度中做中心差分隔离截断误差，再与解析 JVP 核对。

高精度解析 JVP应包含第2节全部HuHu项；只对材料能量做差分不足以验证此模型。

## 6. 新版本闭合与旧参考失败并存

现有修正计划有一处事实错误：“原MATLAB三个历史状态”应改为
**原Python一处、原MATLAB两处**。所有旧路径、0.2.0 wheel、原判定和三点
证据保持原样。新版本不需要把原 MATLAB 两处旧态改成平衡状态才能完成修正。

新Python闭合应同时具备：正常/强压缩导数和评估精度预算通过；新版本唯一
受限路径到达100个原目标；全部新目标的HP平衡、J、固定DOF、合力、反力与
材料分域能量通过；和旧MATLAB的原七项响应对账容差继续通过；干净环境重放
与HF-1回归通过。旧MATLAB仅继续作**版本响应参考**，其存档残差失败不能作为
新Python是否通过的强制否决项，也不能被覆盖成通过。

因此最终记录应至少分别列出：旧HF-2运行状态=`partially_complete`、旧MATLAB
严格平衡=`historical_fail`、新Python严格验证状态、修正闭合状态、源码响应
一致性状态。若新路径闭合，可更新“当前HF-2修正已闭合”，并保留历史失败。
不要让沿用旧对账脚本的 `both_sides_valid` 总门把新Python的正确结果永久卡住；
也不要只删除旧方失败标志而不另写这组明确的状态字段。

闭合本修正仅能解除HF-3前置条件，**不自动授权HF-3**，不进入真实两几何的
非线性试点，不产生接触物理精度、稳定性或排名结论。新实现、路径、高精度
原始数组与验证规范必须有独立版本和哈希，禁止改写旧输出目录。

## 1. 这一阶段要回答的问题

HF-1 已验证几何搬迁、端口映射和去空区实体线性诊断，见 [HF1_REPORT.md](HF1_REPORT.md)。HF-2 的原 MATLAB 与 Python C 形单次路径均已到达 100/100 目标、λ=1；原参考终态最小 J 约为 4.85×10⁻⁵，原始证据见 [reference_summary.json](../reference_validation/matlab/reference_summary.json)。这些存档说明路径达到终点及指定源代码的实现对账结果；严格平衡复核与当前阶段状态以上述进入条件和HF-2最终报告为准，不能从存档的收敛标记推导HF-2全部验收通过。它们也没有验证独立接触精度、项目材料、稳定性或真实机构的性能。

## 4. 平均位移控制和半模型指标

从几何物理线段构造 b_in、b_out，原生网格权重均为 [1/4,1/2,1/4]，方向固定在参考构形。施加的是 `b_inᵀu=d`，端口局部变形自由度保留。反向器输出方向 −x，夹持器输出方向 +y。

实际平衡方程为 `Fint(u)+k_out b_out(b_outᵀu)−b_in R_in=0`，加平均约束组成增广系统。Newton 使用实际残差 Jacobian，包含秩一输出弹簧项；不把端口三个节点刚性绑定，不逐节点安装三个独立弹簧，不对称化整个增广矩阵。

R_in 为执行器对结构的广义力，结构对执行器为 −R_in；输出弹簧对结构的广义力为 −k_out q_out。每步记录 q_in、q_out、R_in 和实际约束误差。力与能量首先报告下半模型量，不统一乘 2。夹持器可另列理想镜像假设下的闭合量 `2q_out`，明确这是几何运动量，不是夹持力或工件接触结果。

自由力残差与平均位移约束有不同量纲，不能直接拼接后取未缩放的范数。建议先构造满足本目标平均位移的可行预测点，之后 Newton 位移修正满足 `b_inᵀδu=0`，以真实自由力残差下降作回溯判据。预测点 J 非法时先缩小输入增量。若采用另一种等价的缩放增广求解，须在小系统中证明相同约束和功共轭符号后再冻结，不增加多套求解框架。

## 5. 两层桥接与必须区分的误差

对每个候选先独立形成完整 TMC 模型的 `K0=∂Fint/∂u|u=0`，使用与非线性路径完全相同的 γ、kr、背景边界、厚度、平均约束和输出负载。以 d=10⁻³、10⁻⁴、10⁻⁵ mm 各自从零求解短程非线性点，比较 `q_out/d`、`R_in/d` 和实体附着节点上的 `u/d` 与 K0 的线性预测。这一层检查实现的小变形极限。

第二层在同一几何、材料、厚度、端口、实体夹具及实体对称条件下，独立求解去空区的实体线性模型。此时显式移除介质单元及其不与实体相邻的自由度，关闭正则化，再与 HF-1 的线性参照核对。矩形 Q1、常材料的线性刚度可用 3×3 Gauss–Lobatto 与 HF-1 的 2×2 Gauss 作积分一致性检查；不能把 HF-1 积分方式直接换入非线性 TMC 内核。

报告 K0 相对实体参照的响应偏差、初始刚度中介质/正则化分量的范数，以及夹持器一次背景边界诊断的响应差。加载趋零只消除有限变形效应，不消除介质和正则化的初始寄生刚度。第二层的模型偏差不要求人为接近零，不作为调 γ/α 来获得 PASS 的目标；超过 5% 时标记 `model_bias_requires_followup`，说明当前两种模型不可互换，仍保留原数值和固定主任务。这个诊断阈值不代表物理精度容许误差。

## 7. 顺序、有限预算和停止规则

1. 冻结两份任务、求解配置、单位及实体/背景边界表，复核原权威输入哈希；绘制实际 DOF 选择图后再启动力学路径。
2. 实现平均约束的小系统与最小网格验证、初始切线对照、失败回滚；通过后执行两候选的两层小变形桥接及一次夹持器背景边界线性诊断。
3. 只有接口、第一层桥接和独立实体参考一致性通过，才各启动一次 40 目标完整试点。依共同规则最多25次 Newton 残差检查、12次回溯、4层增量二分，最小 Δd=0.025/16 mm；新增子步与原目标分别记录。
4. 检查两例路径、重复性与断开运行结果，汇总边界/模型偏差，再提出 HF-4 最近计划并停止。第二层模型偏差可作为明确诊断结果，不冒充已被消除的误差。

小变形桥接各幅值是单独的从零短程任务，最小增量取该预设幅值的1/16，沿用相同检查/回溯/二分次数和容差；不能给10⁻⁵ mm桥接误用完整试点0.025/16 mm的最小增量。这个按任务原增量缩放的规则对两候选一致，最终目标均不改变。

CPU float64、单进程顺序运行、树 RSS 4 GiB 软上限。建议数值累计上限40分钟：环境编译冒烟5分钟，小系统/桥接/重复累计10分钟，两例完整路径各10分钟，独立安装后的短程验收5分钟；包含失败尝试和重算，安装下载另列。小作业单进程≤5分钟；每个完整候选只有一次主任务尝试，逐接受步落盘。保存每进程墙钟、编译、单元核、装配、稀疏解、回溯与端到端计时；不承诺基于 C 形经验的运行速度。

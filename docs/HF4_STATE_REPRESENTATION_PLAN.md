# HF-4 位移状态表示修正方案

2026-09-14。**本文记录基于本轮证据的后续修正方案，尚未实现或执行验证。** 本轮维持原物理参数、残差尺度、停止阈值和 0.4.0 生产源码。HF-4-B 应记为四个组合中三个完成生产及独立验收、一个未完成；依赖完整 B 阶段的非均匀接触和圆柱工作继续停止。

本提案承接 [HF4_AB_EXECUTION_PLAN.md](HF4_AB_EXECUTION_PLAN.md)、[固定状态排查决定](HF4_PRECISION_INVESTIGATION.md) 和 [原冻结规范](../hf_repo/configs/hf4/validation_spec.json)。目标是使小应变能够在较大平移背景下被保存、求值和独立核验。它不改变第三介质物理模型，也不把状态表示问题改称接触模型误差。

## 1. 当前结论与可以交付的范围

前三个组合的独立记录分别为 [g0_m0_001_audit](../hf4_results/g0_m0_001_audit/summary.json)、[g0_m1_001_audit](../hf4_results/g0_m1_001_audit/summary.json) 和 [g1_m0_001_audit](../hf4_results/g1_m0_001_audit/summary.json)。它们支持各自冻结工况的规定运动、分侧测力、数值精度及所列均匀模型偏差结论；不支持第四个组合或一般二维接触的通过声明。

第四个组合 h=0.0625 mm、gamma=1e-7 的 [原始结果](../hf4_results/g1_m1_001/result.json) 仅接受零态，`target_reached=false`，`target_metrics=null`。它在首个非零目标 d=0.125 mm 接近收敛后停滞，按原设置二分到 d=0.00048828125 mm 仍未通过。这里必须保留两个不同的事实：数值解已非常接近平衡，但它没有通过冻结的生产接受条件。

[固定态探针](../hf4_results/fixed_state_probe_001/summary.json) 对诊断重现的实际失败候选和独立分段仿射参考逐节点一次舍入后的状态给出：

| 固定态 | 独立 HP 自由残差 / SF | 生产全内力求值误差 / SF | 50/80 位内力差 / SF |
|---|---:|---:|---:|
| 首目标最后失败候选 | 1.8410298639e-9 | 7.0836e-16 | 1.2123e-42 |
| 一次舍入的仿射参考 | 1.8410298926e-9 | 5.9453e-16 | 1.5106e-42 |

相同输入上的生产力与高精度力非常接近，原残差平台是真实已存 binary64 位形的平衡误差。局部去除平移后仍约为 1.84103e-9，没有显示足以解除停滞的求值改善。因此，本次主要问题不应归因于本构或梯度求值消去；修改本构表达式、Armijo 门槛或迭代上限缺少相应证据。

探针的限制必须随结论保留：

- 它诊断性重现首个 0→0.125 mm 目标，并关闭二分以定位首次失败；不是完整正式路径重跑。所有候选和原失败目录分别保留。
- 它只核查该目标的两个选定固定态，没有逐一核查原二分树中的全部失败候选，也没有证明所有可能的 binary64 节点场都无法满足 1e-9。
- 去平移试验的实际 binary64 减法使理想梯度最多改变约 2.12e-17，因而不是严格相同物理输入上的纯表达式替换。这不影响“原始生产力对原始 HP 力误差很小”的直接证据。
- 候选的 HP 残差虽小于独立上限 1e-8，仍大于生产上限 1e-9；两个门槛须同时通过，不能用前者追认生产接受。
- dyadic 规定值及当前约束记录没有显示固定边界乘积错误。证据指向近刚体区域自由节点的绝对位移表示精度，不应泛称固定边界条件错误。

本轮可交付原源码与 wheel、三个通过组合、第四个失败组合、探针、图和完整资源记录，并标注 `HF4-B: partial, 3/4`。后续提案不改变 [生产源码冻结清单](../hf4_results/production_source_freeze.json) 或其 [0.4.0 源码副本](../hf4_results/source_v040_001/src/hf_eval/prescribed.py)。

## 2. 建议的权威状态：两个 binary64 分量

建议增加显式的新状态表示，而不是改变既有 `u` 数组的含义：

```text
state representation = split_displacement_v1
u_physical[i] = D(u_lift[i]) + D(u_fluctuation[i])
```

`D` 是将实际 binary64 值精确提升为 Decimal 的操作。两个 full-ndof 数组均采用现有 x-fast、节点 ux/uy 交错顺序，单位为 mm。它们相加的数学值才是权威位移；`u_display = round64(u_lift + u_fluctuation)` 仅供绘图和旧格式查看，不能作为新状态的力学或 HP 输入。两个分量并不自动提供通用 double-double 运算，也不承诺所有计算具有约 106 位有效尾数。

`u_lift` 在一个固定目标的 Newton/线搜索中保持不变。自由未知数只有 `u_fluctuation` 的自由 DOF，不能同时把两个分量作为独立未知数，否则会引入同一物理位移的非唯一分解。状态中同时保存 lift 构造规则、参数、目标和实际 lift 数组；复放以实际数组为准，规则用于独立核查。

规定边界继续满足原 `base_D + d*direction_D`。本合成任务的 dyadic 值允许 lift 在规定 DOF 上精确取该值，fluctuation 在这些 DOF 上为零。对于将来的非零基值或非 dyadic 乘积，必须先冻结固定 DOF 的两分量生成规则及舍入补偿规则；无论选择何种规则，HP 都直接比较两分量之和与 `D(base_D)+D(d)*D(direction_D)`，沿用原约束误差门槛。不能把未存档的理想乘积当作隐含第三分量。

旧状态可无损导入为 `(u_lift=u, u_fluctuation=0)`，含义仍是 `D(u)`；这种转换不会修复旧状态的精度。新状态压成一个 binary64 数组属于有损导出，必须标明用途及状态变化，不能把其旧 U-only HP 结果移用于原两分量状态。

## 3. 首轮 lift 的具体构造与非均匀兼容性

首轮只增加当前合成问题的明确几何 lift，不用半解析平衡解或接触力来选择 lift。设下块高度 H1、初始间隙 g0：

```text
l_x(X) = 0
l_y(X) = 1                       y <= H1
         (H1 + g0 - y) / g0       H1 < y < H1 + g0
         0                       y >= H1 + g0
u_lift(X; d) = d*l(X)
```

它表示下块平移、上块静止及背景的连续线性延拓，由几何和规定运动决定，与 E、nu、gamma、当前力、求解答案无关。实际 lift 生成运算和数组须归档；本轮 dyadic 网格及目标下的精确性要由独立输入审计验证，不能只凭几何标签推定。

在首个分离目标，实体的很小弹性变形主要保存在 fluctuation 中，避免先加到约 0.125 mm 的平移上再求梯度。超过闭合位置时，lift 自身可能给背景带来非正 J；**合法性只检查总物理状态**。不能要求 lift 单独是一条平衡或合法变形路径，也不能用 lift 自身的能量、反力或 J 代替总状态量。

这种分解与通用非均匀 Q1 场相容：自由 fluctuation 仍覆盖原全部自由 DOF，未施加行内等位移、分层仿射、对称均匀应变或一维降阶约束。一般问题可提供独立定义的平滑或分片 lift，只要在固定边界满足规定值，剩余场仍完整。不过一般问题如何选择有利的 lift、复杂转动、接触变化及大范围位移累积，不由本次合成工况证明。HF-3 候选接口暂不自动迁移；采用新状态须另有对应的端口与持久化核验。

## 4. 残差、导数和路径算法的改动范围

建议新增显式状态入口，例如 `assemble_split(model, state, tangent=...)` 与规定运动的 opt-in 路径入口。旧 `assemble(model,u)`、旧状态 schema 和旧 wheel 保留原语义。下一版本号及 API 名称应在编码前与新执行清单一起冻结。

单元运动学必须从两个分量分别作用于原算子后形成总量：

```text
G  = grad(u_lift) + grad(u_fluctuation)
Hu = H(u_lift)    + H(u_fluctuation)
F  = I + G
```

禁止先在 binary64 中形成 `u_lift+u_fluctuation` 再调用旧内核。正 J 守卫、材料应力/能量、HuHu、切线及仅残差的两个求值分支必须使用同一总运动学。积分点、权重、实际 Lamé 数组、未乘 gamma 的 kr、`exp(-5J)` 和弱式均不改变。HuHu 的实际非对称 Jacobian 继续保留，不增加虚构的总势能。

固定 lift 时，`du/dw=I`，所以 Newton 自由切线仍是物理残差对自由位移的导数，不增加双倍未知数。独立方向测试必须扰动 fluctuation 并将 lift 保持不变；方向导数在 HP 中按实际两分量与实际扰动向量重建。若复用自动微分，须检查其没有对 lift 规则、重分解或分量归一化误求导。

目标推进时需要明确坐标转换，不能简单把较大的新旧 lift 差加进小 fluctuation 后丢掉有效位。建议 lift 在每个目标固定，保留原预测—Newton—回溯—二分流程；预测右端在新坐标下按总规定增量和 lift 增量推导。例如固定 fluctuation 的边界增量为零时：

```text
K_ff * delta_w_f = -(K * delta_lift)_f
```

若固定 fluctuation 含规定值补偿，须加入相应 `-K_fD*delta_w_D`。该等式及实现中的运算顺序要通过小规模方向检验；不得把未计入状态的补偿值藏在预测器中。若采用重新分解，必须证明重分解前后两分量精确和不变，保存转换记录，并在接受状态和回滚中整体处理两个数组。第一版优先固定可审计的 lift，避免自动改选 lift 或误差驱动参数扫描。

回溯只改变当前自由 fluctuation；所有试探、拒绝、接受和失败记录都携带相同目标的 lift 身份。接受门和回滚语义沿用原规定，失败保留最后接受的两分量状态和 null 目标指标。基于显示用单数组决定 J、收敛或回滚，均属于接口错误。

## 5. 独立 HP、测力和可搬迁接口

独立 HP 新入口接收实际 `u_lift`、`u_fluctuation`、原单元原语、d/base/direction 和测力组。它须在 Decimal 中先形成 `D(u_lift)+D(u_fluctuation)` 再由独立公式计算梯度、Hu、J、内力与方向作用，不导入生产内核，不把已舍入的梯度作为参考输入。旧 HF-2/HF-3/HF-4 HP 入口保持原行为；可以增加显式新适配层，但不能静默改变 `D(u)` 的含义。

同一 HP 权威状态用于自由平衡、约束、全/自由生产求值误差、固定 DOF 反力、分侧合力、功共轭驱动力、材料/正则分量及间隙。规定反力仍只取唯一固定 DOF；组力仍为组虚位移向量与反力的点积，没有额外对称倍率。间隙、端口和其他线性测量须对两分量分别运算，HP 在 Decimal 中重建实际坐标及完整两分量；不得从 `u_display` 重算用于验收的量。

建议保存普通 NPZ+JSON，至少包括：

| 载体 | 必须保存的内容 |
|---|---|
| model.npz / model.json | 原几何、连接、DOF、材料与算子；新增表示 schema、lift 规则及边界匹配规则 |
| 每个接受态 NPZ | `u_lift`、`u_fluctuation`；原力/J/能量数组；可选 `u_display`，明确非权威 |
| 每个接受态 JSON | d、原目标/补步身份、两个分量内容 SHA、模型/规则 SHA、原接受与失败字段 |
| HP 记录 | 两分量输入哈希；原始 Decimal 内力、J、能量、约束、反力、尺度和分子；50/80 位对照 |
| 诊断记录 | 选定 Newton 基态及修正量、试探因子、实际变化的分量和回滚身份；不只保存残差摘要 |
| 包清单 | schema/API 版本、Git/源码/wheel/依赖、全部普通数据文件哈希及复放入口 |

独立安装验收必须在不能访问原工作区的环境中，由新包读回普通两分量数据，复算同一残差和测量并进行受控路径复放。不能依赖 LF、MATLAB、源 ZIP、PDF、未打包缓存或安装路径中的历史绝对引用。展示图仍用真实 mm 坐标，可用 `u_display` 作像素级渲染，但图注和数据文件要区分显示状态与权威状态。

## 6. 编码前冻结的小门禁与后续放行顺序

科学验收继续使用原规范的所有物理参数及门槛，尤其是生产残差 1e-9、HP 平衡 1e-8、力求值预算 1e-9 SF、约束 1e-10、50/80 位交叉 1e-30，以及原法向力、间隙和模型偏差界。新实现应通过更准确状态满足这些门槛，不能因换 schema 而改尺度。新执行清单引用原规范哈希，不覆盖原文件。

建议一次冻结以下顺序，每级失败停止依赖工作：

1. **状态与独立公式小检查。** 验证旧 U→两分量无损导入；构造大常量 lift 加小仿射/非仿射 fluctuation；比较两套生产求值分支与独立 50/80 位参考。加入具有非零 HuHu 的非均匀小网格、方向导数与原切线测试，防止实现只适用于均匀层。lift 取零时的原小核参考、强压缩与近零检查仍须通过原门槛。任何误差比较都先核对完整数组形状。
2. **原失败目标的最小闭合试验。** 同一 g1/m1、同一 d=0.125 mm，从零按新的权威状态求解；接受后必须同时通过生产及独立门。保留旧失败候选作诊断比较，但不要求旧 U-only 失败态因此变成通过，也不将参考解作为初始答案。此级不执行完整路径。
3. **第四组合完整路径。** 小门通过后，唯一一次新版本的 g1/m1 六目标尝试，仍允许原规则的补步。保存全部接受态并逐态 HP，末个原目标做 50/80 位交叉。若仍停滞，报告表示改进未闭合，不自行再换 lift、gamma 或算法。
4. **前三组合与兼容性。** 第四组合通过后，在同一新版本重放前三组合，核查原模型、参考及 HP 门。旧版本通过证据仍作为旧版本记录；新状态不同，不能直接继承旧 HP。新旧响应差保存为比较量，物理参考标准保持不变。
5. **可搬迁交付。** 独立环境复放一个完整新状态路径并做两种任务顺序的状态隔离检查；完成新旧状态阅读兼容、拒绝错误 schema、两分量持久化/回滚及哈希审计。发布说明明确新增状态表示的数值范围，继续不声称一般非均匀接触或真实夹持精度已验证。

新的表示不需要提前确定圆柱尺寸、真实材料阈值或所有后续研究参数。真正必须在执行前决定的是表示 schema、边界补偿和 lift 更新规则、HP 重建接口、固定的小检查、版本/来源及预算。

# HF-4 均匀法向参考与计算前误差界

2026-09-14。本文的方程、唯一根论证和分相误差上界均在 HF-4 参考数值计算及有限元计算之前推得。它们用于解释本合成基准的预设容许差，不是根据结果倒调门槛。实际数值是否通过，必须另读冻结规范对应的执行输出。

权威计算规范为 [validation_spec.json](../hf_repo/configs/hf4/validation_spec.json)；物理范围和准备理由见 [HF4_READINESS_REVIEW.md](HF4_READINESS_REVIEW.md)。独立实现为 [hf4_normal_reference.py](../hf_repo/scripts/hf4_normal_reference.py)，逐状态预检查入口为 [preflight_hf4_reference.py](../hf_repo/scripts/preflight_hf4_reference.py)。

## 1. 明确的参考问题与物理量

全模型由下、上两块相同材料的弹性块与均匀第三介质层组成。参考宽度 W=1 mm，块高 H1=H2=1 mm，间隙 g0=0.25 mm，厚度 t=1 mm；H=H1+H2=2 mm，参考受力面积 A=W t=1 mm²。整个场 ux=0，顶边 uy=0，底边 uy=d；d 为朝顶边运动的正接近量。材料采用当前 P26 平面应变形式，E=1 MPa、ν=0.3，γ 为 1e-6 或 1e-7。

六个原目标为 d=0、0.125、0.21875、0.25、0.28125、0.375 mm。网格 h=0.125/0.0625 mm 只用于后续 FE；所有几何及目标均为二进制可精确表示的数，材料界面精确落在网格线上。

p 表示正压缩**名义应力**，F=A p 是底部驱动器对模型的 +y 作用力。顶边装置对模型的有符号 +y 力为 −F；模型对装置的力取反号。这里没有半模型倍率。第一 Piola 应力与参考面积配对，不能把当前面积应力与参考面积混算。受限横向反力属于约束反力，但其向量范数不是法向接触合力。

## 2. 从已核实能量独立推导一维材料式

两维实现来自三维平面应变 F=diag(1,s,1)，J=s>0。将已审计的 P26 能量代入得

```text
Psi(s) = lambda/2 * ln(s)^2 + mu/2 * (s^2 - 1 - 2 ln(s))
p(s) = -dPsi/ds = mu*(1/s-s) - lambda*ln(s)/s
p'(s) = -mu*(1+1/s^2) - lambda*(1-ln(s))/s^2
```

λ≥0、μ>0 且 0<s≤1 时，p'(s)<0，p(1)=0，s→0+ 时 p→+∞。唯一性论证只使用这一压缩区间，不把其单调性外推到任意拉伸状态。公式来源的范围见 [PAPER_FORMULATION_AUDIT.md](PAPER_FORMULATION_AUDIT.md) 第2节；以上降维及导数是本项目独立推导，不是论文算例的数值输出。

## 3. 有限介质参考的唯一根

实体及介质的伸长比分别记为 s_s、s_v。参考接受两套**实际**材料系数，不以 γ 重新计算输入：

```text
H*s_s + g0*s_v = H + g0 - d
p_s(s_s; lambda_s,mu_s) = p_v(s_v; lambda_v,mu_v)
F_TMC = A*p_s(s_s), gap_TMC = g0*s_v
```

用实体总缩短 x=H(1−s_s) 化为单标量方程

```text
f(x) = p_s(1-x/H) - p_v(1-(d-x)/g0) = 0
max(0,d-g0) < x < min(d,H),  0<d<H+g0
f'(x) = -p_s'(s_s)/H - p_v'(s_v)/g0 > 0.
```

左端 f<0 或趋于−∞，右端 f>0 或趋于+∞，所以恰有一个压缩根；d=0 单独返回 s_s=s_v=1、F=0。实现使用保持上述符号的括区二分，不评价 s=0 的奇异端点；内部有迭代上限，不能解析到合法伸长或达到指定求根精度时抛出明确错误。

两块材料完全相同，因此只通过 H1+H2 进入伸长解，但各块的空间位置仍属于 FE 测力/几何验证。独立参考不导入生产本构、JAX、FE 梯度、连接表、装配器或求解器。

## 4. 独立的理想单边硬接触参考

另一参考直接施加无黏附单边接触条件，不含第三介质：

```text
0<=d<=g0: F_hard=0, gap_hard=g0-d, s_s=1
g0<d<H+g0: gap_hard=0, s_h=1-(d-g0)/H,
           F_hard=A*p_s(s_h)
```

它满足 p≥0、gap≥0、p*gap=0。有限介质在几何闭合前便传递非零力，不能用“首次非零力”定义理想起触点。

FE 与有限介质半解析解之差用于核查实现、边界、测力和积分；有限介质与硬接触解之差是模型差异。HP 或另一套相同 TMC 程序不能替代后一参照。即使这两个比较都通过，也只涉及受限均匀合成试件，不是实际材料或一般接触的实验验证。

## 5. HuHu 的适用范围

在精确分层解中，每个与材料界面对齐的矩形 Q1 单元内位移是仿射的，故**代码实际采用的单元内部** Hessian Hu=0，HuHu 残差为零。材料界面两侧梯度可以不同；这不等于全域的分布 Hessian 为零，也不暗示实现中存在界面梯度跳跃罚项。

这使半解析参考与当前离散算子的均匀模式对应。FE 仍须报告真实数值解的 HuHu 分量并按规范检查，不能仅靠理论把存档正则力写成零。两个网格主要检查映射与装配一致性，不足以声明一般网格收敛、二维接触中的正则影响、滑移或曲面精度。非均匀问题的总力仍须包括实际 HuHu 残差；不能用材料能量导数替代完整非保守弱式的反力。

## 6. 实际 binary64 输入与高精度自洽

生产与预检查分别按普通 binary64 运算生成 λ_s=Eν/[(1+ν)(1−2ν)]、μ_s=E/[2(1+ν)]，以及 λ_v=γ λ_s、μ_v=γ μ_s。预检查不调用生产函数。FE 归档中实际数组的系数必须逐位核对，不能仅核对 E、ν、γ 标签相同。

参考对实际 λ_s、μ_s、λ_v、μ_v、W、H1、H2、g0、t、d 分别使用 `Decimal.from_float`。一般不能认为 `D(gamma*lambda_s)==D(gamma)*D(lambda_s)`；实际两套缩放比也不必是同一个精确 Decimal 数。记录同时保留输入的 binary64 hex 与精确 Decimal 字符串。

参考分别从头以50/80位重算，工作上下文另留24位保护。导出的伸长比先按声明精度舍入，长度闭合和应力连续残差再从这些**实际导出的伸长比**重算，避免只报告隐藏高精度迭代量的残差。

预检查按冻结的 `reference_equation_relative=1e-35` 核查两个精度的长度/应力方程；长度尺度为 H+g0，应力尺度为 λ_s+2μ_s。50/80对照使用独立正尺度：力差/(EA)、间隙差/g0，伸长差取绝对值；均≤`precision_crosscheck_relative=1e-30`。公开参考 API 另保存基于 A(λ_s+2μ_s)、H+g0 的无零分母对照值，预检查明确重算自己的 EA/g0 比较，二者不混称同一归一化。

这些是参考求值自洽门，不是 FE 的外部残差阈值，也不是接触物理误差容许差。FE 自由平衡、规定值、全/自由力求值预算、三路合力、间隙和位移参照门槛均保留各自定义。

## 7. 计算前保守界支持分相诊断容许差

以下为计算前数学界。冻结的实际实体系数满足

```text
0<=lambda_s<0.58 MPa, 0<mu_s<0.39 MPa,
M=lambda_s+2mu_s>1.34 MPa.
```

对各 γ，用其实际二进制值提升后再检验 `lambda_v<0.58*gamma`、`mu_v<0.39*gamma`；γ 的二进制值仅用于这一宽松上界，参考求解仍使用实际介质系数。γ=1e-6 的 binary64 值不大于精确十进制1e-6；γ=1e-7 也小于该统一上界。预检查必须实际验证这些前提，不能因标签相同跳过。

压缩区间有 −p_s'(s)≥M，因此 p_s(s)≥M(1−s)，x≤Hp/M。以下 F 与 p 的数值相同只是因为 A=1 mm²，不取消其单位。

### 7.1 分离区 d≤0.21875 mm

由于 x≥0，有 s_v≥1−d/g0≥1/8。利用 ln8<3：

```text
p=p_v(s_v)<=p_v(1/8)
  < gamma * [0.39*(8-1/8)+0.58*8*3]
  < 17*gamma <= 1.7e-5 MPa.
x <= 2*p/1.34 < 2.54e-5 mm.
gap_TMC-gap_hard = x.
```

所以预设 `F_leak/(EA)<=1e-4` 及 `|gap_TMC-gap_hard|/g0<=1e-3` 有保守余量。后一允许绝对差为0.00025 mm。零状态单独应精确无力；不得用 F_hard=0 作相对误差分母。

### 7.2 几何闭合目标 d=g0=0.25 mm

此时 s_s=1−s_v/8。在试探伸长 s_v=0.01 处，实体 p_s≥1.34×0.00125=0.001675 MPa；由 ln100<5，介质 p_v<329γ≤0.000329 MPa。两者差随 s_v 严格增大，平衡根故满足 s_v<0.01、gap_TMC<0.01 g0。

令 a=0.00125、s=1−a；由 −ln(s)≤a/s，

```text
p_s(s) <= 0.39*a*(2-a)/s + 0.58*a/s^2 < 0.00171 MPa.
```

因此本目标的预设 `F/(EA)<=0.002`、`gap/g0<=0.01` 有数学余量；它不是要求有限介质在此点精确零力或精确零间隙。

### 7.3 压紧目标 d=0.28125、0.375 mm

硬接触伸长 s_h=1−(d−g0)/H 分别为63/64与15/16，故 p_h≥M/64>0.0209375 MPa。有限介质的 s_s=s_h−g0*s_v/H。在 s_v=0.001 时，由 ln1000<7 得 p_v<4450γ≤0.00445 MPa，而 p_s≥p_h；因此真实根 s_v<0.001，G=gap_TMC<0.00025 mm。

实体 s_s>0.937375>0.93，在此区间利用 −ln(0.93)<0.08，

```text
|p_s'| < 0.39*(1+1/0.93^2)+0.58*(1+0.08)/0.93^2 < 1.6 MPa.
0<p_TMC-p_hard < 1.6*G/H < 0.0002 MPa.
(p_TMC-p_hard)/p_hard < 0.0002/(1.34/64) < 0.00956 < 0.01.
```

这支持预设的力相对偏差≤1%、gap/g0≤1%。该界仅覆盖这两个原压紧目标及给定材料范围，不自动推广到任意更大行程。

## 8. 实际代码只读复审与停止门

计算前只读审查 [normal_contact.py](../hf_repo/src/hf_eval/normal_contact.py) 与 [prescribed.py](../hf_repo/src/hf_eval/prescribed.py)：冻结任务的材料分层、底部正规定运动、顶边负反力方向和 `g0+u_upper-u_lower` 间隙定义与参考一致。自由预测右端为 −K_fD Δu_D，Newton 自由修正使用实际非对称 K_ff；测力向量只作用于规定自由度，整体反力合计使用去重自由度。此项为代码审阅结论，不代替后续运行验证。

逐状态预检查输出同时记录 numerical_status 与 model_status；任何未通过检查均保留并使脚本返回非零。单位、符号、参考自洽、HP、规定运动、正J或资源失败时停止依赖该结论的后续工作。实现通过而模型偏差超限时单独报模型适用性问题，不能改阈值、参数或初始间隙追求 PASS。圆柱参数仍不阻塞本基准，但本基准通过也不放行未经定义的圆柱任务或一般二维接触精度声明。

## 9. 实现测试中保留的表示层失败

# 独立 HF 评估器：目标、工作与证据总览

更新：2026-09-14。本文是项目审查入口；阶段报告保存当时事实，不追溯改写旧失败。用户持续要求记录总体目标、要做/已做的工作、理由和效果。最新进度为**0.5.0完成HF-4-B四组冻结均匀法向路径验收**，HF-4-A此前已完成，HF-4-C/D仍未开始，见[HF4修正报告](HF4_REPAIR_REPORT.md)和[总验收摘要](../hf4_repair_results/acceptance_summary.json)。下方保留HF1–HF3及旧0.4.0的阶段历史。

## 总体目标

建立独立正向力学评估器：仅提供HF仓库、其独立环境和自包含几何数据，即可在同一版本物理任务下，对真实反向器及夹持器输出有单位、符号、版本、有效性标识的响应。几何生成与LF优化属于来源环节，不是HF运行依赖。最终要分清数据可读、几何资格、数值求解、物理模型精度及功能表现；程序运行成功不等于高保真真值。

## 为什么分阶段

先保证输入与物理含义不被搬迁改变，再验证单元/装配/求解精度，再把已验证内核接入真实机构的项目任务，之后才验证接触、参数误差和小批量评价。这样可以把几何映射、算法错误、模型偏差和机构性能分开解释。

## HF-3 当时要做什么、为什么做、如何判断效果

1. 构建项目适配器，把原始掩膜、mm/N/MPa、真实支承/端口及背景边界显式变成全域TMC模型，防止把C形整边固定或LF弹簧误当项目工况。
2. 实现功共轭平均位移控制，验证乘子反力符号及非对称增广系统；保留端口局部变形自由度。
3. 优先检查近零应变内力精度，验证内部停止与独立高精度误差预算可实现。HF2强压缩通过不自动涵盖近零状态。
4. 比较非线性→自身K0与K0→实体线性参考，前者检验实现极限，后者量化第三介质/正则/边界模型偏差。
5. 逐状态保存实际输入、U/R/力/J/能量、接受及拒绝原因、HP误差和资源。每个阶段用可查看图及普通数组支持结论。

## HF-3 当时的效果与下一步判断

两条完整路径各一次完成40/40目标到1mm，全部80态独立HP通过；加上六个桥接态，共86态通过，8态50/80位交叉核验通过。最终反向器输出1.682304535mm、输入广义力0.175256261N；夹持器输出1.161186104mm、输入广义力0.216125158N，均是当前下半模型、自由输出诊断。详细符号和物理边界见报告。

近零内力求值相消问题已由真实固定状态取证并等价修正，最大相对求值误差约5.97e-8降至2.98e-13；原小参考及强压缩回归通过。小位移三响应误差随幅值缩小约同比缩小，初始输入刚度模型偏差约0.140%/0.159%，未改变输出方向。这些结果让项目接口和数值实现可以审查，不等于给出了物理误差上界。

HF-3结束时的下一步是准备并冻结HF4独立法向接触基准、间隙/合力定义和验收门槛，再确定圆柱工况与敏感性计划。HF-3阶段没有执行HF4。该阶段证据总入口为[总验收摘要](../hf3_results/acceptance_summary.json)和[完整报告](HF3_REPORT.md)。

## HF-4-A/B 原版0.4.0的效果与当时判断

0.4.0已实现合成任务、非零规定运动与功共轭分侧测力，12态独立标量参考预检通过。四组合中三条完整路径通过；所有39个接受态（包括第四组合仅有的零态）经HP验算。通过组合的原压紧目标相对硬接触力最大偏差0.1969%，只限当前均匀任务。回归与新增测试去重491通过、1个既有平台权限跳过；独立安装63检查通过，并复现第四组合失败。

第四组合h=0.0625、gamma=1e-7在首个非零目标停止，target_metrics=null。固定失败候选的HP残差约1.841e-9，而生产求值误差仅7.084e-16×SF；1/16校正时全部595个自由DOF逐位不变。这将问题定位到当时绝对binary64位移及更新的舍入平台。原参数/阈值不变，当时停止进入更复杂接触，并提出[状态表示方案](HF4_STATE_REPRESENTATION_PLAN.md)，先验证大平移与小变形的分量保存及独立HP重建。历史证据见[原HF4阶段摘要](../hf4_results/acceptance_summary.json)。

## HF-4-B修正0.5.0：为什么、做了什么、效果与边界

修正针对已取证的状态舍入原因。阶段0保留同一已存修正方向时，未折回单数组的更新把HP相对残差从约1.841e-9降至6.890e-16；此实验仅用于判断修正方向，不作为生产初值。随后新增三个运行模块：[split_state.py](../hf_repo/src/hf_eval/split_state.py)分别保存宏观lift与小fluctuation；[split_kernel.py](../hf_repo/src/hf_eval/split_kernel.py)用总G/F/Hu/J评估原材料与HuHu残差及完整切线；[split_prescribed.py](../hf_repo/src/hf_eval/split_prescribed.py)仅修正fluctuation，保留两数组预测、回滚和失败语义。旧单数组入口仍有原含义，显示用的舍入和不能冒充新状态权威。具体接口、公式、文件格式与测试对应见[实现文档](../hf_repo/docs/HF4_SPLIT_IMPLEMENTATION.md)。

六个固定态先核验实际两数组的求值精度，包含三个位形的均匀参考、非均匀HuHu、精确等价分解及小于显示ULP的修正。独立HP直接提升实际两数组并计算原公式，方向只扰动fluctuation；实际接受态另从已保存内力重算原生产1e-9停止门槛。通过固定检查和首目标后，四组完整路径各从零开始、各完成6/6原目标至0.375mm；接受态数量为12、12、14、14，包含补步，共52态全部HP通过。另一次首目标检查的2态单独列出，不能重复计作完整路径态。

新完整路径的最大HP相对残差约4.50301e-10，最大完整内力求值误差约6.24321e-12×SF；相对同一有限介质参考的最大力差约5.60e-14N、间隙差约8.31e-14mm。压紧区相对硬接触参考的最大模型力差约0.196916%，通过原1%模型门槛。这里的有限元实现误差和有限第三介质的模型偏差分别验收，均匀法向任务通过不构成一般接触精度上界。

完整回归592通过、1跳过，随后新增12项存档审计测试通过；去重合计604通过、1跳过，来自两次测试运行。独立安装73项通过，包括A–B–A以及双数组存档读取。新验收核对旧14个运行文件除版本声明外、旧376个证据文件、395个原几何文件和旧HF4交付ZIP的哈希不变；本轮新增模块、版本声明与持续维护文档属于明确更新范围。详见[机器可读总验收](../hf4_repair_results/acceptance_summary.json)和[修正报告](HF4_REPAIR_REPORT.md)；[修正版交付包路径](../deliverables/HF4_repaired_evaluator_and_evidence.zip)提供本轮可搬迁成果的固定位置。

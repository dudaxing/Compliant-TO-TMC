## 诊断任务提案

为避免未来材料和工件参数阻塞当前数据验证，定义一个名字明确的 `hf1_linear_interface_smoke_v1` 配置：E=1 MPa、ν=0.3、平面应变、几何所带 t=20 mm；输入平均位移 +1e−6 mm；输出弹簧为 0、无输入弹簧、无工件。这些是建议的数值诊断设置，来源类别 `proposed_pilot`，只在 HF-1 授权后写入任务配置，不是正式研究任务。

真实夹具使用已映射的 x=0,y∈[0,8]；实体对称段按几何定义。去空区线性参考只约束存在于实体上的对应自由度，明确记录源 full_midline 中空区自由度没有进入此参考。TMC 背景边界的影响留到 HF-3，不能由本阶段推断。

## 预先规定的验证

| 检查 | 比较量与预期 |
|---|---|
| 数组往返/分区/身份 | 二值及分区逐元素相等；NPZ 不含 object；改变物理尺度必须改变几何身份；来源记录变化不应改变实体身份 |
| 方向/面积/端口 | 非对称样本各标记在预期物理象限；面积由实体计数×dx×dy 对账，双精度相对误差 ≤1e−12；固定 1 mm 端口权重为 1/4,1/2,1/4，总权重 1 |
| 区域资格 | 与独立统计核对实体/设计/被动计数；连通与角点断开反例产生正确诊断；缺失阈值保持 pending |
| 线性单元和小网格 | 刚体位移零力、仿射应变的应力/能量与解析本构相符；各自用同量纲参照：力为 K_ref u_ref，应力为 E ε_ref，能量为 E t A ε_ref²（系数按解析例）；归一化误差 ≤1e−10，零量用上述非零参照对应的绝对容差，避免除零 |
| 平均端口约束 | 检查 bᵀu=d；残差尺度取 max(‖K u‖,‖bR‖,E t d)，相对自由力残差 ≤1e−9；约束误差 ≤1e−10 max(|d|,1e−6 mm) |
| 输入功/输出符号 | 解析小系统中比较广义乘子、输入功和端口平均，暴露符号/刚性绑定/逐节点弹簧混淆；不套到非保守 TMC 总能量 |
| 故障与重复 | 缺文件/坏哈希/非二值/转置元数据可被识别；重复 A、B、A 输出数组/数值一致（时间戳、调用 id 可不同） |
| 断开 LF | 新环境和 wheel 中无 LF 依赖；仓库外 cwd 可完成两例读取、诊断分析和输出，运行访问无 LF 文件 |

上述是下一阶段的预设计算一致性容差，不代表物理模型误差界。发现超差时先解释尺度、实现与条件数，不根据已见结果放宽阈值来通过。

## 可视化与资源范围

每例提供源 clean/导入掩膜对照、差异图、支承/端口/对称段图和线性位移示意；输入量太小时可夸大位移显示，但图上同时标记真实输入量和显示倍率。保存原始数组、坐标与绘图元数据。没有非线性路径时不画伪造的非线性曲线。

预算：2 个真实 3200 单元样本、1 个非对称小样本、少量单元/小网格测试。CPU float64，内存软预算 4 GiB，单个真实结构分析上限 5 分钟，阶段数值作业累计上限 30 分钟（不含安装与人工检查）。这不是速度承诺；超出即先定位瓶颈，不扩展扫描、不切换 GPU。生产环境由 HF 自己建立并锁定；已探测的系统 Python 环境仅供 HF-0 探针。

## 完成与停止条件

完成：两个真实样本自包含；来源/处理/物理语义完整或缺失明确；无 LF 的环境可读取并完成诊断分析；所有预设验证和图示有证据；正式研究资格与非线性/接触精度仍标明尚未验证。

停止并报告：真实样本来源链或关键坐标无法确定；需要改变几何才能求解；独立运行仍访问 LF；数值一致性超差未能解释；到达算力上限。普通任务参数 pending 不阻塞本诊断阶段。HF-1 完成后按任务书暂停，不自动展开 HF-2～HF-5。

# Right-medium margin closure archive

This is a selected ordinary source/review/documentation archive, not another scientific run.
Six reviewed proposals were installed as raw bytes. Their recorded before/after identities
and all archived file identities are in documentation_install.json. Author material that
already has the same raw SHA in a formal stage is referenced by archive_selection.json
rather than copied again. No model/state/NPZ/PNG/GIF or large source capsule is duplicated.

Historical candidate README/notes, interim banners and source-phase snapshots describe
their authoring time; pending wording there is not current scientific status. Absolute
author paths are provenance only. Current results remain in the formal production,
reference and functional_views stages and the current main report.

The fixed-body side18/right2col comparison has peak total Fy +0.1883%, regularization
Fy 4.267 times, while max |Hu| changes only +0.0576%; early loading total Fy changes
about +14 to +32%. This does not establish pressure, friction, free-body or domain/mesh
convergence. The next proposed comparison is 2 to 4 mm right margin at the same h=1 mm.

root_physical_interpretation.md is the root's planned subsequent report append. The
reviewed six proposals are retained unchanged, including their historical reference
status snapshot. Root will separately move that snapshot to prior_reference_snapshot
and record the actual current reference PASS in a document-only revision. This archive
receipt covers the six-proposal installation before that separately recorded revision.

# Reviewed documentation installation candidate

File/JSON-only helper; authored and compiled, not executed. It installs the six reviewed
proposals exactly and creates a fresh `right_margin_source_context/closure_001` archive.
All proposal, preimage, selected source and retained-formal SHA checks precede writes.
No scientific outputs, whole author workspace or redundant runtime source capsules are copied.

Run only after root review, from any directory:

```powershell
& '<HF Python>' '<author root>/installation_candidate/install_right_margin_docs.py' --repo '<Git root>' --author '<author root>'
```

The six proposal install is distinct from the root's later document-only reference-status
closure and physical interpretation append. Existing source-phase history is retained in
raw proposal bytes. The receipt is `closure_001/documentation_install.json`.

### 初猜是否改变物理结果

新选项只改变进入 Newton 的位移种子，保留真实 KKT LU 的反力预测、材料／TMC 力、切线、均值约束与原验收门。15 项小模型测试已通过。另从两张相同 side18/x71 任务的保存 JSON 中，选取唯一**加载** `d=0.5` mm 接受态：

| 工况（均为加载 d=0.5 mm） | 半模型输入 R / N | 下半工件总 Fy / N |
| --- | --- | --- |
| x71/side16 原完整对照 | 0.10624453013654195 | 0.0001350598644814841 |
| x71/side18 默认初猜；失败卡保存态 | 0.10683175174858359 | 0.00038737341911164127 |
| x71/side18 端口投影新生产 | 0.10683175175737766 | 0.00038737341914691904 |

端口投影相对默认初猜的输入反力差为 `8.79407e-12` N，下半工件总 Fy 差为 `3.527777e-14` N。这支持“同一任务在该共同加载态取得一致物理读数”；新初猜的作用是改善路径进入可行 Newton 区域。这个比较没有证明全路径唯一性，也没有把旧失败前缀变成完整参考。side16 对照仅在同一加载位移并列：尺寸和域边界位置发生变化，后续需匹配工况与网格检验。旧 side16 的 1.8 mm 峰值与新 side18 的 1.2 mm 峰值不用于因果比值。

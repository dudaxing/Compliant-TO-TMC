## 当前目标与物理进度

整体目标是从 LF/N4 研究层复用普通几何与物理任务，让 HF 独立计算有限变形、第三介质作用、力和加载—卸载，再以明确的精度与适用范围接回优化流程。当前工作集中在真实夹持器的正向功能和可视化；整个 HF 项目尚未完成。

用户要求工件靠右并稍大，以便最右钳尖接近工件。本轮固定方体中心 `(71,40)` mm、边长 `18` mm，下半计算域中的体为 `[62,80]×[31,40]` mm，右侧介质余量为零；输入是 24 个原始平均位移目标 `0→1.2→0` mm。E=1 MPa，材料、介质、支承和原 Newton 门保持。原 x72/side16 与本 side18 默认初猜两张失败卡继续保留，各自的接受前缀没有完整路径资格。

已实现 NumPy 机械力、材料/Hu/总力与三切线、CSC 组装、平均输入 KKT、固定工件和有序卸载，以及保存态的几何、节点力与 ×1 变形观察。可选端口投影初猜沿前一状态分配端口位移，保留真实切线 LU 给出的反力增量；原自由端口仍可产生不等位移。15 项小模型测试已证明默认路径保持和可选参数传递；这项测试没有替代新工件的完整参考。

读数需按位置与方向理解：`R_input` 是半模型输入端的广义反力 N；下半工件 `(Fx,Fy)` 是固定体弱式合力，分别保存材料与 Hu 分量。镜像上半体为 `(Fx,-Fy)`，全体净力为 `(2Fx,0)`，双侧法向幅值和为 `2 abs(Fy)`。`q_out=.25 uy(80,28)+.5 uy(80,29)+.25 uy(80,30)` mm；真正钳尖位置与有限工件面间隙由保存几何另测。节点力和这些合力尚没有压力分布资格。

下一步按实际结果逐项推进：先给出可人工核查的接触／夹持判据及压力定义；再匹配网格、gamma 和接触区域，检查力／间隙是否稳定；随后探索圆形与可动工件、局部柔顺性，最后接入 HF5/LF-N4 评价接口。每项新实验都保存物理任务、完整路径、实际成本、数值读数和图。详见 [本轮报告](WORKPIECE_ENLARGEMENT_20261007.md)。

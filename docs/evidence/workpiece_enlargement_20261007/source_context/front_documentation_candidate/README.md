# 四份简短前言提案

`fronts/` 对应四个正式文档的新增前言；`baseline_docs/` 保存作者读取的原字节。未改仓库文件，没有启动测试、FE、HP、solver 或渲染。

根 Agent 在实际生产、参考和视图终态齐全后，按真实结果替换所有 `{{...}}`，再将前言接在原全文前。前言已明确旧全文属于历史；旧的“下一步”不覆盖当前顺序。`author_note.json` 列出前言 SHA、原文件 SHA、动态 token 与来源检查。

动态读数必须含状态与范围：生产成功／失败、实际接受 N、峰值是否达到和卸载是否完成；参考实际 pass／failed／not_started及 N/2N；视图的实际路径与标签。失败分支如实写 partial／无完整资格；未发生参考或图片不补成 pass。峰值表区分各自峰值，共同加载位移采用真实 loading 态；`q_out` 不替代有限面钳尖间隙。实际图片链接需按对应目标文档的相对路径填写。

恢复命令仅展示源码／资产恢复及安装步骤。它们没有执行，不构成已闭卡重跑指令。后续新数值实验由根按具体功能任务、输入与资源范围开展。

# 下一项物理实验的只读取舍

建议最近一步只做 **γ=10⁻⁶→5×10⁻⁷** 的一个新完整加载—卸载任务，α仍为10⁻⁶、Lr仍为80 mm。现有合格24态作基线，不重跑基线。先回答“当前固定方体、右侧余量为零的任务，对第三介质材料倍率有多敏感”，随后据实际结果决定下一步。本意见不是执行卡，也不替根 Agent 决定授权。

当前 main `16ee4eb` 的峰态输入为1.2 mm，单侧工件Fy为0.1190075723 N，材料分量0.1188180648 N、Hu分量0.0001895075 N；介质minJ为3.23984×10⁻⁵，有限底面钳尖间隙5.70075 μm。加载0.85 mm时Fy为0.00252423 N、间隙33.6302 μm；0.9 mm时Fy已增至0.01411982 N、间隙14.2588 μm。这个跃升区比再改变工件尺寸或行程更值得先解释。峰态Hu约占Fy的0.16%，但早期占比更高，不能据此宣布α没有作用。

源码中γ只乘原第三介质的λ、μ；α控制全域 `kr=α Lr²(κs+4μs/3)`，不乘γ。重新平衡会改变F与Hu，因此新工件力不能按γ线性缩放。选择减半而非一次减十倍，是一次局部灵敏度测量；两点不能证明参数收敛或硬接触极限。α不与γ同时改，否则无法辨别机制。

独立源码审阅也提出一个合理的优先级差异：**若下一步目标是立即给出可转移的夹持力结论，应先补右侧介质余量对照。** 当前选择γ优先，是为了以最小实现改动继续检验已完成的功能；结论明确限于本边界任务。右侧余量的影响仍待排除，压力、硬接触与自由工件稳定夹持仍未成立。

输入/输出仍按同一有限端口的参考弧长归一梯形权重；完整24个原目标、峰值1.2 mm、零起点、port_projection初猜与原Newton/Armijo/KKT/J/范围/回滚门保持。比较按原目标索引及加载/卸载方向匹配；若新计算插入二分态，所有实际N态各有新参考，比较不插值、不用卸载态替换加载态。旧side16的1.8 mm峰值不能混进γ因果比较。

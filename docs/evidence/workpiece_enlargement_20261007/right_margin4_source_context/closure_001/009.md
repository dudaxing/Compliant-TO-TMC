# 统一E缩放与贴合：源码物理意见（2026-10-08）

**判断成立，但它是有条件的方程缩放结论，不是新工况实测。** 在同几何/网格/厚度、相同位移边界与平均输入位移、固定工件、ν/γ/α/Lr不变、k_out=0、没有独立非零外载，并沿同一静态解分支时，将全域构造参数E改为cE（c>0），理论上保留位移、F/J/Hu、Green应变、尖端距离及q_out；材料/Hu/总机械力、物理有限元切线、输入R、支承与工件on-body/holding力均乘c。

依据是native_project.py的λ=Eν/((1+ν)(1−2ν))、μ=E/(2(1+ν))、κ=E/(3(1−2ν))、kr=αLr²(κ+4μ/3)。相位因子为solid:1/medium:γ，kr不再乘相位因子（metadata kr_material_factor_applied=False）。固定ν/γ/α/Lr时，所有λ_i/μ_i/kr同步乘c。C1材料P=μF+(λ logJ−μ)F⁻ᵀ对这些系数线性，Hu弱式力为kr乘纯运动学/求积项；NumPy三切线是这些残量的位移导数，仍随c缩放。非保守Hu项不妨碍残量齐次性，结论不依赖把它当能量最小化。

实际平均输入方程是free DOF上的f_int(u)+k_out b_out q_out−b_in R=0，以及b_in·u=d。k_out=0时，(u,R)的解对应于(cE模型的u,cR)。**增广KKT矩阵不是整张乘c**：只有物理刚度块K_FF乘c，端口约束列/行b不变；精确Newton的位移增量可相同、乘子增量乘c。必须保持同一初始位移/解分支；若非零warm-start反力，应同步乘c。当前从零开始的R=0满足此条件。port_projection位移初猜是几何端口分配，实际KKT反力预测仍按新刚度计算。

若保留不随E缩放的非零输出弹簧、重力/体力/死载/工件重量/外部指定力，或改成力控制、引入另一独立材料/接触刚度尺度，形状就可能改变；只有这些力和刚度也统一乘c，才能维持上述齐次关系。当前native平均入口方程没有独立重力/死载项，仍需在将来新增这类物理时重新判断。局部软化、保持绝对介质/kr不变、改γ或α则改变相对刚度，也不属于统一E缩放。

数值实现不保证逐位相同。当前主停止门是相对残量，force floor=设置因子×(E×厚度)×位移尺度，native入口随E更新；位移约束门不依赖E，归一化Armijo在精确算术下也保持。因此未见本入口另加固定N单位的主绝对停止门。实际DD支持范围/≤2^8算术选择器、舍入/抵消、非均匀缩放的稀疏LU与tiny诊断下界可能改变末位、接受次数、成本或分支；mixed-unit backward error源码明确只作诊断。多解/分岔附近也不能保证算法选到同一形状。这里没有执行E缩放实验或取得新资格。

功能取舍：在当前同一位移任务中，统一降低E主要降低驱动与工件力，不能作为“更软所以会更贴合”的依据。若目标是提高尖端贴合，应优先在同任务下依据新2→4域结果讨论局部结构柔顺性、相对介质/正则项或行程；不同时改变多个因素。旧soft001曾在E减半时γ/α倍增，保留绝对介质/kr，因此是相对刚度实验，不能拿来证明本统一缩放定理或保证更贴合。

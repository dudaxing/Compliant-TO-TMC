本比较保持 h=1 mm、E=1 MPa、nu=0.3、gamma=alpha=1e-6、Lr=80 mm、工件/端口/目标路径及数学入口一致，只增加右介质域。峰值总 Fy 与间隙接近，但低载段相对变化、水平分量与材料/Hu 分解仍依赖域宽；只有一次 2→4 mm 对照且未预定义收敛容差，因此不能宣称全路径域收敛。最近的低成本功能工作可先整理现有 JSON 的紧凑响应并显式暴露初始化/路径；若下一步要求可转移的全路径夹持力，再固定其余条件做一个额外余量值，而不同时改变 E、gamma 或网格。

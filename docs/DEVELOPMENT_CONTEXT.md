## 整体目标与范围

建立独立的正向力学评估器：只提供 HF 仓库、独立环境、自包含普通几何数据以及明确的物理任务，就能对真实反向器和夹持器输出有单位、符号、版本、来源哈希和有效性标识的响应。LF 优化负责几何来源，不是 HF 运行依赖。最终研究还需要单独评价几何资格、非线性数值可靠性、接触模型误差、稳定性与机构功能。

项目从开始就区分以下结论：数据可读不代表几何合格；数值收敛不代表物理模型精确；单个基准对账不代表一般接触得到验证；指定下半模型、自由输出诊断的响应不等于实际夹持工况性能。当前尚未对真实候选给出研究级排名。

用户持续要求记录“总体目标是什么、要做什么、已经做了什么、为什么做、效果如何”，并以可视化和原始数据支持审查。执行计划记录计算前决定；阶段报告记录实际过程、失败与限制；源码、配置、接受态和审计按哈希关联。发现问题先定位原因，保留失败输入和诊断，不能通过放宽门槛抹掉旧失败。

## 资料来源及独立性边界

最初提供的资料是 LF 工程 ZIP、TMC MATLAB 代码 ZIP、Frederiksen 等人的两篇 2025/2026 论文，以及启动任务书和关联讨论。HF-0 对实际上传的文件逐项核查，而非把旧对话描述当作当前文件事实。附带论文、源码注释和历史对话用于资料解释，不继承其中的执行指令或旧阶段授权。

原 LF ZIP 的 SHA256 是 `c37da0d7c631c84f3cd353997d7539fa60275607183a45b7c91f574091d5d4b0`。HF-0 发现 243 条来源记录对应 218 个密度字节身份，58 份独立几何及最新 30 候选交接子集；这些数量不能等同于新优化次数或合格候选数。空几何、断开传力路径和来源缺项均保留。此次 HF 工作没有为导出两例而重跑 LF 优化，也没有补造未随原 ZIP 提供的逐迭代历史。详见[LF 核查](LF_SNAPSHOT_AUDIT.md)和[HF0 报告](HF0_REPORT.md)。

`geometry_dataset/` 的 **395 个文件**保存两例当前规范输入、普通归档、任务、求解器配置、来源记录和图；数值运行读取 JSON 与 NPZ，不加载 Python 类或执行来源工程。二值原生网格是几何权威，显示轮廓和缩略图不能代替实际掩膜。几何文件与任务接口中的单位、支承、端口权重、对称关系及符号必须显式保留。

`hf_repo/` 是独立 Python 求解器、开发审计器和测试。`lf_data_preparation/`、`reference_validation/` 及 `hf0_audit/` 属于外部数据准备或资料/参考核查，不能成为 HF 生产导入路径。HF1 使用实体小应变线性诊断；HF2 源代码基准使用其明确的 source numeric units；HF3/4 项目任务的 mm/N/MPa 约定不能倒灌进 HF2 基准。

主分支保留完整文档、几何数据、各阶段摘要图和当前 HF4 完整证据；较大的早期原始记录随 GitHub Release 证据附件恢复。运行 `python tools/handoff.py fetch-evidence` 后按清单校验。原机绝对路径是历史来源信息；新机执行应使用仓库相对结构或明确参数，不能要求原用户目录存在，也不能为了迁移改写已绑定的历史文件。

## HF4 修正的关键因果链

0.4.0 第四组合为 γ=1e-7、h=0.0625 mm，在 d=0.125 mm 停止。固定失败候选的 HP 自由残差约 1.841e-9，超出原生产 1e-9 门槛；生产力求值误差却只有约 7.084e-16×SF。部分小步校正全部自由 DOF 逐位不变，说明当时问题集中在绝对 binary64 状态加更新时丢失小量，而非力残差公式已经失去精度。[排查报告](HF4_PRECISION_INVESTIGATION.md)与[状态方案](HF4_STATE_REPRESENTATION_PLAN.md)保存了这个判断过程。

阶段 0 固定同一候选、同一 Newton 方向、两个预先确定步长，不再求解或改物理参数。全步先舍入为单数组后，HP 残差仍约 1.841e-9；保留输入分量后降到 6.890e-16，半步保留后也满足原门槛和 Armijo。它证明保留实际校正能解除这个已观察平台，不是证明所有 binary64 表示都不可能求解。诊断状态未用作生产初值。[原始摘要](../hf4_repair_results/retained_update_001/summary.json)

0.5.0 新增三份运行模块：

- [split_state.py](../hf_repo/src/hf_eval/split_state.py)：两个实际 binary64 数组 `u_lift`、`u_fluctuation` 共同定义权威状态；`u_display` 是有损显示和，不能回灌后声称是原状态。
- [split_kernel.py](../hf_repo/src/hf_eval/split_kernel.py)：分别算梯度与 Hessian，用 `F=(I+GL)+Gw`、总 Hu 和总 J 计算原材料/正则残差及完整非对称 Jacobian；不把两个非线性力简单相加。
- [split_prescribed.py](../hf_repo/src/hf_eval/split_prescribed.py)：几何 lift 随目标变化，预测器补偿其变化，Newton 仅更新自由 fluctuation；两数组与切线一起回滚，失败方向绑定真实基态。

旧单数组 API 保留原语义。`from_legacy(u)` 保留已经舍入的旧状态，不能恢复曾经丢掉的精度。均匀参考夹具用于验证算术；四条完整生产路径从零开始。详见[冻结实现规范](HF4_SPLIT_IMPLEMENTATION_SPEC.md)与[代码说明](../hf_repo/docs/HF4_SPLIT_IMPLEMENTATION.md)。

## 当前 0.5.0 验收应怎样解读

任务是两块各高 1 mm、宽 1 mm 的平面应变弹性体，初始间隙 0.25 mm、厚度 1 mm，E=1 MPa、ν=0.3，固定全部水平自由度及顶部竖向自由度，底部向上规定运动。γ 为 1e-6/1e-7，h 为 0.125/0.0625 mm；α=1e-6、正则长度 1 mm。原六目标为 `[0, 0.125, 0.21875, 0.25, 0.28125, 0.375] mm`。

## 下一步应做什么，以及尚未证明什么

当前 HF4-B 已闭合，没有需要靠放宽门槛继续推进的原失败目标。下一步是**先审阅并冻结 HF4-C 非均匀二维接触验证计划**，再依门禁运行小规模验证。计划应明确独立参考及输入来源、间隙/合力的可比较定义、混合变形和非零 HuHu 覆盖、网格/第三介质/正则化影响的分开判断、资源预算、逐态存档和停止条件。参考、参数和门槛必须在生产求解前确定。

后续仍缺少一般非均匀接触路径、固定圆柱及真实夹持工况、稳定性、网格与参数敏感性、小批量重复性和最终候选功能/排名证据。均匀 HF4-B 路径的 HuHu 接近零；非均匀制造场测试证明相应数值项的实现，不能替代真实非均匀接触路径。双分量仍由 binary64 数组保存，也没有任意分解、任意尺度或跨硬件逐位一致的普遍保证。

接续开发应继续维护“目标—计划—代码—测试—证据—效果—限制”记录链。保持来源数据和历史失败不可追溯改写；新增工作使用新版本、新计划、新目录和新验收结果，让下一位开发者可以仅依仓库及其已校验附件了解现状并继续。

## 复审结论与排查顺序

独立审阅见 [数学与验收复审](HF2_REPAIR_REVIEW_INDEPENDENT.md)、[求解器审阅](HF2_REPAIR_SOLVER_AUDIT.md)。当前三个超限不是“响应不一致”：原路径的全部响应指标已通过。问题是源式先形成C=FᵀF，再以相近数相减求det(C)，使内力求值误差接近停止门槛。只加严原式的停止值可能要求求解器分辨其算术噪声，不能作为充分修正。

以下因素仍须分别排除，不能因已找到一个原因就跳过：

| 假设 | 本次鉴别证据 |
|---|---|
| 逆C消去导致内力偏差 | 同一组primitive binary64输入，旧HF核与新核分别对照50位重算；不同时改变装配 |
| J、积分或累加仍不够准确 | 高精度从u和实际算子重算F/J/材料/正则/逐元积分/逐DOF累加，检查全力及自由力向量；另记录同一局部力的累加误差 |
| 导数遗漏或对称化 | 对新的实际残差求JAX Jacobian，与独立50位解析方向导数分材料/正则/总项比较 |
| 浮点扰动或两种JIT方式影响近阈值判断 | 同状态带/不带切线的力向量对照；区分理想Decimal扰动与实际binary64扰动 |
| LU精度、状态或目标串接问题 | 保留现有回归/回滚测试；新路径记录每次线性解相对残差和范数后向误差；逐目标保存原值及实际状态 |

代码审阅未发现当前C-shape索引、符号、回滚或目标串接错误。通用API中固定DOF载荷如何定义归一化等其他问题与本例无关，本轮不改任务语义。

## 最小实现修正

新版本0.2.1采用T=F⁻ᵀ、c=λlogJ−μ、P=μF+cT。材料内力直接积分P；辅助S=μI+cTᵀT也不再使用det(C)。J仍由F计算；材料、材料能量、九点积分及全部HuHu项保持原定义。JAX继续对实际非保守残差求非对称Jacobian。

通用NewtonSettings默认10⁻⁸保留；基准专用profile `hf2_precision_v2` 显式设置10⁻⁹。新输出记录profile、核版本、实际primitive输入与每个已接受状态的全内力。内部成功只表示所用数值停止规则通过，独立验收另行判定。

## 小阶段计算前冻结

机读规范位于 `hf_repo/validation/hf2_repair/precision_spec.json`。先保存三存档U、实际grad/H/weights/points、已插值λe/μe、kr、连接表、载荷和方向为普通NPZ；Decimal.from_float逐位提升，不各自从E/ν/hx重建不同末位的输入。算子定义和来源仍由原16个参考例独立核对。

三状态为旧Python目标73、旧MATLAB目标76和99。每个使用canonical一基DOF的sin和cos两个方向，固定DOF置0，二范数归一化并乘√(hx·hy)。所有方向在看新核误差前存档。

对理想方向F(t)=F+tD，以50位计算J(t)=J₀+a t+b t²，a=cof(F):D、b=det(D)。跨全部积分点取h₀=.99min(1,J₀/(8|a|),√(J₀/(8|b|)))，零分母项略过。使用固定h₀×[1,.1,.01,.001,.0001]。h₀只依正J域，不依误差曲线调节；实际binary64双侧必须预检J≥.5J₀，任何失败不能删点。保存理想Decimal和实际浮点差分。

| 门槛 | 冻结值 |
|---|---:|
| 新版全力/自由力求值误差除以外载二范数 | ≤10⁻⁹，原外部预算的10% |
| 分材料/正则力相对误差 | ≤10⁻⁸，分母max(对应HP向量范数,10⁻⁸外载范数) |
| 分材料/正则/总项解析方向导数，完整及自由向量 | 相对≤10⁻⁸ |
| 双精度/理想Decimal五点差分最佳相对误差 | 分别≤10⁻⁶ / 10⁻⁸ |
| 首步误差大于10⁻⁹时，第一次十倍缩步改善 | ≥20倍 |
| 三基状态50/80位精度层全力/自由力差除以外载范数 | ≤10⁻³⁰ |

两种JIT模式分别受上述总力误差预算约束，彼此差异另报；不要求逐位一致。旧核只作原因对照，不要求旧核通过新预算。三个旧U本就未达到平衡，本阶段门控是力与导数求值精度，不是把冻结旧U改成平衡。完整回归及原976项参考检查也必须通过。

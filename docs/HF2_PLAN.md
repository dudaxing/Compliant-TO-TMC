## 2. 固定的实现路线与职责

采用单一 Python 生产实现：NumPy 管理普通数据与映射，局部 JAX float64 计算每个 8-DOF 单元的实际残差及位移 Jacobian，SciPy COO/CSC 装配并用一般稀疏 LU 解 Newton 方程。CPU 为唯一执行设备，不维护 Java 或另一套完整非线性实现。

JAX 仅用于单元核；不对二值几何求优化梯度，不把全局稀疏求解搬进 JAX，不声明加速。HF-0 曾在系统 Python 3.13 / JAX、jaxlib 0.11.0 上得到 CPU、float64 冒烟结果；这不代替 HF 自己环境的验证。授权后先核对当时官方安装/API 文档和实际 wheel，再在 HF 独立环境锁定精确版本，记录 `jax_enable_x64`、设备、输入/残差/Jacobian dtype。出现 float32、不可重复安装或不支持平台即停止该实现环节，记录问题；不悄悄切换低精度或第二个完整技术栈。

允许修改 `hf_repo/` 中新非线性职责、相关测试、受限基准入口、状态/结果扩展及独立依赖锁定。现有 HF-1 线性入口和数据身份规则继续接受回归测试；新 TMC 配置使用明确的新版本，不能让旧 `solid_linear_q1` 接受不同物理语义。

MATLAB 参考驱动放在工作区的 `reference_validation/matlab/`，**位于 HF 仓库之外**。它读取只读源代码副本，输出普通 JSON/NPZ 参考数据；原始 MAT、日志、源文件哈希留在参考区。HF 仓库可携带少量已经生成的纯数字夹具，不携带 LF、MATLAB 源码或调用它们的必需测试流程。重新生成参考数值需要开发环境，安装/运行 HF 不需要 MATLAB。保留原作者声明，仍不把上传参考代码自动赋予开源许可证。

## 6. 计算前冻结的验证量、尺度与容差

这些是**实现一致性容差**，不是接触物理误差界。授权后在运行新内核之前将下面案例与阈值写入版本化测试定义；不根据已见新结果放宽。超差先检查公式、坐标映射、误差阶、条件数和参考有效性；未解释就停在该环节。

| C-shape 单方平衡 | 每个已接受共同目标 λ，检查 J>0、有限数、固定 DOF、自由残差 | `norm(r_free)/norm(λF0)≤10⁻⁸`；全固定零位移误差 ≤10⁻¹² Lx；全局合力不平衡 ≤10⁻⁶ max(norm(λF0),3λ)，尺度保持 source units |
| C-shape 跨语言 | 原100目标 λ 的全局 U、支承反力、六个加载节点位移、J 场、分域材料能量；MATLAB基准返回点有效才可比较 | U相对差 ≤10⁻⁵，位移分母下限10⁻⁶ Lx；反力与材料能量相对差 ≤10⁻⁴，分母下限各自源参考尺度10⁻⁸；J场相对差 ≤10⁻⁵且最小J绝对差≤10⁻⁶；逐点报告，任一目标超差不能称整条路径一致 |

方向差分表中的 `Ltest v` 是长度单位的扰动方向；材料/非仿射单元样本固定 E=100、ν=0.3、α=10⁻⁶，并分别取 γ=1、10⁻⁶。固定场和差分两侧若不满足预设 J≥0.4，要先纠正测试定义的录入错误或说明原因；不能在运行后任意筛掉困难方向。

C-shape 的 Newton 迭代次数作为诊断量记录，不作为跨语言完全一致的硬条件；稀疏求解顺序、收敛阈值附近舍入和新增合法性回溯可能改变次数。若安全策略改变了路径采样，新增子步与原100目标分开保存，只在共同目标比较，并报告触发原因。

## 7. 有限而必要的求解保障

HF-0 已实测原源 J<0 返回复数、J=0 返回非有限数、F0=0 时 NaN 绕过失败比较。这些直接支持本阶段加入以下保障，不需先发生真实候选失败。

1. 每次评估先算全部单元/9积分点的 J；J≤0 或非有限时拒绝试探，不取绝对值、不截断 J、不改变材料。残差、切线、线性解和归一化量显式检查有限性。
2. 保留已接受的 U、λ；Newton 修正属于试探状态。载荷控制使用非零参考载荷尺度；λ=0 不沿用 `0/0` 分母，而使用明确的基准力尺度并报告零加载平衡。
3. 首先试全 Newton 步。发生非法 J、非有限量或真实残差不满足下降规则时，才按固定回溯规则处理：步因子1、1/2…2⁻¹²，残差平方作为判据，Armijo系数10⁻⁴；不用不存在的总能量作线搜索势。记录每次拒绝原因与额外核调用。
4. 原目标步在25次残差检查内失败，则回滚。可按事先固定的区间二分，最多4层，最小 Δλ=0.01/16；不得改变最终目标 λ=1。子步不是新的物理任务，也不能代替未达到的共同目标。
5. 记录源策略与安全策略版本。MATLAB原函数没有这些保障；若参考与新策略出现不同分支、参考失败、持续条件恶化或不能解释的对账误差，停止完整基准并交付失败证据，不临时调 kv、α、E、载荷或容差追求收敛。

不引入弧长、动力学、伪时间阻尼、自动几何修补、候选间热启动或“收敛即稳定”的结论。若基准需要超出上述策略，应先报告已定位的问题，再提出下一次有限修订。

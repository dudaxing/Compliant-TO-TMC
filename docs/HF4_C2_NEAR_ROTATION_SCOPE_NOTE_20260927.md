# 近旋转制造场结论的范围勘误

2026-09-27 主干整合补充。本文不修改历史报告或数值记录，也不引入新计算。

[P1/稳定 F 原报告](HF4_C2_P1_AND_STABLE_F_REPORT.md)的摘要与 §3.3，以及[验证目录历史说明](../hf4_c2_stable_f_validation/README.md)，曾将三个近旋转场的失败概括为 binary64 分辨率限制；原报告还使用了“任何 binary64 实现”都无法达到该力门的表述。这一概括超出了已有证据，应采用以下限定解释。

## 已经观察到的事实

- 三个近旋转制造场的新旧内核完整力检查均失败，制造场仍为 30/33 通过，原门槛与 SF 不变。
- 候选 F/G 的报告误差在约半 ulp 内，生产 J 为 1；权威双数组定义的 HP J 仍有约 `6.84e-17` 的非零小增量。正确舍入的单个 float64 J 不一定保留后续所需的小量。
- 当前直接应力表达式存在强消减；两个矩形网格还有 Hu 信息损失及极小正则力失败。单位网格 Hu 与参考一致，材料力仍失败。
- 这些节点由浮点三角函数和运算生成，属于近旋转输入，并非精确无应变刚体状态。不能据理想旋转应力为零而把本次输入的非零力或 Hu 归零。

这些事实说明当前完整求值链未满足冻结门，不能推出所有 binary64 算法不可能满足该门，也不能已将完整误差百分之百分配给某一个环节。F/G 最终舍入、小不变量、J/对数/应力算术、Hu 和装配的贡献仍需按预定固定场反事实分段核对。

## 后续采用的判断

以[独立失败分析](HF4_C2_STABLE_F_FAILURE_ANALYSIS.md)和[独立复核报告](HF4_C2_INDEPENDENT_RECHECK_REPORT_20260927.md)为当前解释。补偿展开、稳定小不变量、代数等价应力表达式及 Hu 补偿仍是候选研究方向，而非已实施的修复。不得因原文称“分辨率限制”便豁免失败或调整门槛。

该勘误不否定保存态 63/63 的改善，也不撤销 v4 单条细网格补测的 21/21 状态与 651/651 检查通过；它明确这些结果的覆盖边界。默认内核仍未切换，制造场未全部通过，一般接触与 HF5 仍未完成。

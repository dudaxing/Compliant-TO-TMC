## 冻结方程与判据

力方程`r=fint(u)+k*bout*(bout^T*u)-bin*R=0`，约束`g=bin^T*u-d=0`，R为执行器对结构的力。用实际非保守残差Jacobian构造非对称KKT，固定DOF为零。预测满足均值，Newton修正维持约束；回溯以同一次试探固定尺度的真实力残差下降为据，非法J拒绝而不修补。

`dscale=max(abs(d),1e-6 mm)`。生产停止尺度为`SF=max(norm(fint_free),norm(bin_free*R),norm(spring_free),1e-8*E*t*dscale)`，内部力残差≤1e-9，平均约束≤1e-10*dscale。独立HP从实际binary64 primitive/u/R/bin/bout/k重新计算所有力项及均值；以HP力项得到共同SF，验收HP自由残差≤1e-8、生产全/自由内力误差≤1e-9*SF。不得提升预舍入F/J/q/载荷乘积替代HP重算。合力尺度=max(支反力范数+输入力范数+弹簧力范数,SF)，相对误差≤1e-6。50/80位力差/SF≤1e-30。

两例各从零计算d=1e-3、1e-4、1e-5mm；第一层比较qout/d、R/d、实体附着u/d与自身K0：最小幅值相对误差≤1e-4；首末误差比≥5，首点≤1e-6则记录舍入平台并免趋势判据。尺度下限继承提案：q/d为1e-6、R/d为1e-8Et、u/d为1e-6 sqrt(n_s)。第二层3x3/2x2实体线性刚度相对差≤1e-11，同任务响应≤1e-9；K0对实体模型的差不强迫接近0，>5%标model_bias_requires_followup。若运动方向或主导刚度被模型项改变，先解释该现象再决定完整路径，不转成性能排序。

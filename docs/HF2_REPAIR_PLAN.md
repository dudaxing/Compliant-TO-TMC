## 第一阶段：稳定表达与精度预算

只做局部、小网格和存档状态验证，暂不重求解完整路径。

1. 冻结新数值版本，采用直接第一Piola或其他避免形成病态逆C的等价表达。保持原Neo-Hookean弱式和全部HuHu项，对**修正后的实际残差**重新计算非对称一致Jacobian；不能只换残差而沿用未验证的旧切线。
2. 重用现有刚体、仿射、16个小状态、方向差分和装配验证，不改变已有正常状态门槛。另纳入三个冻结强压缩状态，在计算前规定扰动方向、正J范围和高精度导数参考；不在见到结果后筛选方向或步长。
3. 计算前区分外部平衡误差、浮点评估误差、Newton内部停止裕量与后处理误差。外部平衡仍≤10⁻⁸；拟先检验内部10⁻⁹停止是否提供足够裕量，再将成立的方案作为显式solver版本冻结。该内部试点不能替代或放宽外部门槛。
4. 拟把表达式评估误差预算限定为外部允许自由残差的10%，逐状态比较全力/自由力向量与高精度参考；不混用“向量差的范数”与“两个残差范数之差”。强压缩切线仍须验证方向导数。精度预算不成立即停止小阶段。

第一阶段通过后，才审阅并授权一条修正Python路径。几何、材料、九点积分、100个原目标及总载荷−3保持不变；只运行一个新版本，不作参数扫描或无限重试。

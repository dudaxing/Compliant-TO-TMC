# HF4-C2 局部反力排查计划

日期：2026-09-21。用户要求认真排查 HF4-C1 遗留的 TMC 局部负节点反力。整体目标仍是建立可独立核验的 HF 力学评估器；本轮任务是解释已观察现象并用对照计算区分原因，不以总力接近作为一般接触验收。

## 已知证据与可证伪问题

C1 的十条选定路径通过数值/几何审计；四个 TMC 末态出现 18 个负顶边节点反力。它们在初始实体横向范围外，但这不构成实际接触区域判定。原始数据、50/80 精度失败及后续修正均保持原样。

1. 是否存在力符号、梯度/Hessian、材料系数、反力分组或装配错误？用独立单元重装、制造场和分项虚功判断。
2. 域内弱式节点反力与边界第一 Piola 牵引投影有何差额？分别记录材料、正则、单元界面/体残差和积分影响，不将两种读数互相替代。
3. 全顶面正则合力接近零是物理失效还是离散恒等？对任意 Q1 状态推导并制造场检验。
4. 负项主要受网格、背景域宽度还是外底边驱动影响？一次只改变一个因素，不调 alpha/gamma 来追求净力吻合。

## 执行顺序和证据约束

第一步仅读取 C1 的四个已审计末态。新独立 Decimal 80/120 单元重装、边界牵引和虚功诊断在计算前保存各自计划与阈值。边界牵引同时区分三点 Simpson 与增加阶数的 Gauss 积分；有限阶差异只作观察，不自动称为积分收敛。所有图明确参考/当前坐标、力的符号和单位。

第二步为独立公式/代码审查及无求解的边界实验设计复核。已有非均匀外区 profile 仅在原域保持整底边零均值；直接扩大域宽会额外改变加载，故本轮域宽判别只使用均匀加载。

只有保存场重装和公式核对通过，才冻结新的有限 FE 对照协议。候选为：原均匀任务 h=0.0625；h=0.125 时 padding=2.5；h=0.125 时仅实体底边驱动、外底边竖向自由。原两网格数据作对照。物理实体、间隙、材料、参考长度、刚面、加载目标和求解/审计阈值保持；外底边自由时整底面平均位移改为观测量，实体底面平均位移仍须等于输入。

实现和无求解预检可以提前准备。具体 FE 准入、预算、停止条件、代码/协议哈希须在新求解之前另行冻结；候选清单本身不代表已启动计算。任何失败都保留，不覆盖原路径或原审计。

最后按“问题—假设—实现/公式—数值证据—判断—剩余范围”形成报告和对照图。保存场诊断不冒称新的 FE 验收，局部离散反力不冒称已验证的接触压力。本轮不开展 HF5、真实夹持器或设计池排名。

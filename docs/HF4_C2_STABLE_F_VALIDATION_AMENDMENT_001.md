## 2. 新增：不设门的旧内核对照

对每个制造场方向与每个保存态，在**同一输入、同一 HP80／HP120 参考、同一 SF** 下，用未修改的旧 `split_kernel`（`p26_q1_split_displacement_v1`，按生产方式编译，不加严格编译选项）重复同一组比较，结果写入 `legacy_control`，**不进入任何 case 的通过判定**。

作用是把两类失败分开：只有旧内核失败、候选通过的，是 F 构造误差被修复；两者同样失败的，与 F 构造无关（例如 binary64 本构求值的分辨率）。在保存态上，旧内核对照还应在同一次运行中复现历史细网格末态的生产失败（`1.0943792164e-11`），用来核验测试装置本身。

## 3. 事先写明的预期：近刚体制造场的力检查受分辨率限制

`near_rotation` 在网格上施加转角 1/32 rad 的线性位移场，|G| ≈ 0.031 > 0.01，走直接分支 `P = μF + (λ ln J − μ)F⁻ᵀ`。二进制 64 位输入下 F ≈ [[c, −s], [s, c]]，J − 1 = c² + s² − 1 只有几个舍入单位，精确内力约为 (λ + μ)·2⁻⁵²·O(1) ≈ 1e-14 N 量级；任何 binary64 实现计算 μF − μF⁻ᵀ 时都有约 μ·ulp(1) ≈ 1e-14 的绝对误差。已声明的制造场 SF 下限为 1e-8·100·0.125 = 1.25e-7，因此总力门要求绝对误差不超过约 1.25e-18，分量门的尺度就是约 1e-14 的参考范数本身。这些门对任何 binary64 实现（新旧内核都一样）都不可达；它们不检验 F 构造。

按"不因观察结果调松门槛"的规则，本修订**不改门、不改 SF、不改变这一 case 的判定**。若该 case 出现 `not_pass`，报告将按事先写明的这一分析、并结合旧内核对照解读，同时如实记为制造场阶段未全部通过；是否据此修订未来的制造场 SF 定义，另行决定，不回改本次结果。

# 工件几何定义预览

本目录只展示下一功能阶段的几何定义，帮助人工检查尺寸、位置、对称关系及原生网格覆盖。它不构造有效 HF 模型，不计算位移、接触力、压力、切线、平衡或卸载，也不修改原 LF/HF 几何及材料。

候选一为正方形：边长 16 mm，中心 (70, 40) mm；实际下半区域为 [62, 78] × [32, 40] mm。候选二为同中心、半径 8 mm 的圆。两者下方解析最低点 y=32 mm，相对原夹爪上边界 y=30 mm 的初始间隙为 2 mm。圆的原生网格表示是台阶近似，不能把它当作精确圆边界。采用单元中心位于解析形状内部的规则，并独立记录其单元、关联节点及拟固定 ux/uy 与原固定自由度的并集和交集。

y=40 mm 是原下半模型的对称线。线上方轮廓仅为完整对称工件的镜像示意，不表示已生成上半分析网格。图中的 +x 输入与 +y 输出箭头只表示参考方向，不表示计算所得力；原输出仍是自由测量端口。

# F16 Horner192 保存诊断视图：新独立执行卡

目标：显示已关闭完整力入口的原始机械量、辅助能量失败位置及新旧首坏位置，供人工检查。输入仅为两份冻结诊断、原始 F16 坐标/连接及其保存数组。不得重新计算力、切线、HP、全局组装、反力、求解或几何距离。

一次执行 `launch_phase.py render`。helper120秒、outer120秒、采样进程树8GiB；包括导入、校验和保存。协作停止，不是操作系统硬内存限；首错停止、无重试、无force。图保存至新render_001，不改任何旧图。

输出：2880×1980 PNG、3200行CSV、字段/输入/输出SHA元数据及独立实际审图。三图为保存局部8DOF力的欧氏范数，采用共同N色阶；1e-30N只是显示下限，不改数据。能量NaN不填零。空间坐标为参考坐标，不是新的变形或接触测量。完整入口仍失败，原始finite字段未获HP资格；诊断视图不恢复力或平衡资格。

后续最小功能步骤为新显式机械量入口与同一F16 fresh HP80/120力及切线作用对比；旧完整字段合同保持严格。

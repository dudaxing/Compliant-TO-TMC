# Cycle009：完整九目标循环与可选分块切线

## 整体目标与本轮任务

整体目标是实现独立 HF 非线性正向力学评估器：从明确的原生几何、材料、支承、平均位移端口和工件定义出发，求解实际加载与卸载路径，保存可追溯的位移、力、三分量切线及平衡证据，并用真实倍率的结构与力学图供人工检查。后续接触或夹持结论必须有相应物理证据；本轮没有开展 LF 优化、批量标签或排名。

本轮解决 cycle008 在原预算内未完成返回零目标的问题。保留同一粗网格、固定方形工件、原材料与边界、完整行程和全部数值门，只增加显式可选的分块切线执行方式。默认 `tangent_mode="full"` 保持，只有明确选择 `chunk256` 才按 256 单元块执行。

## 为什么优化切线，为什么保留九目标

cycle008 请求的原路径为：

`[0, 0.5, 1, 1.5, 1.75, 1.5, 1, 0.5, 0] mm`

它因 `time_limit` 关闭，保存了前八态，最后接受位移为卸载 0.5 mm，返回零未接受。其 F63/63、T36/36 完成，没有力或切线范围异常；失败证据原样保留，未启动该失败卡的 HP 参考。

此前曾建议删除回程 **1.5 mm** 观察点以减少目标数。本轮**未采用**该建议，完整九目标、卸载次序和返回零终点均保留。cycle009 从独立零状态启动，没有接续 cycle008 状态或重试其关闭卡。

旧实现同时广播全批单元的八列 DD 切线，产生较大的临时数组。新实现只分块单元维度：全批算术分支仍选择一次，单元内积分点与归约顺序保持，三张完整张量在末尾统一检查并转换，CSC 仍一次全域组装且不对称化。原控制器、导数表达式、Armijo、回滚、分步、尺度和门均未更改。

九态按实际 index 保留，初始零与返回零没有按位移或状态身份去重；没有二分、失败尝试或范围观察。保存过程没有新增 F/T。213 科学协议绑定、68 源码胶囊、63 输入及原 27 字段模型身份保持。前八态的 `state.npz`、`forces.npz`、`tangents.npz`、`total_matrix.npz` 共 **32 个完整文件**与关闭的 cycle008 原字节完全相同。因此实现改进没有改变前八态的物理解，只使完整原任务在预算内完成。

## 实际物理数值

模型仍为 1 mm 原生网格、3200 单元、3321 节点、6642 DOF；固定 376、自由 6266。下半固定 16 mm 方形工件位于 `[62,78] × [32,40] mm`；E=1 MPa、nu=0.3、plane strain、厚度20 mm，gamma=alpha=1e-6、Lr=80 mm，输出和输入辅助弹簧为零。输入为三节点平均 +x，输出为自由三节点平均 +y。

| 量 | 1.75 mm 峰态（index4） | 返回零（index8） |
|---|---:|---:|
| 输入 R / N | 0.3969477463933483 | −5.4942929453479064e−30 |
| 自由输出平均 +y / mm | 2.0346869443877553 | 3.1540569513240884e−29 |
| 最大节点位移范数 / mm | 2.772376810150279 | 3.3202704746807254e−28 |
| 全域 / 原第三介质 minJ | 0.02808043969551585 | 1 |
| 原机构实体 minJ | 0.9562359128632606 | 1 |
| 最大绝对 Hu 分量 / mm⁻¹ | 0.4698093969993863 | 2.034275059338684e−28 |

返回态的生产相对残量为 4.8696270698144145e−17，均值约束残量为 0（原界限1e−16），全局力平衡相对量为 1.3902319326045364e−16。返回态固定工件内部保存的 `F−I`、`J−1`、Hu、应力和局部力为零；下半工件弱式合力为 `(−4.407897629741671e−31, +2.985672011257475e−32) N`。这些小量是实际保存值，没有手工归零。

峰态第三介质 minJ 很低而原机构实体 minJ 接近1，必须分开解释。J 不是接触压力，Hu 也不是夹持力。

## 资格范围与尚未完成的功能

同阶段独立参考在生产关闭后启动，对每一个实际接受态重新执行 HP80/120；覆盖全部单元和实际 DOF，并沿原门验证三分量力、固定 lift 的 PORT 方向切线作用、平均约束、平衡和工件弱式力投影。初始零、卸载重复行程和返回零都单独检查。

**本轮没有新增接触、夹持、压力、辅助能量、应力 HP 或切线全列资格。** PORT 是一个声明方向；全矩阵组装检查不等于全部列的独立导数验证。辅助材料能量仍明确 `not_evaluated`。原生产结果中的 HP/equilibrium/HF 标志保持 false，新的外部参考资格另行报告；它也不回授给旧 cycle008 失败卡。

下一步物理功能应依据本次实际结果：先完成本卡已安排的区域重叠与有限工件面法向射线观测，结合真实 ×1 变形、输入输出和工件三分量力，明确还剩多少空间、最近点是否角点、返回路径是否完整；再据此规划更大行程或更具体的接触/夹持验收。暂不以小间距或非零弱式工件力直接宣布夹持，也不自动扩展到细网格、其他机构或工件。

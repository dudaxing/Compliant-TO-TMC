# 工件节点力功能：目标、实现与下一步

整体目标是形成独立 HF 力学评估器：从不可变几何和明确物理任务出发，计算第三介质大变形、输入/输出响应、固定工件受力及加载—卸载过程，并逐步完成接触相关诊断、细网格和不同工况，最终接入设计评估。HF 不导入、安装或调用 LF 力学系统。main 是唯一后续开发主干，origin 固定为 https://github.com/dudaxing/Compliant-TO-TMC.git。

用户允许探索对称方形和圆形工件，自主设置尺寸、位置及较大行程。因此现有 16 mm 方体、中心 (70,40) mm 是有记录的探索工况，不是唯一正式产品尺寸。继续向更大变形推进必须以实际求解结果选择增量，不能把“探索空间更大”理解成跳过压缩介质、平衡或几何问题。

目前 NumPy 完整分量力入口、组装、切线与平均输入位移平衡求解已实现。009 工况完整执行原九目标 0→0.5→1→1.5→1.75→1.5→1→0.5→0 mm；63 次力、36 次切线、一次求解入口，独立 80/120 位参考 18 次及 174111 项原检查通过。可选 chunk256 切线仅切分元素批次，保留默认 full、数学、原门和数值。008 的原时间限制失败保留，009 并未删去卸载 1.5 mm 或返回零目标来缩小任务。

本轮补齐“合力作用在哪里”的功能。既有每个接受态已保存材料、Hu 和总全局弱式力，因此增加一个纯读取 API 和 CLI：选择所有固定工件节点，对全局内力取负得到作用于工件的节点力；分别输出三个原始分量，以 fsum 求合力，并核对保存的工件合力和每个节点保持反力。总力独立保存，不能用材料+Hu 覆盖其原始值。API 仅依赖 NumPy、fsum 和已有纯 Q1 边界拓扑。

物理边界、数学对称截面、两者共有角点和内部节点构成四个互斥组。共有角点只计一次；底部两条物理面相交的角点仍属于 physical_only，保留边表而不人为拆分角点力。所有节点都保留，不仅画外边界，也不将内部或截面节点丢掉。四组重求合力的 8eps×sumabs 容差只检查浮点求和的一致性，原物理和高精度验收门没有改变。

节点力的单位是 N。绕 (70,40) mm 的力矩采用普通浮点乘积后 fsum，单位 N mm；它是保存节点量的派生结果，未新增高精度力矩资格。节点弱式力不是面压力，也不能唯一归属于某个相邻面。数学对称截面力不能作为物理接触面压力；对称上半体由反射关系另行解释，半模型纵向合力不能当完整镜像净力。

本轮只有保存数据解析测试、九态节点读取和绘图。没有新的力、切线、组装、平衡求解、JIT 或 HP 计算。零机械调用的依据是源码与实际模块导入闭包；未装置机械 hooks，不把静态来源证据称作受 hooks 监测的计数。继承的 009 独立参考仅限其原本声明的接受状态、力、一个 PORT 方向、组装、平衡和工件合力；不扩展为一般接触、全列切线、压力、应力、能量或力矩资格。

每一正式阶段仅一次，helper 120 s / outer 150 s、树 RSS 采样上限 8 GiB；包括导入，采用合作停止和采样，不是 OS 硬内存限制。先等测试实际终态通过，再读力，读力终态通过后才画图。首错关闭整卡，保留实际部分证据，无原卡修复、重试、force 或资源延期。执行前阅读路径探查和 AST/source compile 属作者准备，未开启任何测试、观察或机械阶段。

下一步应依据当前 1.75 mm 状态：底面首次外向法向射线距离 0.07671066678990902 mm、左面 2.8327754289207783 mm，介质最小 J=0.02808043969551585。底面接近但左面远离，不能认定双面夹持；近接触压缩已明显，因此优先同方体小幅新增峰值并完整卸载，不直接跳到很大的位移。具体峰值、目标序列、时间预算和停止条件须在新的物理任务卡冻结后执行，再决定圆体、尺寸/位置变化和细网格工况。当前尚未建立或执行新的更大行程平衡任务。

自由工件、有效夹持/压力定义与资格、细网格/圆工件平衡、应力/能量高精度验证以及 HF5 批量标签尚未完成。整体项目仍在进行；本轮完成的是可直接复用的保存节点力观察入口和实际作用分布可视化。

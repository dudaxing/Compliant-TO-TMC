# C-shape 逐目标独立对账与未通过项

两方均完成唯一配置的 100 个原定目标至 λ=1；全部 100 个目标的源码对账指标
均通过。独立平衡复算发现三处自由残差超过固定的 1e-8 门槛，因此完整独立验收
保留 `not_pass`，不将路径到达终点或响应一致改写为全部验收通过。
最终机读判定为 `cshape_final_decision.json`：HF-2 `partially_complete`，源码
路径一致性 `pass`，严格独立基准 `not_pass`。该文件引用并散列原始比较、
高精度取证、恢复后的冻结规范与比较时规范；仅汇总现有证据，没有重算路径。

除最后一项外均为带冻结物理下限的相对误差，具体分母逐目标保存在 CSV/JSON。
两方节点、单元、材料区、支承、六节点载荷及 100 个精确目标均与冻结配置核对。
没有只挑终值，没有丢弃已比较的目标，也没有比较新设计或新网格。

全部目标的固定 DOF 位移为零，J 正，分域能量和支承反力的独立复算均通过；
全局合力按 `norm(balance) <= 1e-6*max(norm(lambda*F0),3*lambda)` 判断，MATLAB
与 Python 的独立合力绝对值最大分别为 2.9851e-11 与 2.6112e-13，均通过。
合力通过不能替代每个自由 DOF 的平衡残差。

独立后处理以 `P = mu*F + (lambda*log(J)-mu)*F^(-T)` 和显式 Q1 混合 Hessian
直接计算原弱式内力，不调用生产 JAX 核或全局装配器。该后处理在冻结的 16 个
小状态下与 MATLAB 的力、J、加权能量全部通过一致性检查。

| 存档状态 | 求解器记录相对自由残差 | 独立 float64 Piola | 固定输入提升至 50 位 Decimal |
|---|---:|---:|---:|
| Python，λ=0.73 | 9.88577641e-9 | 1.06479188e-8 | 1.06444512e-8 |
| MATLAB，λ=0.76 | 8.36266945e-9 | 1.07502625e-8 | 1.07513900e-8 |
| MATLAB，λ=0.99 | 9.51843838e-9 | 1.04427774e-8 | 1.04443527e-8 |

三点的 50 位算术结果仍超过 1e-8。条件数取证显示 C 的最大条件数约为
1.18e8、1.45e8、4.28e8；原 `det(C)` 的减法消去会影响由 `C^-1` 计算的 S 和
微小平衡残差。仅离线将逆 C 的分母换成数学等价的 J² 后，F*S 与直接 Piola
自由力差由约 1.3e-9–1.35e-8 降至 3e-13–1.4e-12。该实验解释数值差异，
**没有修改生产实现、没有重求解，也没有让三个存档状态通过**。高精度仅针对
固定 binary64 输入的数值复算，不是独立物理接触基准。

# 三个存档状态的残差表达式敏感性取证

结论：直接 Piola 后处理的公式正确。源形式 `C^-1 → S → B1ᵀS` 在高度压缩的第三介质中有显著浮点消去，足以解释残差阈值附近的判定差异；但 50 位十进制重算仍确认三个状态均略超原定 `1e-8`。**保留三项超限，不修改容差，不将数值解释等同于验收通过。**

本次只读取 Python 第 73 个目标及 MATLAB 第 76、99 个目标存档；没有 Newton 迭代、线性求解、路径重跑或生产代码修改。所有力和长度沿用 `source_numeric`。

Decimal 诊断固定存档位移、梯度、积分权重、Lamé 系数和 kr 的 binary64 数值，将这些数值精确提升后用 50 位算术计算 F、J、log、exp、积分和全局装配。它是固定离散输入的高精度诊断，不是独立接触物理参考，也没有改动存档解。直接 double 与该诊断的自由力向量差为 `1.13e-11、1.26e-11、2.81e-11`，远小于源 C 逆表达式与直接式的差异。

## 代数核对与误差定位

源代码 `reference_validation/matlab/source/assembleKtFi.m:33–42,79–81` 使用

`C=FᵀF; S=λ log(J) C^-1 + μ(I-C^-1)`，再积分 `B1ᵀ[S11,S22,S12]`。

因为 `F C^-1=F^-T`，其材料项严格等价于

`P=μF+(λ log(J)−μ)F^-T; r_material=∫ Grad(N):P`。

`compare_cshape.py` 的逆转置指标、载荷符号、权重和 Q1 两项混合 Hessian 正则残差均正确。该函数与本探针独立写出的直接式自由力向量差仅约 `6.7e-14–8.1e-14`，来自正则项运算顺序。

| 状态 | min J | max cond₂(F) | max cond₂(C) | max abs(det(C)−J²)/J² | det(C) 计算的最大消去因子 |
|---|---:|---:|---:|---:|---:|
| Python 0.73 | 9.319980218e-5 | 1.08637e4 | 1.18021e8 | 3.87219e-9 | 3.53234e7 |
| MATLAB 0.76 | 8.411759806e-5 | 1.20296e4 | 1.44711e8 | 5.71788e-9 | 4.47317e7 |
| MATLAB 0.99 | 4.921634236e-5 | 2.06792e4 | 4.27628e8 | 1.93727e-8 | 1.75175e8 |

这里消去因子是 `(abs(C11*C22)+abs(C12²))/abs(C11*C22-C12²)`。最严重的行列式相对偏差都位于材料倍率 `1e-6` 的第三介质单元。构造 `C=FᵀF` 将条件数平方，再以两个相近数相减求 `det(C)`；当前观察到的偏差与这个敏感机制一致。

进一步保持同一 F、S 公式及积分不变，**仅在离线诊断中**把逆 C 的行列式分母改用等价的 `J²`：

| 状态 | 原 F S 与直接式自由力向量差 | 用 J² 分母后的差 |
|---|---:|---:|
| Python 0.73 | 1.28619e-9 | 3.17763e-13 |
| MATLAB 0.76 | 3.05188e-9 | 2.97318e-13 |
| MATLAB 0.99 | 1.34827e-8 | 1.39238e-12 |

这把主要误差定位到源逆 C 的行列式消去，而不是 HuHu、装配符号或 P/B1 的代数不等价。NumPy `B0+A G` 构造 B1 后的结果与 `F S` 接近；两处 MATLAB 状态还复现了原 MATLAB 存档残差。Python 存档与 NumPy 源形式在 λ=.73 的细小差异说明同一表达式的后端运算顺序也能改变这个临界判定；本次没有声称逐位重现 JAX 执行顺序。

## 绝对力尺度与结论边界

外力 2 范数依次为 `0.9291383105、0.9673220767、1.2600642841`；容差对应绝对自由残差 `9.29138e-9、9.67322e-9、1.26006e-8`。50 位残差分别为 `9.89017e-9、1.04001e-8、1.31606e-8`，约超限 `6.44%、7.51%、4.44%`。装配前材料单元力整体范数约 `84.1、86.1、100.3`；装配后的内力整体范数约 `8.30、8.52、10.13`。因此对较大力项很小的绝对运算差异，可以改变约 `1e-8` 的自由残差判定。向量差的范数不能与两个残差范数之差混用。

冻结计划明确要求每目标自由平衡 `norm(r_free)/norm(λF0)≤1e-8`，并冻结了源弱式。它没有明确指定必须以额外直接 Piola 后处理器作为第二套门控实现。因此可以分别报告“两个实际求解器的原残差检查与既定跨语言量比较已通过”和“新增独立重算有三个超限”。但这些式子描述的是同一个数学弱式；高精度诊断支持超限真实存在于固定离散状态，不能靠称其为额外诊断就宣称平衡具有表达式无关的 `1e-8` 可靠性。保守的阶段汇总应保留独立验收 `not_pass`/未完全通过，记录已定位的舍入敏感性。若以后修正残差表达式或增加收敛裕量，应作为显式的新验证配置另行执行，不能追溯改写本次结果。

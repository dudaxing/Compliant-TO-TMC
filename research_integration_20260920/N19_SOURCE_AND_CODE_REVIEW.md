## 2. N19实际提供的证据及不足

N的A模型只保留实体单元、去掉第三介质、alpha=0，用水平刚性面施加法向节点约束；候选节点ux自由。法向乘子为 `-f_int,y`；拉力或当前x越出有限平面的节点释放；范围内非主动候选若穿透必须重新加入。被屏蔽节点重入达到上限后报 `contact_feasibility_failed`。这是一套有明确范围的底面节点接触方法。

但A与N的TMC共享 `ElementOps/make_element_functions` 和主要 `PathSolver`。N3b修订记录已将“独立参照”收窄为接触处理层独立，不应再称整个有限元实现完全独立。

- 均匀柱A在h=0.5、0.25 mm上的接触后解析力最大相对差，实际摘要分别为 `3.4727776210274897e-13`、`3.461675390781238e-13`。仅验证该均匀柱，不是非均匀接触误差界。
- 硬区间夹持器A在160/320网格、2–7 mm有效范围内，法向力变化约−1.09%至+1.69%。N3d四个设计在5 mm的变化约−0.9%至−1.3%；原第一、第二名在细网格互换。两级敏感性不构成收敛证明，局部包络不能借给全部候选。
- A的160网格硬区间在7.1875 mm之后因有限边缘释放/重入循环停止；320网格的8 mm态虽然候选节点不穿透，却有 `0.007222851736514713 mm²` 单元边/角重叠。它说明节点互补条件不能替代实体—障碍几何检查。
- N的TMC基线alpha=1e-6在部分夹持器状态出现实体—工件重叠。alpha=1e-5在已测有效范围改善了这一现象，但初接触附近对A仍存在约27–28%的力差；不构成可移植的推荐参数。
- N记录了不同环境的路径重放、互补条件核查和Shapely交面积对照。这些是来源报告的复现证据，本次未重跑。包内Python源码未发现mpmath/decimal全路径力学审计实现；文档里的80位应力点检不能冒充A全路径HP验收。
- ZIP确实包含柱体float64状态NPZ；没有真实工件正式归档中的 `fields.npz` 或 `result.json`。本次不能从摘要与manifest宣布已重新审计N真实工件全部原始状态。
- P3的1800成员/1799有效标签以及P4a替代标签仅作为后续研究设计背景，本次未将这些标签作为O线的验证数据、重复试验或新力控制响应。

## 3. 采用与不采用

采用：独立实现实体—已定义障碍的重叠检查；在全部接受态上锁定有效前缀；未知与真实零值分开；先验证接触参照自身，再做同任务模型间比较。具体路线见 [INTEGRATION_DECISIONS.md](INTEGRATION_DECISIONS.md)。

不直接移植：N的单U材料内核、求解器残差上升政策、力尺度底值、默认容差、有限面主动集源代码或alpha候选设置。O线已有近零稳定算术和split状态证据，应持续使用。

N源码的迁移风险已作为设计依据，而非本轮待修N缺陷：`reference_row_valid`对缺失几何字段默认通过；某些记录将非主动候选不可行数量直接填0；矩形重叠主要在后处理判断；ContactPathSolver调用newton绕过PathSolver.solve的时间限制。新的O诊断避免缺字段默认有效，并由隔离进程限定运行预算。N的粘着B也只作为切向约束对照，不解释为真实摩擦上界。

A0为2×1 mm、厚度1 mm、E=100 N/mm²、nu=0.3的全实体块，kr=0；障碍为[-2,4]×[1,2] mm。顶面uy=0，底面 `uy=d*[1+a*(1-3*(x-1)^2)]`，只固定底中心ux以消除水平刚移，其余切向自由。初始即闭合，上表面法向约束只有在逐态压力非负、几何可容许时才代表单边接触。没有接触进入/释放搜索。

均匀情形的自由横向条件为Pxx=0，lambda_y=1-d；由Pxx消去压力系数后，障碍法向力为 `W*t*mu*(lambda_x²/lambda_y-lambda_y)`，也等于 `-sum(f_int,y on top)`。以参考宽度乘Piola应力，面积和符号约定正确。本分工用仅含标准库Decimal的70位Newton计算独立核对了该契约；精确十进制E=100、nu=0.3时，四个非零目标的参考力约为7.058602231427455、14.527969453407526、30.906531032409993、71.422065271689444 N。正式审计使用精确提升的已保存binary64模量，二者材料输入有舍入级区别。

非均匀底面驱动的功共轭广义力为 `sum(profile_i*f_bottom,y_i)`，与底面总竖向合力不同；后者应取bottom反力分组。顶面法向力、底面总力、驱动广义力不能混名。

## 6. split几何权威与额外只读读回复核

面积诊断用一次正确求和后舍入的变形坐标，实际最大坐标舍入约 `2.220446049250313e-16 mm`；这些坐标没有反馈给FE计算。仅有rounded交面积为零不构成任意split状态的精确无穿透证明。

本次另以Python标准库 `Fraction.from_float` 直接提升每个保存的坐标、lift、fluctuation，形成其**精确有理数之和**，未调用任何生产几何函数或FE求解器。6路径/30态逐一核对：

- 2970个节点实例全部满足 `y<=1`、`-2<=x<=4`；全部顶节点精确满足y=1。
- 2400个单元实例的四个相邻边叉积全部严格大于0，即保存状态形成严格逆时针凸Q4。
- 非顶节点的最小平面净距为精确分数 `190888414422451193/2305843009213693952 mm`，约0.08278465344765396 mm。

Q1参考单元内形函数非负且和为1，故本批精确节点上界保证单元内部也不进入y>1的障碍区域。该证明限于本批保存状态与此水平障碍，不涉及一般自接触、全域单射或曲面接触。

额外精确读回的最小可复核算法如下；数组与索引来自上述六目录保存的模型和状态。`F` 为 `Fraction.from_float`，必须先分别提升三个binary64加数再求和，不能先用float64合并位移。

```text
逐目录读取模型、状态索引、metadata及completion，核对其保存的SHA-256链。
逐索引条目核对状态NPZ的SHA-256，再读取X、lift、fluctuation和Q4连接。
对每个节点i、坐标分量k：
    p[i,k] = F(float(X[i,k])) + F(float(lift[2*i+k]))
             + F(float(fluctuation[2*i+k]))
要求全部节点 -2 <= p[i,0] <= 4 且 p[i,1] <= 1；顶节点 p[i,1] == 1。
按保存的Q4顺序取四个顶点q[j]，令e[j] = q[(j+1)%4] - q[j]。
要求四个精确叉积 cross(e[j],e[(j+1)%4]) > 0。
在非顶节点上求 min(1 - p[i,1])；累加已检查的状态、节点和单元数。
```

独立几何oracle的另一个成果见 [geometry_rational_audit.json](geometry_rational_audit.json)：报告288/288有限样本通过，其中156个精确零面积、132个正面积，最大规范化面积误差约4.21e-17。其算法为精确有理数包含点/边交点与凸包，和生产裁剪分开；本分工读取了其记录，未冒称亲自重跑了该脚本。有限样本通过不是对任意输入的通用精度界。

## 7. 允许与不允许的结论

允许的表述：在冻结参数、两网格、三个底部幅值及五个目标内，O线受限已闭合宽平面A0分支通过保存状态的生产/独立HP/解析与几何准入；两个非均匀幅值确实产生非零剪切/二阶梯度；已建立可用于下一步同任务比较的受限参照基础与诚实失效语义。

仍不能宣称：

- N环境或N固定工件路径已由本轮重现；N的1800正式标签已在O线重新验证。
- 整个A0是与O完全独立的有限元实现。它共享O材料、装配和split求解器，独立性来自另写的Decimal残差/方向公式及均匀解析契约。
- 已验证一般主动集、非接触到接触转换、有限面释放/重入、角点/侧面接触、摩擦、自接触、固定圆柱或真实夹持器。
- A0中Hu非零就等于检验了非均匀TMC HuHu正则项：本批kr=0，没有第三介质，其正则残差和对应切线项未被本批激励。
- 两级网格敏感性是收敛率或误差上界；一条确定方向的Jv检查等于验证全部Jacobian方向；数值平衡等于稳定性、材料安全或实验精度。
- 受限A0通过自动完成HF4-C/D或批准HF5排名。尚需冻结A0/TMC同任务对照、其有效路径交集及必要参数/步长/网格检查。

本轮来源审查与代码复核未发现上述限定A0结论仍需阻止发布的未闭合科学缺陷。发布说明应保留这些范围；源附件的历史关闭状态、试验规模和已有复审结果不替代本线新证据。

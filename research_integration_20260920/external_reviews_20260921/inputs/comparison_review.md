# N4-P4a 与 Astra 当前工作的比较：应迁移什么、应停止重复什么

## 1. 结论

最值得迁移的不是一整套非线性求解器，也不是旧的1800个HF标签，而是 **任务—资格—选择—标签—统计—机制诊断** 的研究分层。

N4-P4a所在的LF/N线已建立某一固定夹持任务下的研究闭环。Astra目前主要解决自身TMC与受限接触参照的可信计算问题。二者有相同最终研究目标，却不处于同一功能层和同一物理验证范围。

因此建议：**保留Astra已有的数值与状态优势；让它将来成为既有研究层的一个版本化评价后端，而不是在Astra里重新开发一遍LF、选样、计分和所有实验管理。** 研究层统一，不表示物理标签可互换，更不表示当前Astra已经可以替换N线A。

这是一份比较与规划意见，不改变C2的未通过状态，不新增计算授权，也不追溯增加已关闭阶段的验收项。

## 2. 本轮实际比较依据

本次上传的N(19)(2)与此前N(19)(1)文件集合及逐文件内容完全一致，2007文件；LF(10)(2)与LF(10)(1)也完全一致，4666文件。所以这次不是新的P4a修订完成证据。

Astra使用上一轮明确上传的 `Compliant-TO-TMC-main.zip`，不是禁止读取的另一条 `Compliant-Nonlinear-TMC-O` 仓库。Astra文档有自身旧“O线”用语，本报告只指当前已授权上传包。

实际读取：Astra README、C0集成报告、INTEGRATION_DECISIONS、N19_SOURCE_AND_CODE_REVIEW、C2配置与稳定F计划、几何读取和评价接口；N的P4a脚本/文稿/JSON、C1恢复分数、标签入口、选择器与归档接口。

本轮独立用1800个原LF包的端口量重算恢复L和固定5mm任务的线性预测，并检查200池首选与主命中；1799个有效标签下r=0.9992099968184492，200/200池的LF首选及线性预测首选都是已验证HF最好者。全部S0/S2预算的命中计数与记录相符。力限阶梯数字在本轮仅作为已有探索记录读取，未重做该阶梯的所有插值；上一轮复审曾检查它，不把前次工作冒称本次运行。

没有重跑单元测试、真实LF/HF路径、C2高精度本构、细网格，也未进行源码修改、归档迁移或远端操作。Astra细网格失败数值沿用前一轮已有独立核查，并与当前源码/配置/报告对照，不声称本轮重新解算。

## 3. 不是“新线落后旧线”，而是研究层与评价器层不同

| 对比项 | N4-P4a所在LF/N线 | Astra当前线 |
|---|---|---|
| 最近核心问题 | 在共同资格和预算下，哪些选择方式更容易找到已验证近优结构？ | 对指定离散模型，力/切线/状态是否正确；TMC接触相关输出如何解释？ |
| 主要评价路径 | 实体有限变形＋有限底面无摩擦主动集A；正式P3无第三介质、alpha=0 | TMC全域介质/正则与受限A0/Aalpha参照；split状态及独立高精度审计 |
| 本轮主要几何 | 80×40mm夹持器，160×80，厚度20mm，E=1MPa，间隙2mm，逐点输入到5mm | C2诊断实体2×1mm，厚度1mm，E=100MPa，间隙0.25mm，位移到0.5mm |
| 已有研究证据 | 200池/1800几何/1799有效标签，P3及C1已关闭；P4a为探索性诊断 | 有独立数值与几何核查；C2两条通过、细网格末态未过；尚无同一正式任务下的候选排名证据 |
| 状态表示 | N自身单U运行与float64归档 | u_lift/u_fluctuation共同为权威，显示和不可回灌 |
| 直接迁移风险 | 不能外推到任意任务或认为A是实验真值 | 不能继承N的标签有效性、边界适用域或验收关闭状态 |

不要把约71.4N的Astra小实体压缩诊断力与约1N级的N夹持器力比较“谁更准确”。尺度、驱动、几何及测量定义不同。同样，数值求值1e-11门与研究5%近优阈值也不直接可比。

## 4. 一个重要事实：Astra已经吸收了部分旧线经验

Astra `research_integration_20260920/INTEGRATION_DECISIONS.md` 和 `docs/HF4_C0_RESEARCH_INTEGRATION.md` 已记录了LF(10)/N(19)的接入取舍。已采纳/实现的包括：

- 普通几何与来源保持，HF不运行LF优化器。
- 几何交面积与严格有效前缀；J>0或节点不穿透不能代替实体—工件无重叠。
- A0共享自身材料/求解器，不称为独立FE真值。
- 不复制N的单U内核和默认残差政策，不把N的alpha值直接当成本线推荐参数。
- 区分原执行顺序、C1解盲后恢复顺序和未来任务匹配顺序。

尤其是其INTEGRATION_DECISIONS §5已正确写出：小种子主效应不否定池级独立性；同步全下界/全上界不能认证混合区间命中；采样单调不证明连续段单调或力控制分支等价。

所以这次的启发不应重复变成“再实现一次contact_audit和前缀”。真正欠缺的是把这些数值能力导向一个明确、有限的研究用途，并复用现成研究层。

## 5. 科研启发一：更强HF实现不自动带来更强多样性结果

若池j的共享首选a_j已经在近优集合H_j，则任何包含首选且k≥1的策略都命中：

\[
a_j\in H_j \Rightarrow Z_{S0,j}(k)=Z_{S1,j}(k)=Z_{S2,j}(k)=1.
\]

原P3所有200池都处于此情形。这是真实且有价值的结果，不是实验失败，但它意味着“做出更复杂的HF求解器”不一定改变同一选择问题的信息量。

Astra稳定F修复解决的是生产算术对既定离散弱式的求值偏差。它应按原1e-11门关闭，不能因为最终指标只有5%就忽略该失败；然而通过之后，也不能据此预测多样性必然获益。

合理做法是让两种问题分别报告：

1. **评价器是否可信？** 数值一致性、几何可容许性、模型适用域、敏感性。
2. **在这个可信评价器与任务下，多样性是否值得消耗有限查询？** 首选失手率、补救能力、best@k、未知覆盖和成本。

不应让研究层为了等待“任意任务下的完美TMC”无限延期，也不应让研究需求反过来迫使数值验证放水。

## 6. 科研启发二：先有任务匹配的廉价基线，再判断多样性

原LF排序可写为（本批F_LF=1N）：

\[
L=F_{LF}\frac{g}{K_{in}+k_{ref}}.
\]

对应两端口代理在闭合输出条件下的力为：

\[
\widehat F_n(d)=\max\!\left(0,\frac{gd-\delta}{C_{out}-g^2 C_{in}}\right).
\]

这些关系在相应线性端口模型内成立；它们不是A的逐点驱动/有限面接触的精确表达，更不是Astra TMC的通用解析真值。价值在于能够用已有便宜信息预测功能趋势，并辨别“HF物理导致重排”与“LF排序口径本来就不匹配任务”。

旧P4a的既有探索表（k=3、eta=0.5）为：

| 反力阈值替代标签 | S0 | S2 | 匹配LF口径S0m |
|---|---:|---:|---:|
| 1.5N | 0.005 | 0.965 | 1.000 |
| 2.0N | 0.915 | 0.015 | 1.000 |
| 2.5N | 1.000 | 0.765 | 1.000 |

所有8级中，匹配口径k=2已全命中。这些点估计只对旧位移路径插值读数成立，不能当作真实力控制验证或新确认性结果。

对Astra的启发：将来验证真实候选时，优先并列记录g、K_in、C_b及线性预测与实测Fn/Rin/接触起点。用它们解释新增HF物理带来的差异，而不是只画S0/S2的胜负图。任务已知时，S0m值得保留为对照；未知任务时必须另定任务集合或分布，不能事后挑有利阈值。

这不是要求现在新增线性求解或改变C2任务，而是确定未来研究输出应包含哪些便宜但关键的信息。

## 7. 工程启发：复用研究层，后端保持边界

建议采用的逻辑分层不是新框架，而是已有文件接口的分工：

```text
普通几何 + LF-only元数据
        → 共同资格、C、距离、选择顺序
        → 一个明确task/model/implementation下的HF评价
        → 紧凑有效标签表 + 原始科学状态索引
        → 原有计分/统计/机制解释
```

| 已有资产 | 对Astra的处理 | 不应怎么做 |
|---|---|---|
| N `experiments/n4/selection.py`, `scoring.py`, `stats.py` 与合成测试 | 优先复用定义和小型测试；后续通过普通标签接口做一致性回放 | 仅因新后端名称不同就重新开发三套策略和统计 |
| LF的v2包及C1分数字段 | 通过准备环节显式转换 `dmftd` 格式到 `hf-geometry-1.0`，保留双geometry_id/来源；不让HF依赖LF运行时 | 把JSON文件名相似视为可以直接互换；覆盖原395文件 |
| N `scripts/run_n4_p3_labels.py` 的任务/标签/未知分离 | 参考其紧凑表结构；按Astra任务另写实际字段/来源 | 将N旧标签复制为Astra输出，或某候选失败时换后端补分混合排名 |
| P4a诊断模式 | LF先验—HF偏离—查询收益的因果顺序可以复用 | 照搬2mm/5mm/旧k_ref和8级阈值到不同尺度C2压缩问题 |
| N归档结构与测试分层 | 学其“普通研究分析只读小表、原状态按需” | 把N单U字段替换Astra双数组，或依赖缺失时跳过准入 |
| N材料/接触求解器 | 作为方法与适用域对照，当前不直接迁移 | 用N单U覆盖split，或改变Astra既定残差门/物理参数 |

**研究层复用≠标签互换。** 模型、实现和任务都必须进入结果来源；TMC与A对同一几何也可能有不同的物理近似和有效域。只有匹配的任务、测力定义和共同有效区间才允许作有意义的模型比较；相互接近不是单方真值认证。

Astra当前 `INTEGRATION_DECISIONS.md` 已明确“不直接拿N线A替代本线评价器”，本报告没有更改这一决定。若所有者未来只追求Q-S结果，原A在既有范围内仍可继续服务研究；若追求TMC方法本身，需说清它将补足何种旧A未覆盖的任务能力，不能仅以“也是HF”重复相同实验。

## 8. 验证范围应当由用途约束，而不是由测试数量推动

| 层次 | 检查的问题 | 当前可迁移的经验 |
|---|---|---|
| 数值实现 | 对既定离散残差/切线是否正确 | Astra的split、HP参考与失败归因值得保留；原C2失效不借统计容差掩盖 |
| 接触可容许性 | 节点/材料域/障碍/有效前缀是否合格 | 两线已有的交面积、边缘域、首次失效经验可共享 |
| 模型近似 | TMC介质/正则/边界引入多大偏差 | 与匹配A0/A等对照分离，不能把数值求值误差当模型误差 |
| 研究决策 | 近优集合、首选命中、预算结果是否可靠 | N研究层已有完整定义；将来只对当前任务所需边界做有限核查 |

目前Astra的1e-11项是完整内力向量求值门；旧P3的5%是候选近优定义。二者不能拿来互相放松或互相当物理精度证明。继续保持旧门槛，同时限制新研究目标：完成一个明确任务的可用评价后端，而不是一次性实现所有工件、摩擦、三维、自接触和稳定性。

在进入大样本前，建议未来用少量由LF特征选择的代表几何检查输出/有效性范围。这只能在C2和目标任务所需接触准入完成且获授权后执行；本报告不规定新个数、不新增实际算例、不预批1800条复算。若按旧HF结果选择“难例”，明确是诊断集，不充当新的确认性随机样本。

## 9. 对瘦身的直接启发

此次ZIP原成员大小：Astra1240.66MB；N59.36MB；LF134.98MB。体积差不能解释为N做了更少或更便宜的科学计算。N/LF的正式外置清单分别报告原始HF1,106,398,583 bytes、LF1,880,882,259 bytes，共约2.987GB（双副本另计）；本轮未挂载原始档案验证字节。

旧线之所以能很快完成P4a，是普通研究分析只读端口表、标签、顺序和必要检查点，而不是每次打开所有Newton记录和场数组。Astra已有摘要，但高精度详情和逐字节复读副本仍大量随工作树携带。

因此沿上一轮125.56MB轻量目标继续：

- Git/工作树：代码、测试、小fixture、必要几何、协议/来源、紧凑研究与准入表、少量图。
- 外置不可变资产：全部权威split数组、高精度字符串、失败/插入态、完整控制历史与详情。
- 按需独立复读树：恢复对应源码和所有前置数据，不在冻结树写新结果。

未来高精度详情可以共享同一字节对象并保留不同复读回执；当前不要求建设对象存储平台。不得减少有效状态、降低精度、取消缺失报错。新的科研紧凑表也不能取代追查小量F算术所必需的split原始证据。

## 10. 当前执行边界和唯一最近阶段

这次比较不改变上一轮最近阶段：**HF4-C2-S0，证据外置与可恢复瘦身，物理源码保持不动。** 验收仍沿原迁移清单、双副本/恢复校验、既有相关测试和失败状态不变；不因为本报告又增加一组物理或研究验收。

| 项 | 本次比较给出的边界 |
|---|---|
| 输入 | 当前Astra快照及原清单；上一轮可恢复瘦身方案；N线归档与小表分层作为参考 |
| 产物 | 轻量默认树、可恢复证据资产及依赖、原科学状态与准入摘要、迁移验证记录 |
| 验收 | 无损恢复、测试不因数据缺失新增跳过；两个通过/一个未通过及细网格失败门保留；不改变几何/材料/求解器 |
| 停止点 | 交付迁移结果后停；不在存储迁移中修F或跑HF5/1800候选 |

稳定F仍是下一项已明确的力学修复，先固定态/有限制造场，后申请原失败路径的有限新版本复测。迁移和算术修复分开，避免互相掩盖来源。研究任务/后端角色的讨论可以同时进行，但不自动成为代码或计算需求。

最终建议可以概括为：**从N4-P4a吸收“如何形成有辨识力的研究问题”，从Astra保留“如何不把数值输出误当可信物理”，然后以共同数据层连接二者，而不是重复两套完整项目。**

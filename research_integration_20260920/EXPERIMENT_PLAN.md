# 新研究融合：先验证参照与失效识别

本计划在新有限元试验前冻结。目标仍是建立能独立读取普通几何、与 LF 断开、对有限变形与接触给出可核查响应及失败状态的 HF 评价器，为后续固定预算多样性选型研究提供可靠标签。新上传的研究是方法和数据来源，不改变既有 HF4-B 的物理合同、通过范围或历史证据。

## 为什么先做这一层

N19 提供了接触处理不同的实体参照 A，也展示了“Newton 成功、候选节点没有穿透，但单元边跨过工件角点”的反例。因此，下一步需要同时验证参照自身与几何/路径失效语义。N19 的单 U 算术、较松的力尺度底值及残差上升政策不替代 O 线已经验证的 split 状态和严格停止条件。A 与 TMC 共用材料和有限元实现，不能称为完全独立真值。

## 本轮可执行范围

1. 独立实现严格凸 Q4 与固定矩形的交面积检查；非法、退化、自交 Q4 不得以零面积通过。容差显式给定。用可手算的接触、包围、边跨角、尺度变化及非法状态验收。
2. 独立实现所有接受态的有效前缀：字段齐全、严格递增，首个无效状态之后不能恢复计分；真实零响应与未知 `null` 区分。插入态同样参与判定。
3. 构造受限实体参照 **A0**：单实体矩形在已闭合宽平面下压缩，全上表面作为候选接触面。现有 O split 求解器施加法向约束，逐态独立验证接触乘子非负、无穿透及切向自由平衡。它只在已验证的全接触分支成立，尚未实现主动集激活/释放，不能推广到一般接触。
4. 两个均匀路径首先对独立解析平面应变 NH 横向自由解；通过后，两个网格乘两个非均匀幅值，共四个真正二维短路径。每个接受态保存两分量与力，并由独立 Decimal 50/80 位公式重算残差、J、约束、反力平衡及切线方向。非均匀场必须报告剪切/二阶梯度，不能把均匀解换名当二维验证。

任务与阈值完整写于 `../hf_repo/configs/contact_reference_a0_v1.json`。坐标、长度单位 mm，应力 N/mm²，力 N。两网格只报告敏感性，不宣称网格收敛。上平面总压缩力与非均匀底部虚功广义力分别记录，不混用。

预算为最多 6 条新路径，每条生产求解 180 秒、隔离进程 240 秒；每条独立审计 300 秒。先通过均匀参照准入，再运行依赖它的非均匀试验。任何失败都保留原始状态、日志、配置与源文件哈希；不通过放松门槛、改变任务或调大 α 来消除失败。

## 结果之后的决策

通过只允许把 A0 作为后续宽平面非均匀比较的受限参照基础。完整主动集、非接触到接触转变、有限面边缘失败、同任务 O-TMC 比较及参数敏感性仍须分别完成。HF4-C 不因这六条参照路径自动完成，HF5 大样本选型也不提前开展。若任一准入门失败，先定位原因并追加修订记录。

可审计链条：来源冻结 → 阅读与取舍 → 预先冻结任务 → 逐态证据 → 独立计算 → 可视化 → 结果与下一步。原有 395 文件几何集、HF1–HF4 历史证据和已发布的 0.5.0 Release 保持原样；本轮使用新的输出目录。

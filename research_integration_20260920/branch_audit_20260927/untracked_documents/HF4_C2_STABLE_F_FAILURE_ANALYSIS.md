# 稳定 F 候选的制造场失败分析

2026-09-27。本文只读取本轮已经生成的 JSON/NPZ 和源码，核对已有结果并讨论下一步；没有修改候选代码、运行新的本构求值、HP 参考或平衡路径。向量范数等辅助数值来自已存数组的后处理。所述因果判断区分直接观察与待隔离验证的解释。

## 结论与本轮边界

稳定 F/G 候选通过了 28 项算术测试，制造场 33 例中 30 例通过，3 个网格的 `near_rotation` 均未通过完整内力门。制造场结果明确否定“此次 F/G 修复已经足以使整个既定验证矩阵通过”的说法；它没有否定补偿运动学对强压缩问题的价值，也不代表所有输出单个 float64 的算法都不可能满足某个具体力门。

三个失败场的 F/G 已达到所报告的最多 0.5 ulp 误差，但完整材料力仍失败；另有两个网格的极小正则力失败。这里暴露了运动学之后的近刚体不变量/应力消减，以及未补偿 Hu 的独立限制。本轮保留 `split_compensated_dot2_v1` 的代码、案例、门槛和失败结果，不临时改本构算术使本次结果变为通过。

本分析不授予新路径资格。原 C2 历史失败继续保留，保存态候选验证及其范围由单独结果说明。

## 原门下的直接结果

三例的冻结 `SF` 均为 `1.2500e-7 N`。总力门 `1e-11 SF` 对应绝对误差上限 `1.25e-18 N`。下表列方向 0；方向 1 的静态力完全相同，切线沿各自独立方向检查。

| 网格 | 总力误差 / SF | 材料力归一误差 | 正则力归一误差 | F 最大 ulp | Hu 最大绝对误差 |
|---|---:|---:|---:|---:|---:|
| unit，1 单元 | 7.609767289e-8 | 1.047623833 | 1.011384545e-19，通过 | 0.5 | 0 |
| dyadic_rect，4 单元 | 1.323342210e-8 | 1.046520508 | 3.222422602e-3 | 0.5 | 2.775557562e-17 |
| nondyadic_rect，2 单元 | 1.973854712e-8 | 1.045211653 | 1.958982675e-3 | 0.46875 | 1.387778781e-17 |

材料和正则分量门均为 `1e-9`，分母保持原定义：`max(HP80 分量范数, 1e-12 SF)`。不能以力的绝对量小为由忽略失败。本例正则力分母由 `1.25e-19 N` 的下限控制，仍要求保留输入所定义的极小非零 Hu。

两方向的全部总 Jv、材料 Jv、正则 Jv、直接残差 JVP 与返回 `K@v` 的对照都通过。以上三个失败案例中，相应误差约在 `1.2e-16` 至 `1.7e-15`，不能据切线通过推断静态力也通过。80/120 位的独立参考一致性全部通过，失败不是参考精度未收敛造成的。

## 材料力：已观察到 J 的小增量丢失，未完成误差分段归因

制造场角度为 `0.03125` 弧度，已存 `max(abs(G)) ≈ 0.03124491398532608 > 0.01`。按原内核逻辑，它进入直接材料分支：

`P = mu F + (lambda log(J) - mu) F^{-T}`。

直接观察包括：

1. 三例全部已存生产 `J` 都是恰好 `1.0`。单位网格第一个积分点的 HP120 值为 `1.000000000000000068440403645263847756...`；非 dyadic 网格相应值为 `1.000000000000000068444024710452788155...`。其增量约 `6.84e-17`，小于 1 附近的半 ulp；把 J 存成一个 float64 即会失去它。这并非证明 J 舍入错误，恰恰表明正确舍入的 J 也可能不保留后续所需的小量。
2. 因此直接分支中的 `log(J)` 为零，HP 输入所定义的非零体积小增量不再传给应力。
3. 同时，直接 P 表达式相减两个量级约为材料剪切模量的项。其最终材料力却仅为 `1e-15 N` 量级，存在强消减。
4. 单位网格生产材料力范数约 `4.41424e-16 N`，HP120 为 `9.07979e-15 N`；dyadic 网格分别约 `7.63855e-17 N`、`1.58065e-15 N`；非 dyadic 网格分别约 `1.07520e-16 N`、`2.36059e-15 N`。这些都是同一已存双数组的比较。
5. 单位网格 Hu 与 HP 完全一致且正则力通过，但材料力仍失败，故 Hu 误差不能解释这一材料力失败。

由以上事实可以判断，问题已经超出原来的大平移/强压缩 F 求和误差；仅使 F 正确舍入为单个 float64 并保留后续直接 J/P 路径，并不足以覆盖本制造场要求。

但本轮尚未执行隔离反事实，不能将完整材料力误差百分之百分配给 `J -> log(J)` 或 P 的两项相减。F/G 最终舍入、J 形成、逆矩阵、材料算术和组装的独立贡献仍需分段诊断。特别是非 dyadic 输入下，F/G 的 <=0.5 ulp 误差对本来非常小的物理应变仍可能重要。

这些输入只是“近旋转”，不能宣称其精确物理应变和内力应为零。三角函数及节点构造本身已经舍入，独立参考的权威是 `D(lift)+D(fluctuation)`。把 P、Hu 或极小力直接归零会改变本次被验证的输入问题。

## 正则力：两个网格确有 Hu 信息损失

Hu 保留原先分开计算 `HL`、`Hw` 再相加的收缩，未进入本轮补偿范围。已有数组直接显示：

- 单位网格 Hu 最大量约 `3.469446952e-18`，全部分量与参考一致，正则力通过。
- dyadic 网格零基单元 2 的 `Hu[0,0,1]` 和 `Hu[0,1,0]`：生产为 `-5.551115123125783e-17`，HP 为 `-2.77555756156289135105907917022705078125e-17`。生产值是该分量参考值的两倍。正则力误差约 `4.02803e-22 N`，已足以违反所冻结的分量门。
- 非 dyadic 网格零基单元 0 的 `Hu[0,0,1]`：生产为零，HP 为 `1.1745523535259632202983714577...e-17`；单元 1 的 `Hu[1,0,1]`：生产为 `1.3877787807814457e-17`，HP 为零。共有 8 个 Hu 分量与舍入参考不同。正则力误差约 `2.44873e-22 N`。

因此，“Hu 在此次近旋转输入上已足够准确”已被这些数组直接反驳。Hu 损失是正则力失败的有据候选原因，但仍未用固定 Hu 替换反事实完成全部误差贡献分离。生产 J=1 对 `exp(-5J)` 的影响与 Hu 的巨大相对误差不属同一尺度；不能仅凭量级推断代替分段验证。

正则误差比完整材料力误差小约七个数量级，不是总力门失败的主导解释；它仍是必须单独解决的分量验收问题。

## 最小后续研究计划：先分段诊断，再冻结新候选

下一步先建立一个新目录中的有界固定场诊断，仅针对这三个已存失败输入、使用方向 0 的静态场，不运行 Newton、路径或新的接触问题。诊断需预先冻结输入/源码哈希、精度、预算、结果名称和复现门，拟比较：

1. 已存生产完整材料/正则/总内力；
2. 以已存生产 F、J、Hu 作输入的独立高精度材料与弱式组装；
3. 保留生产 F、Hu，但由该 F 在高精度下重算 J；
4. 使用已存 HP F/J，保留生产 Hu；
5. 已存完整 HP F/J/Hu 和独立参考内力。

相邻向量变化是顺序相关的算术归因，不是独立误差条。诊断必须首先复核最终重构与已存 HP 参考一致，再用于判断哪些改动必要。以上诊断本轮未执行。

如果诊断支持当前解释，新候选的最小研究范围包含两部分，而不只是扩大 `abs(G)<=0.01` 的阈值：

- **小不变量与应力算术**：考虑把仿射运动学的高/低部分保留到 `B = G + G^T + G G^T` 和 `delta = tr(G) + det(G)`，对乘积与求和同时补偿；从准确的小 `delta` 计算 `log1p(delta)`。原近单位分支已有代数等价形式 `P = mu B F^{-T} + lambda log1p(delta) F^{-T}`，但直接扩大使用范围而仍对小 B/delta 普通求和，不能保证本次非常严格的小力相对门。候选须证明代数等价、分支与原始正 J 域一致，并重新检验实际残差的自定义 JVP/切线。
- **Hu 算术**：对 lift、fluctuation 与 hessian 的全部乘积一起进行补偿收缩，保留输入中的极小非零 Hu；随后仍使用原 `exp(-5J)` HuHu 弱式及非对称导数。不裁剪、不将微小值归零、不增添能量项。

任何这样的新内核须另命名和记录来源，当前候选和三例失败永久保留。沿用同一制造场与全部原门，补充独立 HP 分量和方向差分证据，再检查 C1/C2 保存态。只有无求解阶段全部满足预定要求并经独立复核后，才讨论另外冻结的新平衡路径。

本轮的有效结果是明确了修复边界：补偿 F/G 的基础算术和多类制造场已通过，但近旋转完整力与极小 Hu 仍有可复查的缺口。完整力验收继续保持未通过，不能以改善某一个原失败态或通过 Jv 来替代它。

# L-CEXT1 有限兼容测试候选

唯一入口为 `test_load_only_extension.py --repo <hf_repo> --output <stage/run_001/t> --stop-file <stop file> --time-limit 180`。使用一次 `unittest.TextTestRunner(failfast=True)`；本准备阶段仅通过 AST 解析，未导入 HF、未执行任何测试或求解。

| 方法 | 功能与证据 | 科学调用范围 |
|---|---|---|
| 01 | 原零起点 load_only；缺省保存续算保持拒绝；显式首次及再次 append；四说明字段与峰值更新；原数值设置、父文件、绝对态、R、全局/子段目标序号；首个 fresh F/T；旧力/切线/矩阵不读取；子段成功资格保持有限 | 三次真实 16 单元 / 50 DOF 求解，均 mechanical / chunk256 / port_projection |
| 02 | 原 ordered_cycle 完成段仍可下降 append；不改变原任务元数据规则；子段完成不升级全路径资格 | 两次同一小模型真实求解 |
| 03 | 错峰值、改变前缀、改变材料、重复、下降、非有限目标拒绝 | 六个普通内存元数据反例 |
| 04 | 失败/未完成父段、非末态、非原目标、任务来源签名错误拒绝 | 五个普通内存元数据反例 |
| 05 | 子段 anchor 未复核、身份未保持、状态/R 不符、子段序号错误拒绝 | 五个普通内存元数据反例 |
| 06 | 线性控制器不平衡 anchor 首次 F/T 后停止，无校正、提交、外部重试 | 两条 1 单元线性控制器路径，非 TMC 材料验证 |
| 07 | 新内部布尔许可必须显式、非零、有态、首目标相等且递增；不能放宽原 cycle | 八个控制器输入反例，预组装拒绝 |
| 08 | 零起点扩展、缺任务、非布尔 mode 在来源读取/求解前返回原 typed input error | 三个公共 API 元数据反例，禁止调用 saved defaults/solver |

总计固定八个 unittest 方法。真实求解数为五，不含一个预组装失败的默认 load_only 保存续算调用。每次真实控制器时钟 30 秒；共享 180 秒从导入前开始，在每个方法及实际调用前后检查，外部进程由 root 所有者监管；不声称 Python 检查点是硬抢占。首错 failfast；不重试、不扩大测试集合。

临时几何严格复用既有 `test_native_force.small_native` 的 4×4 网格、一孔掩码、边界及材料。新 load_only 位移为 0 / 0.00025 / 0.00050 mm，首次追加 0.00075，二次追加 0.00100；原 cycle 兼容例为 0 / 0.00050 / 0.00025 后追加 0.000125 mm。它们仅检查持久化与接口兼容性，不能作为夹持器、接触、压力、HP 或物理稳定性证明。

输出只写入 root 给定的新短目录，子目录为 `1` 到 `8`，实际包使用 `p`、`c`、`c1`、`c2`。保留新 tiny 几何、五份实际保存包及有限错误响应，普通 `test_report.json` 记录执行方法数、期望数、实际返回调用计数、HP/JIT 计数、总钟及产物范围。产物纳入本阶段最终封存；不清理、不回滚。

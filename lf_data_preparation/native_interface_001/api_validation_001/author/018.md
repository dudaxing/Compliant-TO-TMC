# Native saved response — source-only candidate

Public API:

    summarize_saved_native_result(result_file, *, repo_root=None, reference_file=None, view_manifest=None) -> dict
    write_native_response(response, output_file) -> Path

Reads saved result/model JSON, optional independent summary/source .py bytes, and optional existing view/image bytes. Does not open NPZ, import HF/NumPy, construct/solve/recalculate or render. Supports result1.0/1.1/1.2 and records default option origin from schema/native_mean API.

Compact keys: identity/physics/path/options; target_response is the original task-target state only after full success and task_target_executed; requested_endpoint_response separately gives a completed path endpoint. Both are null for failed paths. A successful short path that did not execute the task target keeps target_response null. maximum_loading_stroke is separate from last_accepted. Signed fixed-body total/material/Hu components and mirror magnitude/net stay distinct; no-workpiece force is null. Producer flags stay their original values.

Independent accepted_reference_pass requires same result/model input binding, all actual accepted states, per-state index/hash/target/2HP, fresh2N bookkeeping, full element/DOF coverage, and declared source .py rawSHA under explicit repo_root. full_path_reference_pass additionally requires production path complete; prefix reference cannot qualify the missed target. Missing/mismatched optional reference remains inspectable and unqualified. This is saved report matching, not HP/NPZ re-audit; contact/clamp/pressure/HF5 false.

Optional view must be a completed same result/model/task/all-N case; only existing matching cached PNG/GIF with rawSHA are linked. Input under repo gives repo-relative links, external absolute inputs remain absolute with explicit path_scope. CLI/evaluator resolves relative input/output paths; writer rejects existing output. Candidate only AST/compile checked; not imported or executed; tests belong to an independent author.

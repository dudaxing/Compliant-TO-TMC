# M-BOUND1 后的功能取舍与最近下一步

2026-10-11。依据本卡[实际结果](RESULTS.md)、[原单元角色](run_001/groups.csv)、[原节点分类](run_001/node_categories.csv)及[整体与误差记录](run_001/whole.csv)。本文件记录接续判断，不是新执行卡，不授予新的数值范围或资源。

## 整体目标与这次增量的实际作用

整体目标仍是读取 LF 普通几何，以独立 HF 有限变形／TMC 前向分析获得结构实际变形、输入反力及有明确物理含义的工件作用，支持外部研究层在同任务下比较候选，最终完成正式 HF5 评价。HF 与 LF 优化保持断开；后续开发只在 main，origin 为 https://github.com/dudaxing/Compliant-TO-TMC.git。

M-BOUND1 补齐了当前矩形 Q1、固定半方体任务的离散 Hu 作用解释：两态1444个原 support 单元的四顶点符号模式数值精确成立；每态1406个工件 DOF（703节点）按原加法次序重播，保存的两态共1406节点行与原 Hu 值数值精确一致。body、bottom_owner、left_owner、right_owner 四组的保存平移合力均为(0,0) N；两枚 corner_only owner 保留整体作用。local 整体与 corner_only 整体的两分量差在两态保存为(0,0) N，跨表达差仅作描述。

| 保存态 | 原 state Hu ON-body (Fx,Fy)，N | 原 bottom_side_interior Hu (Fx,Fy)，N |
| --- | --- | --- |
| loading 0.85 mm | (-0.0002573690035747477, 0.001157502187101581) | (-0.00012035426166507285, -0.011794230646605314) |
| loading 1.20 mm | (-0.0003147888828766561, 0.0012668445429290087) | (-0.0031817720364384176, -0.001299760144598709) |

这些原值说明，侧边 owner 成对平移合力为零与组装后边界节点作用非零可以同时成立。owner 角色和七类节点属于不同 partition，不能跨分组相加，也不能把两个 corner_only owner 当成两个物理角点节点类别的同义项。新端点图是参考单元的负局部 covector；只有选中工件顶点可称 ON-body。原材料／Hu／总力实际变形图仍复用[24态动画](../../../functional_views/native_nested_cycle_20261009/complete_001/run_001/view/fixed_square/actual_states.gif)。

因此，本次取得了保存离散载荷的来源解释。没有证据要求继续扩展同类全24态账本、重构原 Hu／DD，或把 Hu 数值加到材料 P@N 后声明总连续压力。

## 已有能力与尚缺范围

固定工件的 total/material/Hu 总作用、保持反力、镜像完整净力和双侧法向幅值和已在[公共响应](../../../hf_repo/src/hf_eval/native_response.py)及[平均位移求解器](../../../hf_repo/src/hf_eval/native_mean.py)实现。完整24态加载／卸载、真实 CLI／API／batch 和保存态显示已存在。[M-REF2](../nested_reference_002/RESULTS.md)的48次 HP80/120 已覆盖这些保存态的材料／Hu 工件作用投影及不重叠保持投影；其切线仍限原声明 PORT 方向。新的解释不把这些既有功能或独立参考写成尚未实现，也不重复建立同类接口或参考。

当前尚缺的是使这些响应成为可靠候选比较依据的物理稳定性及适用域证据。固定体弱式作用和固定反力能够报告；它们不自动证明可动工件的有效夹持。连续总压力密度、自由体平衡／摩擦、圆体自身匹配任务、一般输入／全列切线资格，以及正式 HF5 批量标签／排名与研究层同任务接入仍有各自缺口。科学版本与原资格保持，本次没有升级这些范围。

## 最近阶段的选择：先准备同任务稳定性比较

下一阶段先冻结一份最小的固定方体稳定性比较合同，再根据已知差异选择真正缺少的一项新证据。此选择直接服务于用户关心的“结构如何变形、力是否稳定、能否比较候选”，而不会把连续压力解释作为所有前向功能的前置条件。

准备时首先复用[同设计 h1／h0.5 原对照](../../../functional_views/native_nested_cycle_20261009/complete_001/RESULTS.md)及其[逐态 CSV](../../../functional_views/native_nested_cycle_20261009/complete_001/run_001/view/mesh_comparison.csv)，核原几何、区域／工件、厚度、材料／介质参数、端口、支撑、目标与分支一致性。已有两网格仅提供敏感性；原报告的峰值反力相对变化 -7.0095%、工件总 Fy +3.1982%、Hu Fy -16.1347%、钳尖到底面间隙 -80.0297% 提示不同作用量对离散的敏感程度不同，不能由某一个合力接近就授予全部场量收敛。以上数值直接复用原报告，不在本轮重新计算。

比较合同应以已有输出为主：输入反力、平均输出位移、半工件 total/material/Hu 有符号作用、有限面尖端间隙，以及介质积分点 minJ／明确的 Hu 场量。整体与局部、ON-body 与保持反力、幅值和与完整净力分别报告。Hu 的两角点 owner 结构说明当前合力具有离散支撑来源，应保留真实物理坐标和顶点／边界拓扑；它不能单独证明网格不稳定，也不应被平滑成压力图。

随后只选择一个确实缺少的因素作为最小新增：若同任务网格证据仍不足，先论证新模型与必要的短加载路径；若先研究介质正则参数，则保持网格与其它物理参数并逐一变化。原 gamma 等探索必须先核任务一致性，不能跨域、工件位置、端口或设计混用为控制比较。网格、域余量与正则参数不在同一轮同时改变。新增模型的初值／路径、记录量、判据及实际成本应在候选和独立审阅后确定，本文件不提前选新 h、步数、求解次数、HP 数量或预算，也不直接重跑四小时完整循环。

这一阶段要形成可审查的比较条件和最小候选，配合既有实际变形与有符号力显示；真正新增的求解／观察／图件必须产生本轮尚无的稳定性信息。原48 HP 解决原模型已保存响应的数值核对，不等于网格或参数物理稳定性；重复这些 HP 不能填补该缺口。

## 后续如何走向可用任务与 HF5

根据最小稳定性结果，再明确固定方体任务可用范围与未通过／未提供状态，使外部研究层能调用已有 HF API 并理解输出资格，之后逐步接入同任务多候选评价。原 LF/N4 的生成、优化和评分层不重新实现。正式标签／排名需要任务一致性及物理稳定性依据，不能仅因 API 已有数值或本卡 PASS 就生成合格夹持标签。

可移动工件与摩擦、其它形状及连续压力分别作为后续物理任务。压力若要实现，必须先给出与原非势 Hu 弱式及高阶／角点作用相容的定义与独立证据；替代能量的有限差分不能用作原完整力验证。本次两态结论不延伸为所有形状、网格或保存路径。

M-BOUND1 的窗口已闭合，下一数值阶段不续用旧授权。最近只推进上述准备；新功能范围、科学门或资源需要按真实候选另行记录。本页不制造新执行卡或批准，也不把尚未完成的整体 HF5 目标写成完成。

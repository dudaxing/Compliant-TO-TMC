# M-EXTEND2闭卡后的取舍

当前最近功能目标已完成：显式追加目标的默认API和两CLI入口已安装；原36兼容测试与真实1.15→1.10 mm子段成功，实际反力、工件作用、变形图和恢复资料齐备。M-EXTEND2已成功闭卡，不能重启其launcher、重复测试或使用旧余时继续求解。

下一步优先对**新1.10 mm保存态**做独立HP80／120参考，复用现有参考流程和严格门，核材料／Hu／总力、原PORT方向切线、组装与工件合力。已有1.15态的原参考身份记录保留；不把旧HP自动授予新1.10，也不重复原加载、旧48HP或已有图。这里只提出下一步范围，尚未生成新卡或取得新资源授权。

新态参考通过后，再利用已安装显式入口按实际响应逐段追加更低卸载目标，首先评估1.05 mm是否合适；保持物理条件，以载荷衰减、距离和结构回弹决定下一步，而不先更换材料／α或同时新增多种工件。每个新目标都以新task、保存态和实际图独立记录；完全释放条件尚未定义和实现，1.10并非释放终点。

保存观察支持这个顺序：输入R由0.3470376815403639降至0.31588601669973565 N，下半固定工件total Fy由0.10671287553103108降至0.08897847109213655 N，尖端下缘有限线段距离由0.0012850478242718566增至0.0017305046045876793 mm。第三介质最小J仍约2.6e−5，连续压力／自由工件有效夹持不能由这些量直接认证。后续若新参考或平衡暴露问题，应先按实际证据定位，不扩大任务或静默放宽门。

整体尚缺完整新α加载／卸载资格、连续总压力及有效夹持、移动／摩擦工件、多形状／位置和材料探索、稳定性／全列切线及一般LF适用验收。HF仍以独立前向功能服务外部研究层，不新增优化器或MPM。保持简洁实现，下一轮不再扩展与功能无关的包装或重复已有诊断；源准备可进行，新数值阶段需完成具体卡、静审、发布／恢复后直接批准。

# 新入口真实正向任务：单次生产卡

目标：从仓库之外的调用目录，通过 `evaluate_native` 一次读取普通几何和明确任务，执行真实构模、平均位移平衡路径、缓存保存及紧凑响应。HF仅正向评价，不含LF优化器。

输入为原 `gripper_canonical` 几何和 `native_mean_001/task.json`：3,200单元、6,642自由度，无工件，目标0→0.001 mm。保留原材料、端口、支撑、方程、生产门及默认complete/full/tangent。旧结果只用于输入身份与成本估计，不授予新数值资格。

资源为新的单次helper180秒／F3外层210秒／采样8 GiB窗口。helper时钟从包装模块开始，覆盖导入、求解、缓存和最终哈希；API内控制器时钟及through-summary计时各自另报。F3采样与合作停止，不是操作系统硬内存限制。

步骤：冻结27个现有产品源及输入字节；一次API；保存实际接受态的已有标量；核对真实builder/class/controller/solver/cache/formatter/response计数、原生产门和输出身份。原缓存写入不得新增力或切线计算。回执保留实际开始／完成计数、输入目标、返回结果和失败前缀。

完成条件仅为本卡一次真实入口与原生产门通过。首错关闭，无修复重试、force或延长。资源异常可只有真实NDJSON标量前缀，结果对象不存在时回执字段为null；普通控制器失败保留原缓存保存行为。高精度参考和视图均为后续独立新窗口，不能计入本卡或借历史资格。

本卡不计算HP、图像、压力、有效接触／夹持、全切线列或HF5批量标签。正常预期两态；实际数值与F/T计数取终端回执。详细冻结协议见 `production_protocol.json`，静态根审与独审及两次未执行的包装修订见 `author/INDEX.md`。

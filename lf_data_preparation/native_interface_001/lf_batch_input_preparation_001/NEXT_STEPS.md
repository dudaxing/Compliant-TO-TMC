# L-BPREP1 结果驱动的下一步

本轮已补齐普通 LF 来源清单→共同任务的批量输入准备，未执行 batch 力学。两个真实包数据保持、共同任务和现有 batch 元数据预检通过，不再重复本轮准备／测试／绘图。

最近的功能缺口是：新准备产物尚未由现有 evaluate_native_batch 做一次真实消费。下一步应详细规划最小实际 batch 验证，而非再构建清单层、重写控制器或从零重跑两个完整25目标循环。

优先方案是复用本轮已准备 geometry，显式定义短加载探针任务并冻结新任务身份，验证两个设计的顺序构模／评价、索引和停止行为，再显示实际变形、反力和收敛。不能直接把本轮25目标任务的 options.targets 截短：现有 batch 要求 targets 与任务 path 精确相同。短任务必须明确承认目标／行程范围变化，原任务和本轮已准备产物保持。

在新卡前，只核现有 batch 入口与既有短行程实际成本，确定控制器设置、总预算、成功及失败输出、最少必要新图；不先承诺具体资源，也不把本轮未设置 clock 的可解析清单直接视为获准执行。新物理路径、资源和资格须按既有阶段约定另行授权。

更远路线仍为：真实批量消费→可追溯响应交付→必要有限独立参考→供外部研究层比较。压力、有效夹持、释放、稳定性、全路径独参、正式标签、排名及 HF5 的缺口分别保留。TMC 正向评估继续独立于 LF 优化，MPM 不实现。

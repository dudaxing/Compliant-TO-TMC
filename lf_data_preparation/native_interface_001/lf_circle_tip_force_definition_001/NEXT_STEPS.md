# GDEF1之后：先固定最小承载任务规格

本页为结果驱动的后续建议，不预写GDEF1执行结论，也不授权新求解。沿现有目标和状态记录继续，不另建报告层或全局文档体系。

当前力口径已经明确：20 mm厚度口径下保存力的单位为N；现有Fy是固定下半工件的单侧、有符号全局弱式合力，holding为原total的相反方向，material与Hu分别保留原分量。不能再乘20或自动乘2，也不能把它改称表面压力或已验证夹持力。现有读取函数已经能访问周期、原差量及峰节点结果，无需再造reader。

## 最近一步：只准备一个可审查的物理任务规格

实质缺口是：**固定工件的保持反力不能验证工件能否承受外载，或卸载后是否释放。** 下一阶段先用现有几何、工件、材料和输入资料作参照，完成以下规格及接口缺口核对，不自动加载、改alpha或新增HP。

1. **明确首个问题与自由度。** 优先讨论“夹持器保持既有输入时，工件能否抵抗指定拔出载荷”。一个最小候选是刚体工件仅允许沿+x平移，其余刚体自由度按对称/任务约束固定；这只是候选规格。必须明确刚体与可变形工件的区别，不能把565个节点解锁就当作刚体平移，也不能引入尚未实现的摩擦。
2. **核现API真实边界。** 仅读task/workpiece解析和DOF分配源码，核清`fixed_rigid`、`fixed_components`、外载入口与现观察器“工件全部DOF固定”合同。`load_saved_study_report`只读已有报告，不能施加载荷或增加运动自由度。规格中逐项写出哪些已支持、哪些需要最小求解扩展，不通过改JSON标签假装已实现。
3. **写明载荷、对称与路径。** 指定力作用于工件还是机构、全局方向、N单位、起终值与加载路径，以及机构输入保持/卸载的顺序。若沿用半模型，须说明外载是否与镜像对称相容、半模型与完整装配的载荷口径；不相容时应先选完整模型方案，不能沿用半模型结果后补倍增。现有固定反力只作参照，不自动充当承载上限。
4. **区分物理判定与数值状态。** 规格必须给出允许工件位移/转角、保留或脱开状态的几何定义、外载平衡口径和阈值来源；原平衡、J和约束门保持，新增物理标准单独列出。求解不收敛、达到资源上限或出现刚体零模均不能直接标作“释放”。无接触的自由工件若仍受非零外载，不应假设存在静态平衡；释放问题需另外明确终止条件或是否必须引入运动学/动力学处理。

近期交付只是一份具体任务规格和对应源码能力/缺口表，复用现有说明入口。自由度、载荷路径、物理判定和接口缺口未固定前，不编码新求解，不把报告关联状态升为机械资格。该准备不读取科学数组、媒体或完整历史，不调用API、测试、绘图或开展新的数值实验。

## 后续仅保留依赖关系

规格明确后，再提出必要的最小实现与受限小模型验证；能力确认后才安排真实工件的外载试算、实际运动/反力可视化，并依据结果决定释放任务。参数、网格和独立参考扩展应针对届时发现的问题安排，不例行重开1.02/1.03、降低alpha或重复HP。无论后续如何，原有定义、原值、来源与资格保持，不能因新图或新入口自动获得有效夹持、释放或稳定性结论。

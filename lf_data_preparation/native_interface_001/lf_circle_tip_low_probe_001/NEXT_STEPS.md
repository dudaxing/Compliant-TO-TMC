# LOW1之后：准备最小导向轴向力控制功能

2026-10-23。当前L-CTIPLOW1唯一窗口已成功关闭；父3态、probe2态、四PNG／两帧动画与原窗口封存均已完成。这里仅安排后续工作，不启动新构模、力／切线、HP、测试、绘图或求解。

## 依据实际结果的取舍

保持输入.50 mm时，q0→.025 mm的半模型轴向Q由3.686421133658022e−5增至4.3272306948756724e−5 N，增量6.408095612176505e−6 N；1.06 mm高输入对应增量1.6177191476489698e−5 N。高输入末态Q是低输入5.91966倍，ON-body Fy是33.6932倍，说明机构闭合确实改变工件／介质响应。

但低输入末态尖端间距仍约.51904 mm且有非零Q，轴向Hu占86.29%；高低增量差约76.89%来自Hu。不能把相减后的数称为纯接触抗拔力，也不把低输入预授为无接触或无力基线。现已完成“规定工件位移→计算原有符号总反力”的实际功能链；当前缺少的是“给定工件外载→求未知刚体位移”。不以继续加q、重复HP或继续降低α代替这个功能缺口。

## 最近仅准备一项最小工作

准备导向+x力控制的数学合同、最薄候选接口及有限小模型验证卡。机构输入仍保持，body-y和转角仍导向，仅将工件q从给定量改为未知刚体平移坐标，给定有符号合外载P_half。沿用现有力核、非对称切线与原body成员，不扩展成通用自由刚体／摩擦平台，不改变默认固定工件和既有位移探针。

1. 明确未知量为非body自由位移、机构乘子R和body刚体坐标q；除原自由平衡与机构均值约束外，加入`Σ_body f_int,x − P_half = 0`。这是广义合力求和，不是节点平均；不能把总载荷逐节点施加565次。给定P的单位为半模型N，已含厚度；对称完整装配轴向P_full=2P_half，q不倍增。
2. 明确锚点载荷与来源。原q0有预载，不能解除body-x约束后设P=0却仍称原q0平衡。将来若选择本次较平缓的.50 mm条件作交叉检验，候选P0_half=3.686421133658022e−5 N，P1_half=4.3272306948756724e−5 N，取自已有Q(q0)与Q(.025)。由未来力控独立求q，不能同时规定q=.025来伪造验证；这些载荷是功能交叉检查输入，不是承载极限。
3. 先写清新载荷参数、单位、步长、尺度／残差门、回溯和终止／partial规则。原最小增量.00625的单位是mm，不能直接改名为N继续使用。任何新的力控门和允许变化须在候选卡中明确；不静默改写原位移控制门。刚体约束误差、保持输入、J、全局平衡及外载符号须分别核查。
4. 小模型验证应检查外载入口、刚体约束、符号／半全换算、锚点身份及位移控制q→Q与力控制P→q的一致性。验证量和容差需在实现前按尺度说明，不能预设必然回到同一q、唯一解或稳定分支。先保原16单元／50DOF量级，实际测试数、资源及真实圆形工件范围另行冻结和授权；本轮不实现或执行新力控。

准备完成后再决定最小实现与小模型试算。真正的自由y／转动、摩擦、释放、稳定性及压力／有效夹持资格保留为粗路线，当前不细排。即使后续力控通过，也只代表包含材料与Hu的导向总力平衡，不能自动升级为纯接触承载。

# L-CTIPMOVE1：最小移动工件能力实施范围（待实施）

2026-10-22。依据 L-CTIPLOADSPEC1 的规格／源码核查形成。本文件安排下一阶段，**本轮不安装、不测试、不启动真实工件求解**。规格文件为 `docs/WORKPIECE_LOAD_TASK_SPEC.md`，参照 main `8d589b65ab2e4efe8ca01b95034ed329fca81171`。

## 目的与最小交付

补齐“机构输入保持、工件独立刚体位移”的能力，先确认运动和反力正确，随后才做真实探针。近期不加入力控制、任意平面刚体、通用MPC、多工件、摩擦或动力学框架。

1. 显式 opt-in 入口，分开 `d_hold`、`q_targets` 和原输入任务。已有 `evaluate_native` 的固定工件行为及严格同物理 `resume` 保持；新模式不得伪装成已支持的 fixed_rigid task 或普通 append-only。
2. 复用原 NumPy 力、切线、split 状态、一般 LU 和有界 controller；最小调整为 prescribed body lift、常量输入平均目标及其预测右端，避免复制整套 controller。只允许指定 body ux 随 q，body uy和其余原支撑为零。
3. 新任务显式 admission：绑定来源、同一模型／节点／材料／设置，旧 split 两数组作为初猜；q=0 做新鲜 F/T 和原门核查，不缓存迁移旧矩阵，不把旧任务或资格改写成新任务成功。
4. 新移动态和观察记录：q／实际节点位置、R_input、Q_drive、三力、互斥驱动／导向／其余支撑、约束误差、原残差与J。矩若提供按实际中心定义。反力口径与半／全量不混用。
5. 小模型一张示意性实际变形／反力／残差图及机器可读记录；此时仍不生成真实圆形工件新图。

研究候选先隔离，必要的 controller 小改须保默认分支。候选文件清单和精确差异在编写后静审；不以一整套新通用求解器代替小扩展，不在数值失败后修复重跑。

## 有界小模型验证合同

沿用可复核的小型 Q1 模型（不超过16单元／50 DOF）；材料、支撑、工件节点和端口必须显式、可人工列举，body／port不重叠，body整体平移须保形。具体 fixture、测试命令和源码 SHA 在候选完成后冻结。验证以下六类行为，不堆叠与实现同义的逐行测试：

|检查|要发现的问题与判定|
|---|---|
|旧路径兼容|固定工件默认入口／已有小模型回归仍通过；不能因新 q 控制改变旧位移目标或旧拒绝条件|
|q=0 显式准入|与同模型旧固定态的 split、机构输入及总力口径相容；新鲜 F/T／残差通过，错误来源／物理差异拒绝；不得自动纠正不平衡初猜|
|独立运动|保持 d 不变时推进至少两个非零 q；每个 body 节点 ux=q、uy=0，刚体形状保持，实际坐标随 q 变；机构输入不随 q 增加|
|方程与账本|在保存的完整残差上独立核非body平衡、输入约束、body总反力及互斥支撑全局闭合；q列用求和口径，半／全转换只一次，三力和符号明确|
|冲突与部分失败|body／端口或不相容支撑冲突 typed 拒绝；q=0 未平衡和一个受控数值终端失败保留真实 partial，不标释放，不自动重试或污染旧结果|
|存储与显示|读回仍保 split 两数组／task身份／q与d两列；图中移动坐标与保存态一致，u_display不进入力学；缺失新字段不能被旧固定观察器默默补成0|

门的定义见主规格。沿用原有效数值门；新 body 约束显式使用 prescribed 偏差，不能要求 body ux=0。小模型参数与真实模型的 minimum_increment 不混用。测试期间允许明确列出的有限小模型求解及一张新图；不含真实14720单元路径、新HP或任何夹持资格。

候选资源建议：一次 tests≤180秒，显示≤60秒，共享 helper≤300秒／outer≤360秒，采样8GiB，各库线程上限16。唯一启动，首个终端错误停止；不外部重试、修复重跑、延期、force、回滚或删除。实施前须冻结候选、fixture、唯一命令和数量并完成有限独立静审，按既有阶段约定确认这一新增实现／计算窗口；本规格阶段不消耗该预算。

## 能力通过后的真实试算安排

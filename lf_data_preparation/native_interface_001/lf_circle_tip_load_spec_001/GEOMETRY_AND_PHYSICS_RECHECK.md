# 最小承载规格：几何与物理复核（只读准备）

本轮可将最近功能目标收敛到：**保持夹持器平均输入1.06 mm，令工件作共同刚体+x平移，先规定q=0→0.025 mm，测量所需轴向驱动反力。** q仍是待批准的真实任务候选，本轮没有执行求解。此探针先验证运动与力测量能力，承载极限与自由释放仍是后续目标。

## 阶梯边界与右域界

现有model/geometry普通JSON没有保存工件阶梯bbox/xmax标量。由源码与已绑定网格可严格给出保守上界，无须读取或重构科学数组：

1. 工件选择规则是单元中心C落入圆心x=80、半径9 mm圆内，故Cx≤89 mm。
2. `regions.py`用轴对齐0.5 mm网格及Q1四角连接；该单元的任一角点x≤Cx+0.25 mm。
3. 故原工件任一incident节点Xx≤89.25 mm。这是**源码证明的参考坐标上界**，不是从NPZ实测的阶梯xmax。
4. 候选q=0.025 mm时，刚体节点最右参考位置≤89.275 mm，距参考平面x=92至少2.725 mm。它足以说明这个候选微小位移不越过参考域平面；不保证实际右边界不会移动、介质不会压缩、J不会失效，亦不证明有限域独立性。

解析圆最右89 mm至x=92的名义3 mm不能直接称“可用拔出行程”。首个真实试算仍须记录实际工件阶梯/变形后右边缘及右侧介质J/Hu。无需为了观察反力删除右侧介质项。

## 右竖边的实际约束口径

`native_project.py`的固定集仅合并support、entity_symmetry、background_symmetry、workpiece四类。普通JSON及源码确认：support在x=0，entity_symmetry在y=40且x≤60；背景对称在y=40、x=0..92，仅约束uy；原工件位于x≤89.25。因此x=92右竖边**没有单独的ux/uy夹紧或刚性墙约束**；其右上端点uy=0来自顶部背景对称，ux不由该对称约束。

这也不是无限介质或外力完全消失的承诺。原材料+Hu完整弱式及其自然边界效应保持；不能把“无显式右墙”简化为仅有材料P·n=0的边界，不能把有限域的响应当作无边界夹持能力。

## 控制与力的最小合同

- 工件：保留原510单元/565节点选择及原参考网格；所有原工件节点ux=q、uy=0，转角0。解锁565个独立ux不是刚体运动，不重新按新圆心筛选单元。
- 夹持器：平均输入保持1.06 mm；原输入反力与工件驱动反力分开。原保存峰可作显式新模式初猜，不能通过旧resume静默迁移新物理合同或参考资格。
- 最近用**位移控制**：给q，求反力；不同时再指定轴向外力。稍后若用力控制，q是共同刚体未知量，规定外载并要求广义轴向平衡。
- 没有独立工件轴向外载时，`F_on,x_half = -Σ_B f_internal,x`，`Q_drive_half = Σ_B f_internal,x = -F_on,x_half`。保留q=0绝对预载和total/material/Hu有符号分量，不扣成假零。
- 厚度20 mm已计入力，输出N，不再乘20。对相容镜像的同一个q，`Q_full=2 Q_half`；给完整装配外载时半模型只施加`P_half=P_full/2`。位移不翻倍，力只在规定转换处翻倍一次。
- uy和转角被导向夹具限制，可存在导向反力/力矩；应独立输出。上下半Fy在完整合力中抵消并不等于没有局部约束，也不等于自由工件能承载。以实际刚体中心定义新矩，不把旧节点均值矩原点默认为圆心。

## 成功与失败分类

|分类|最近试算的含义|
|---|---|
|SPEC_READY|规格与源码边界一致；当前只有此层结论。|
|FUNCTIONAL_PROBE_COMPLETE|新q=0基态和q=.025均按批准合同接受；刚体约束、输入保持、原适用数值门、新反力账本及清理通过，实际几何/力/收敛均已记录。仅说明探针功能成功。|
|CONDITIONED_RESISTANCE_OBSERVED|功能成功且该q的有符号Q_drive>0；说明此受导向、有限域模型在该位移需要+x驱动。不给容量上/下界。|
|NO_POSITIVE_RESISTANCE_AT_TESTED_Q|功能成功但该q的Q_drive≤0；保留符号，只描述本点，不据此宣布释放或普遍夹持失败。|
|PARTIAL_OR_NUMERICAL_NOT_PASS|准入、平衡、刚体约束、J、资源或清理出现终端错误；保留真实部分结果和原因，不把数值失败改写成脱离、失稳或零承载。|

实际反力若没有明确物理正负预期，不应以“必须正值”作为软件功能通过门。先独立检查刚体约束、输入保持、残量/反力口径，再对正负与曲线作物理解读。已有固定工件HP只覆盖原保存态，不能授予新运动路径资格。

## 尚未完成的物理功能

真正力控承载尚需规定全/半外载、允许位移、导向是否存在及保持成功阈值；脱开后受非零外力的理想自由体可能没有静力平衡，需要另行运动学/动力学处理。当前gamma>0介质可以传递剪切，Hu亦参与响应；这不是Coulomb摩擦。现阶段不输出自由承载极限、释放轨迹、稳定性、压力、域独立性或alpha独立性结论。

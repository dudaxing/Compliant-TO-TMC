## 源码依据与结论

仓库没有 `native_controller.py`；`native_probe.py` 实际调用 `split_displacement.solve_split_displacement_path`。核对文件包括 native_probe.py、split_displacement.py、displacement.py、native_resume.py、split_numpy_tangent.py，以及既有 GUIDED_WORKPIECE_PROBE.md、LOW1 RESULTS.md／NEXT_STEPS.md。

1. `split_displacement.py:232–250` 的原残差是 `r = f_int + spring − b_in*R`，其中 `R` 的正号明确表示机构 actuator-on-model 的乘子。`R` 不是工件外载。
2. `native_probe.py:239–249` 将 ON-body 定义为负的 body 节点弱内力合和，并定义 `Q_drive_half_N = −ON-body Fx`。所以正+x作用于工件的总外载为 P_half 时，新广义残差应为 `g = cᵀ f_int − P_half = Q_drive_half − P_half`。不能写成 `Q + P` 或把 `R` 当作 P。
3. `split_displacement.py:145–150` 要求输入／输出口在 body DOF 上均为零；本探索源 k_out=0。新函数仍须绑定该合同。
4. `displacement.py:105–121` 原 KKT 使用正平均约束行与负输入乘子列，并用 general sparse LU。`split_displacement.py:284` 明记 `symmetrized=False`；`split_numpy_tangent.py:1–5` 说明导数针对实际物理弱残差及 Hu，而非一个能量 Hessian。新块不能被“修成对称”。

## 最小未知量及正确块系统

保持原参考 body 节点、body uy=0、转角=0，以及其余零支撑。令 S 将原非body自由波动 w 映射至全DOF，c 在所有原 body-x DOF 上为1、其余为0。保持原 split 表示，body 平移放入 `lift=q*c`，body 波动为零；q 是唯一未知刚体平移坐标。q 不是新的约束目标，也不应通过逐节点独立自由度近似刚体。

本范围 k_out=0、`bᵀc=0`；未知按 `(w,R,q)` 排序：

```text
u = S w + c q
r_w = Sᵀ f_int(u) − b_w R
h   = bᵀ u − d_hold
g   = cᵀ f_int(u) − P_half

       [ Sᵀ K S   −b_w   Sᵀ K c ] [δw]     [−r_w]
J Δ =  [ b_wᵀ       0       0    ] [δR]  =  [−h  ]
       [ cᵀ K S     0     cᵀ K c ] [δq]     [−g  ]
```

K 是原实际、未对称化全DOF切线。`K_wq=SᵀKc` 与 `K_qw=cᵀKS` 应分别装配；一般不能令后者等于前者转置。输入列 `−b_w` 和平均约束行 `+b_wᵀ` 的符号沿用原源，不从“对称 KKT”的外观倒推。P 在最小任务中是固定空间+x方向的 dead generalized load，不依赖q，所以其导数为0；不涉及随动载荷或外加弹簧。

原 NumPy 切线导的是 shadow physical fields，而非 split 浮点记账的导数；因此该物理方向的 q 列使用 Kc。将来候选仍须在小模型以方向差分验证此块，不能据本推导直接授导数资格。

c 的条目是1，不是1/N_body。`cᵀf_int` 是广义合力求和，单位N；若错误使用平均，则人为缩小565倍。也不能向每个body节点重复施加完整P。最薄实现只需广义载荷入口，无需创造压力分布。

## 非零预载与半模型口径

LOW1原普通记录给出以下功能交叉检查锚点，均已含20mm厚度，不在本轮重算：

|固定机构均值|锚点q|候选P_half（N）|来源|
|---|---:|---:|---|
|0.50mm|0|3.686421133658022e−5|LOW1 q0的 Q_drive_half_N|
|0.50mm|0.025mm|4.3272306948756724e−5|LOW1 q.025的 Q_drive_half_N|

最小真实交叉实验应从同一完整固定父末态／q0开始，以P0作为新函数的首个**绝对载荷**，fresh F/T 首检直接通过并保留 split、q0和有符号R；随后仅给P1求未知q。不能将P0重置为0、将P1解释为增量、解除body-x后声称原零载锚点仍平衡，或把q=.025同时强制给新控制器。增量ΔP应另行报告，绝对目标与增量字段分开。新鲜算得的P0若与绑定外载不符，应明示失败，不回写目标让残差人为归零。

P_half是所建对称半模型的轴向合外载，完整对称装配 `P_full=2*P_half`，q保持原值。给定完整已知外载应显式除2后进入求解；不再次乘厚度。材料／Hu分量只分解内部响应，总载荷合同使用 total。即使新力控成功，也不能将包含Hu的导向总力平衡直接称为纯接触承载力。

## 新账本不能沿用处方驱动支撑求和

原probe把 body-x DOF 残差列作外部处方驱动支撑，合和等于Q；这在q给定时正确。q未知后，该合力已由显式P承担：新全局平衡应将P计入外载，不能同时将旧body-x合力再列为支撑，否则双计。原body-y导向及其余零支撑保留；保持转角／刚体性的节点约束可有自平衡分量，它们在q方向的合和必须为0。

为定义一个全节点反力向量，可以选择一个仅作账本的body外载分配p，要求Σp_x=P_half，并将相应约束反力记为 `f_int−bR−p` 的消元分量；不能把该任意分配宣称压力。最薄对外账本无需此分配，明确列出“外载(P,0)、body-y导向、其余零支撑、机构输入”和广义残差即可；必要的支撑合和应从互斥DOF来源核查。全球平衡与g应分别记账，不由其中一项代替另一项。

## 控制、验收与失效界限的准备建议

- 保持原自由平衡残差门、机构平均约束门、J>0、约束／刚体误差门及全局平衡门；新增g的**单独N量纲**绝对／相对门。不能让较大的R尺度掩盖很小的工件P误差。新Merit应明确包含已规范化的g，并用本次base check固定尺度做整次回溯比较。
- 复用 general sparse LU，不对称化、不给奇异切线增加隐蔽正则。最小范围只沿绑定锚点的局部分支；Kqq或完整受约束系统奇异／失去可求解性应typed停止，不能宣称释放、稳定性或承载极限。
- 原 `.00625` 是mm，不能继承为N载荷最小增量。新的P目标、最小载荷步长、最大二分、q合理性边界及资源窗口须另行冻结；q边界如设，属于任务范围／数值停止，不是接触门。不能“保原物理”却静默将位移步长的单位改为力。
- 源准入仍应绑定完整固定父任务、原last-original峰值、材料、几何成员、原非clock设置和源码；新函数继承强准入，不放宽旧默认入口。普通旧Q可作显式载荷来源，不能代替新F/T。新q为未知，不应复用原 `prescribed_body` 分支后偷偷反查目标。

## 对主编拟议新残差尺度的补充核查

主编进一步提出：原非body free的SF与旧残差门保持；新增 `rhoP=|g|/SP≤1e−9`，`SP=max(|P_target|,|P_anchor|,F_floor)` 每个目标固定，其中 `F_floor=1e−8*(E*t)*max(|d_hold|,1e−6mm)`。`E*t` 的量纲N/mm，故该floor为N，与P／g兼容；不增加虚功因子、不需要除body节点数。SP是绝对总载荷门的尺度，不等价于对很小ΔP的相对误差门，应同时报告原值g及载荷增量。

每次Newton base的 `phi=.5*(||r_w/SF_base||²+(g/SP)²)`，所有trial保持同一SF_base和SP，配合原受控均值可行投影仅作用于非body port，理论上与上述完整残差Newton方向一致。不得投影／夹住未知q来隐藏g不平衡。SP正性依赖原正d_hold及正E/t；新接口若扩展到其他源需另作合同，不能借此扩大本轮最小范围。

拟新增必填 `minimum_force_increment_half_N`，而不是将旧mm字段改名；小模型若用 `(P1−P0)/16`，需先明确P1>P0及所用原有符号N值。未来分支允许性仍须任务明示：q应保留有符号未知量，如设置非负或上界，只能作为明确任务终止界，不能暗加投影。该方案可以进入规格冻结；尚未执行验证，也不授平衡解唯一性或稳定性。

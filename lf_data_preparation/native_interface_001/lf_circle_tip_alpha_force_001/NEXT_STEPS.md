# L-CTIPAREPORT1 待批准的最近功能阶段

本页只提出下一范围，**下一授权/启动均为false**，不能复用已关闭AFORCE1窗口。当前证据见[人工页](run_001/REVIEW.md)、[3390节点差与原对象](run_001/comparison.json)、[两图QA](author/pixel_QA.json)。

## 为什么做这个功能

公共`native_response.py:summarize_saved_native_result`已经提供单result的模型、末态/峰态、参考与view摘要；本轮不重复它，也不改默认HF摘要。源码`_views`会读取原summary并哈希PNG/GIF，不适合只关联现成研究报告而不读旧媒体的范围。

最近新增一个独立研究层的可导入读取函数与CLI（例如`load_saved_study_report`），把现成两alpha全周期、260标量差和565对/3390节点差组织为外部研究层可用的统一对象与入口。它是保存报告读取，不是新科学验收或批量标签，也不包含优化。

## 固定的小范围

1. 下一读准备先固定确切源码/输入SHA、字段与形状合同，复用已有数据，不实现另一套力学摘要。只计划读取两份普通JSON：`lf_circle_tip_alpha_comparison_001/run_001/comparison.json`与`lf_circle_tip_alpha_force_001/run_001/comparison.json`，共同前缀为`lf_data_preparation/native_interface_001/`。前者已经嵌入旧PATH1和新APATH1完整原周期对象，后者已嵌入两alpha峰节点对象；不再另读PATH/APATH、原node JSON、task、convergence、HP或完整Newton文件。
2. 以alpha、原global12/loading1.06、两峰原SHA及原源身份精确关联，不按坐标近似或只用d匹配，不将origin/卸载角色改名。可导入函数返回现成cycle/scalar-comparison/peak-node层级及来源；保20原目标/两alpha40原值、260标量差、565对3390节点差、原组/合力/holding和已有资格，不重新计算差量、过滤节点、归一化或生成新物理指标。原数据可由返回对象访问，轻索引不重复3390大表。
3. CLI唯一读取这两固定报告，生成轻`report.json`和人工总览索引，列物理定义、完整/选定态覆盖、来源身份和现成图页入口。图页仅限已有PATH1/APATH1/ACOMP1/AFORCE1四套结果；具体路径/数量在下一准备绑定，不遍历扩大读取。只stat/link已知页面与图，不读、哈希、解码、复制、拼接或重新渲染旧媒体；**不生成新PNG，不作旧图新像素审查**。入口让用户可直接打开已有全周期变形/力图与峰节点图，既有可见性限制原样提示。
4. 整卡获明确授权后，完成最小函数/CLI及有限静审，再按该授权唯一执行；用户已批准整卡时不重复申请同一范围。拟helper180/outer240秒、采样1 GiB、四库线程上限16。首个终端错误停止并保真实partial；无重试、修复重跑、延期、force、回滚或删除，无生产/默认HF API调用或默认HF源码/安装修改、科学数组/CSV/gzip/旧媒体读取、构模/F/T/HP/平衡求解、测试或新加载。
5. 记录实际可用入口、来源/链接核对和功能效果，更新现有状态入口，main普通提交推送、远端核对、同机异目录local-Git恢复及普通回执归档；不称异机科学复算。

## 后续粗路线与边界

先让外部研究层能够读取和比较现成结果，再据实际使用缺口决定下一有限物理实验或接触/夹持指标定义。1.02/1.03空间诊断、参数/网格研究、生产alpha调整均只是以后可能的选项，本计划不自动启动它们，也不例行补齐HP。

节点全局弱力不是面牵引或压力；原参考保持各自选定态/方向，不迁移为全周期。新报告入口不升级有效夹持、释放、稳定性、alpha独立、网格/域收敛、完整路径独立参考或HF5资格；到零仍只表示输入回程完成。旧14段/新4段历史与计数分别保存，不当纯alpha性能比较。

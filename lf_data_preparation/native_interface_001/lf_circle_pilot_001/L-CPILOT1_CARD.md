# L-CPILOT1：wave 圆形工件独立短行程试算

状态：用户直接授权；本文件是执行前具体化，尚未启动。

## 目标与取舍

整体目标是把普通 LF 结构几何交给独立 HF TMC 前向分析，逐步取得可靠的变形与力响应。本卡先检验已通过 L-CPREP1 的圆形工件在短行程中能否完成平衡求解，同时补齐圆形保存态显示。它不完成整个项目或完整加载／卸载。

## 固定输入与数值门

- 仅 wave 几何；使用 L-CPREP1 保存的 source_geometry 描述及唯一配对 NPZ。旧模型、旧状态和旧媒体不作输入。
- 固定圆形半工件，半径9 mm、圆心(71,40) mm；网格 h=0.5 mm，13440单元／27378 DOF。原材料 E=1 MPa、nu=0.3、plane strain、gamma=1e-6、alpha=5e-7、长度80 mm，端口与边界保持。
- 从零单次调用默认 evaluate_native；独立目标 [0,0.25,0.50] mm，load_only。不用保存态续算，不改原25目标任务。新 task 仅四个说明字段区别于 CPREP task，其余精确相等。
- 十项 settings 和三项 options 精确沿用 L-BFWD1；原相对残差1e-9、约束1e-10、全局力平衡1e-6、固定 split 位移8e-11 mm和 J>0不变。约束检查沿用逐态原 bound。原回溯与有界二分允许，实际接受态 N 不预设等于3。
- 保留原 callback；薄包装仅观察既有内存缓存与元数据，核对原生产门，不新增科学内核或验收门。API失败原样保留，不因辅助观察重写原结果成功／失败。

## 执行、显示与记录

一次 SUP2 启动：controller1800 s；保存显示共享600 s；helper总2700 s／outer2760 s；采样8 GiB。共享显示时钟覆盖绑定、一个干净子进程圆形viewer、普通结果JSON收敛投影、状态表及人工页；最终全输出封存仍在 helper2700 s内。SUP2原固定5秒清理包含于outer，不新增force兜底或其他控制合同。

仅科学成功及原门通过后运行显示。纯显示读取新模型27字段，每接受态 state／forces 共18字段，即1+2N唯一NPZ、27+18N字段；不解码切线载荷，最终全输出封存仍覆盖其文件。每态调用既有纯 Q1 外缘、凸Q1单元并集重叠、工件节点力观察，保留原精确合力检查。输出三张实际变形／外缘与力／峰值场 PNG、一张原收敛PNG、一份实际N帧GIF、逐态表和人工页。全结构为可视对称镜像，数值保留原下半模型；坐标放大倍数1。

距离是实际外缘无符号距离；交叉／近接与单元并集重叠分别报告，未做集合包含判断。圆形 Fy 是全局y合力，不称圆周法向压力。材料＋Hu弱式节点力不直接授予压力或有效夹持资格。没有新测试、HP、默认HF安装或源码修改。

唯一启动，首个终端错误停止后续科学／显示；仅原窗口开放时允许实际部分证据封存。无外部重试、修复重跑、延期、force、回滚或删除。成功后最多四张新PNG各一次像素检查；GIF帧数仅原viewer核验，不额外解码。

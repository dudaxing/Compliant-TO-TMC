整体目标是读取普通 LF 几何，独立计算 HF 非线性 TMC 的力、结构变形、平衡和接触相关指标，供外部研究比较。HF 不运行 LF 优化、dmftd 或 MPM。本卡根据用户授权，探索较大行程下的对称固定工件；具体九目标由上一轮实际结果决定。

007 已完成零起点 0/.5/1/1.5/1/.5/0 mm 的七接受态循环、45 F/26 T/一次求解，全部接受态各新 HP80/120（14 次、135364 项原门）。峰值 minJ=.1686782188、输入反力 .3331784932 N、输出 1.7476327691 mm。独立闭区域观测未发现跨区域内部重叠，底面首次法向射线距离 .3593983675 mm，左面首次法向射线距离 2.6988103587 mm。底面接近、左方向间距增大，仍无有效夹持或接触压力资格。旧 unsigned 左距 1.6619606665 mm 的最近点在角点下方，不能当作侧壁法向闭合。

本卡选择 1.75 mm，显式保留 1.5→1.75 及返程 1.75→1.5 的真实结果。新循环从零开始，不读取旧保存态作求解初值；已测 1.5 mm 的结果和资格不自动延伸到新态。

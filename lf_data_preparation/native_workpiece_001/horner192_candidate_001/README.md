# F16 辅助能量 Horner 公共缩放候选卡

本项目的整体目标是从 LF 普通几何文件独立计算 HF 非线性正向力学、平均位移驱动与真实工件的夹持和卸载，供外部研究层比较；HF 内不含优化。用户已授权探索性工件参数、逐步功能开发、记录、可视化及提交推送。本卡只处理 cycle003 卸载的真实首次拒绝输入，不构造新物理任务。

## 问题与最小实现

当前 main 的 matmul320 内核在新的 [0,0.5,0] mm 路径中接受初态和峰值，但卸载失败。独立 trace 定位 F16 到辅助能量14阶多项式的 Horner 循环：先乘再恢复物理量时，36个积分点的非零低词乘项低于原 DD 支持下界。支持域仍为原2^-400…2^400；该拒绝不是 IEEE 下溢，也不是线性求解成本。后续 T25 未捕获，不能用 F16 解释或资格化它。

隔离候选仅把 Horner 余式及每个原系数一起保持在已有 E=2^192 公共能量尺度，完成系数加法后才恢复；单循环保留 power14…2 的13个原二进制系数、原多项式及全部 DD 项。未选中的 NumPy 分支不额外乘1，原运算顺序保持。P/S、完整力、缓存 shadow 切线、matmul320、普通乘法、CI 支持域和控制器均不改。JAX 图有改变但本卡不执行或资格化 AD/JIT。公共缩放的上界有裕量，不保证任意极小孤立低词均受支持。

## 输入与执行顺序

绑定 cycle003 的原 F16 捕获16字段 input.npz（47824b835a70f6eef7ab1d3712d92958040877c4451a3b06902ddb997082248e），state9dbd3c951d322e14fde9734838108af6f4237816f1e9054ad40ada8aafa764e2；原27字段模型和 points，3200cells/6642DOF、原376固定自由度及 Et20 尺度。14重叠字段必须逐字节相同。不删除实体、工件、固定DOF或切线项。

从 current795 的42文件来源复制隔离 runtime（含已验证的 B52 缓存切线消费者），仅候选核心改变。原输入端方向作为历史绑定；独立 witness 文件逐字节复制旧全域 dyadic 方向：v_i=((37*i mod257)-128)/128，原固定DOF置零。它覆盖本次全部26个故障单元，仍只资格化一个方向。旧 F36 的高精度结果不借用。

1. 正式运行前静态核对最小差异、来源、原输入、测试及验证包装。作者阶段的一次换行格式匹配失败发生在修改核心前，无数值调用；已改为原 LF 字节，不属于冻结后的修复重试。

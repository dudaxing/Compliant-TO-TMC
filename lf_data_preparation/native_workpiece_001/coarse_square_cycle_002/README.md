# 粗方工件 0.5 mm 有序循环

目标是把已完成的 0.1 mm 固定工件循环推进到更大行程，观察接近趋势、非线性传力及卸载；本阶段不是预先规定的接触或夹持成功试验。用户已委托选择对称方形／圆形工件参数及探索行程。先保留方形边长 16 mm、中心 (70,40) mm、固定刚体下半部和初始 2 mm 间隙，只改变路径。

路径为 `[0, .1, .25, .5, .25, .1, 0]` mm。同一 h=1 mm 原生机构／背景、3200 单元、6642 DOF、376 fixed／6266 free，原材料、介质／Hu 参数、平均输入端口、自由输出和最小增量 .00625 mm 均保持。全部核心来源与旧 49 文件闭包保持原 SHA；新增包装另冻结。粗／细来源的设计不同，不能称网格收敛。

| 唯一阶段 | 资源 | 工作与范围 |
|---|---|---|
| 准备 | outer 60 s／8 GiB sampled RSS | 原方向字节复制、新任务／来源／输入冻结；0 力学 |
| 生产 | API 与整体 helper 1200 s，outer 1260 s／8 GiB sampled RSS | 一次连续七目标循环，保留全部真实接受态和试探日志 |
| 独立参考 | 整体 240 s，outer 300 s／8 GiB sampled RSS | 每个实际接受态，包括二分态，完整 3200 单元 HP80／120；至少 14 HP，不加时、不删态 |
| 保存态测量／每个查看器 | outer 120 s／8 GiB sampled RSS | 仅原保存态；几何距离、真实结构、输入／工件分力、卸载、GIF，无新 FE／HP |

生产预算根据前一轮三态 263.45 s／峰值约 852 MB 和参考六 HP 60.11 s 设置，不是完成保证。资源监控采用协同截止与采样 RSS，不是 OS 硬内存限制；外层超限写停止请求，生产在下次力入口退出，监控等待真实终端，不使用 force 或 PID 清理验收。

`execute_peak05.py` 仅临时包装原 `native_mean._assemble_force`，成功返回原 tuple；首次 `unsupported_arithmetic_range` 保存完整两数组、单元 DOF／积分算子／材料输入、异常及原始力序号，再原样重抛同一异常。保存 IO 失败是独立阶段错误。观测不增加力、切线或参考调用，不改变原回溯算法；不观察后续切线异常，也不预称捕获点是 trial。正常预算内每次原力函数恰调用一次；资源截止前可以停止调用。

此前 0.1 mm 末腿三次范围拒绝的输入未保存，原因尚不能证明；旧证据永久保留。本次若捕获实际失败，须与完整路径序号对账，后续另行诊断，不能直接改内核或给拒绝态资格。

`audit_peak05.py` 使用原固定 SHA 的 `CoreAudit.run_state` 和 `WorkpieceCycleAudit.workpiece_checks`，原公式和门不改。新 loader 绑定本路径／工件／来源／保存数据，重建每一次基态／试探调用；只有已记录且紧接同基态半因子的范围拒绝可解释未完成 F。未知短缺仍拒绝。全部 CSC entries 核对，HP 切线独立核对一个声明方向，不称全部列均作 HP。

每阶段首个正式错误关闭该阶段，保存现有失败与部分结果；无同阶段修复、重跑或 force。接触压力、signed normal gap、夹持判定、自由工件、H2／H3／HF5 和完整 AD／JIT 尚未实现或未资格化。无符号外边最近距与旧 node-window 分开报告，图的放大面板不能作为接触判断。

# 首次卸载范围拒绝：隔离 matmul320 候选卡

用户已委托参数探索、渐进功能实现及继续开发。本阶段处理已保存的粗方0.5 mm循环首次力范围拒绝，尚不扩大物理行程。整体目标仍是独立HF文件入口、完整力/切线、平均驱动平衡和实际工件夹持—卸载；旧失败及旧资格保留各自来源。

## 最小实现与为什么

首次拒绝F36原始state SHA为`dabcc967cfb475bd42b5baacca0adf6ae58f50a765d9c6e43994257ef42b4a03`。原诊断在已选中tiny支的`S=TᵀP`矩阵乘法发现4个low×high的EFT低词越出2^-400支持下界。隔离runtime保留全部DD项和原范围门，仅将`_scaled_matmul`共同缩放2^±192改为2^±320，另改身份字符串/docstring。两个callsite为small_P和S；普通乘法、能量、方向尺度、力学模型及求解器均原样。当前live源码不改。

完整batch的tiny selector依赖所有元素，不能用两个故障单元代替3200单元输入。静态上界：当前selector |G|≤2^-64、系数/算子≤2^8、near支成立时，两callsite操作数可保守界为2；上缩左输入≤2^321、单项≤2^322、两项收缩≤2^323，低于2^400操作数及2^900临时量上界。320对保存的四尾词增加128位余量，不增加运算数；不能保证任意孤立极小项或最终回缩均受支持。该范围仍由原门决定，不能删掉S、DD项或把极小力归零。

# HF-2 修正：三个强压缩存档状态的精度验证

本报告只汇总已有 `strong_precision_001` 输出，没有重新运行内核、Decimal 或非线性路径，也没有修改既有脚本、夹具或数值文件。

**结论：192 项预先冻结的强压缩精度检查全部通过。** 新直接 Piola 表达式、独立高精度参考及真实残差 Jacobian 在三个旧状态上的计算一致性已经通过本小阶段验收。三个旧位移本身仍未满足 `1e-8` 的高精度平衡条件；这些状态没有被修正、覆盖或追溯改判。新完整路径的平衡与逐目标比较属于后续独立验收，不由本报告替代。

## 1. 输入和比较含义

三个固定状态为旧 Python λ=0.73、旧 MATLAB λ=0.76 和 λ=0.99。每个状态使用保存的实际 binary64 `u/grad/hessian/weights/lam/mu/kr/F0`；Decimal 从这些值精确提升，再计算 F、J、log、exp、积分及装配。参考器不导入生产核，不提升已算好的浮点 F/J/局部力充当完整高精度参考。50 位和 80 位结果另作交叉检查。

新版材料力采用 `P=μF+(λ ln J−μ)F^-T`，保持 Q1、平面应变、3×3 Lobatto 及全域 HuHu 弱式不变。Jacobian 来自该实际残差，包含 `exp(-5J)` 的导数，没有以能量 Hessian 代替非保守正则项。

以下“旧核”是原 HF Python 0.2.0 内核字节副本在**同一套实际输入**上的只读重算，不是 MATLAB 原运行存档的内力值。这样比较隔离了核表达式差异，而不会混入不同语言的输入或装配口径。旧核数值只作诊断，不决定新版本通过与否。

## 2. 旧、新力向量对高精度参考的误差

定义 `εF = ||f_binary64−f_HP||₂ / ||λF0||₂`；先在 Decimal 中求力差，避免高精度内力先舍入后抵消。表中取 `tangent=True/False` 两模式的较大误差。全量及自由 DOF 的新核预算均为 `1e-9`。

| 固定状态 | 旧核 εF，全量 | 新核 εF，全量 | 旧核 εF，自由 DOF | 新核 εF，自由 DOF |
|---|---:|---:|---:|---:|
| Python 0.73 | 1.074015e-9 | 7.820107e-12 | 1.074015e-9 | 7.819860e-12 |
| MATLAB 0.76 | 1.726232e-9 | 7.032716e-12 | 1.726232e-9 | 7.032447e-12 |
| MATLAB 0.99 | 4.806727e-9 | 1.174814e-11 | 4.806727e-9 | 1.174805e-11 |

新核全量力差的绝对范数分别为 `7.26596e-12、6.80290e-12、1.48034e-11`，对应旧核 `9.97908e-10、1.66982e-9、6.05679e-9`。三个状态的核计算误差下降约两个至三个数量级。新核最差归一化误差占冻结 `1e-9` 预算约 1.17%。

这是**力的计算误差**，不能与**旧位移的平衡残差**混同：

| 未改变的旧状态 | 高精度 `||f_HP−λF0||free / ||λF0||` | 原平衡阈值 |
|---|---:|---:|
| Python 0.73 | 1.064445124e-8 | 1e-8，仍超限 |
| MATLAB 0.76 | 1.075138999e-8 | 1e-8，仍超限 |
| MATLAB 0.99 | 1.044435273e-8 | 1e-8，仍超限 |

表达式修正使固定状态的力计算更准确；它本身不会把原来的位移变成新的平衡解。

## 3. 两个 JIT 路径、装配及 J 的诊断

`tangent=True` 用于 Newton 检查，`tangent=False` 用于仅残差评估。新版两模式力差除以外力范数的最大值为 `8.46019e-17`；旧核对应最大值 `8.55941e-17`。在这些状态上，两个 JIT 路径的差异远小于算术误差预算，不是原超限的主要来源。

对**完全相同的局部 binary64 力项**，另用逐 DOF `math.fsum` 与生产 `np.bincount` 比较：

| 状态 | 最大全量装配差绝对范数 | 装配差 / 外力范数 | J 对 HP 的最大相对差 | 最差位置，0-based 单元/积分点 |
|---|---:|---:|---:|---:|
| Python 0.73 | 2.05325e-15 | 2.20985e-15 | 7.44000e-12 | 741 / 8 |
| MATLAB 0.76 | 1.90650e-15 | 1.97091e-15 | 8.43139e-12 | 803 / 8 |
| MATLAB 0.99 | 2.59912e-15 | 2.06269e-15 | 7.01892e-12 | 1051 / 8 |

这些装配差也远小于旧核误差，所以没有证据把原问题归因于全局求和次序。上述三处 J 的绝对误差分别约 `6.93e-16、7.22e-16、1.39e-15`；新旧核使用相同运动学，其 J 误差记录相同。三个状态的最小 J 仍为约 `9.32e-5、8.41e-5、4.92e-5`，说明严重介质压缩依然存在；稳定表达式没有“修复”几何条件数。

这些是解释误差来源的诊断记录，没有追加新的通过阈值。

## 4. 分量与实际 Jacobian 的验证

材料、正则化、总力分别检查全量和自由 DOF；方向导数也分别验证，避免总量抵消掩盖分项错误。分量比较的分母为 `max(||HP 分量||₂,1e-8||λF0||₂)`。每个状态采用预存的全局 sin/cos 两方向，固定 DOF 为零，长度归一化为 `sqrt(hx*hy)`。

| 分量 | 力向量最大相对误差 | 实际 Jacobian 作用 `Kv` 最大相对误差 | 两项冻结阈值 |
|---|---:|---:|---:|
| 材料 | 1.16918e-11 | 7.78600e-12 | 1e-8 |
| HuHu 正则化 | 2.85382e-13 | 2.64234e-14 | 1e-8 |
| 总量 | 1.17481e-11 | 7.78564e-12 | 1e-8 |

独立 Decimal 方向导数使用 `dF`、`dJ`、`d(F^-T)` 的解析式和 `kr Σw exp(-5J)[Av−5 dJ Au]`。材料及正则项均通过，支持已实现的残差与切线一致，也排除了在这些测试方向上遗漏 HuHu 导数、错误对称化或分量抵消掩盖问题的解释。两个全局方向不是对任意强压缩状态、全部可能方向或接触物理的穷尽证明。

## 5. 五步差分和 50/80 位交叉检查

每个方向的 `h0` 只由预先规定的正 J 二次界确定，没有按差分结果调节；固定使用 `h0×{1,.1,.01,.001,.0001}`。全部 30 对双侧样本通过 `Jtrial≥0.5 Jbase` 预检，所有样本、失败判据和曲线点均保留。

| 状态/方向 | h0 | Decimal 理想差分最佳误差 | binary64 实际差分最佳误差 |
|---|---:|---:|---:|
| Python 0.73 / sin | 6.169697e-4 | 3.64548e-11 | 5.34982e-8 |
| Python 0.73 / cos | 7.135913e-4 | 3.44448e-11 | 6.36209e-8 |
| MATLAB 0.76 / sin | 5.594378e-4 | 4.47519e-11 | 7.52452e-8 |
| MATLAB 0.76 / cos | 6.210357e-4 | 4.33958e-11 | 8.17697e-8 |
| MATLAB 0.99 / sin | 3.392826e-4 | 1.19871e-10 | 1.99100e-7 |
| MATLAB 0.99 / cos | 2.966280e-4 | 1.11173e-10 | 3.01585e-7 |

六个方向均满足冻结的 Decimal 最佳误差 `≤1e-8` 和双精度最佳误差 `≤1e-6`。首次十倍缩步均使误差改善约 101–102 倍，高于预定的至少 20 倍。

双精度曲线在最小步长处出现舍入限制：MATLAB 0.99 / cos 的最细点误差为 `3.55894e-6`，没有被删掉；其五点中的最佳值仍为表列 `3.01585e-7`。该最细点的实际有效方向与理想方向相对差为 `7.68829e-7`。Decimal 理想输入差分仍下降到约 `1.11e-10`，而解析 HP/JAX `Kv` 差约 `1e-11`，共同支持细步双精度差分受输入扰动与求差舍入影响的解释。验收采用“完整曲线加预定最佳值/早期下降条件”，不是要求每个有限步长均低于最佳误差阈值。

三个基状态的 50/80 位全量及自由力差除以外力范数最大为 `1.048916844e-44`，远低于冻结 `1e-30`。另外保存的 J、能量、分量相对精度检查也全部通过。50 位参考精度不足不能解释目前约 `1e-11` 的新核算术误差。

## 6. 已定位的原因与本阶段边界

此前只读取证发现，形成 `C=FᵀF` 使条件数平方，再以 `C11*C22−C12²` 求逆分母，在第三介质强压缩时产生消去误差。那次诊断已由高精度重算确认原状态的微小超限，本次不改写该结论。

本次对同一组实际输入替换为直接 Piola 后，力误差明显减小；运动学保持相同，装配求和差约 `1e-15`、两个 JIT 模式差约 `1e-17`、HP 50/80 差约 `1e-44`，且材料/HuHu 的独立方向导数均通过。证据支持将原主要数值问题定位于逆 C 表达式的消去，而不是载荷符号、正则项遗失、两个 JIT 入口或装配求和。这个结论限于已检查输入和指标，没有证明任意形变条件下都能达到同等精度。

相关回归记录显示：完整 pytest 为 **199 通过、1 跳过、0 失败**；唯一跳过是 Windows 无权限创建符号链接的输入安全测试。旧小型参考的 **16 个案例、976 项检查、160 条差分记录全部通过**。它们支持修正没有破坏已有材料/单元/小网格一致性要求，但也不代替新的完整路径验收。
